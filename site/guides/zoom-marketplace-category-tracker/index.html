    Zoom Marketplace Category Tracker: export to CSV, Excel or JSON

    Track all Zoom App Marketplace apps for a specific Zoom product (Meeting, Phone, Webinar, etc.) in their default marketplace ranking order. Returns rank position among all apps for that product.

    This tutorial runs Zoom Marketplace Category Tracker through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 6 columns its publisher puts first: rankInProduct, name, companyName, usage, fedRampAuthorized and appUrl.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    The columns you can export

    The Actor's build declares 6 output fields in 1 dataset view ("Apps by Product"). The export below keeps these, under the labels the publisher gave them:

    Get an API token

    Copy it from Console, Settings, API and Integrations.

    Choose the input

    1 field is required:

    • product: Return all apps that work with this Zoom product, ranked by their position in the full marketplace listing.
