Use Spotify Podcast Show & Episode Metadata Extractor with Python

Search Spotify podcast shows and episodes, fetch a show's full episode list, resolve a show or episode by link, and browse categories by market - with descriptions, durations, release dates and preview URLs.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "episodeIds": [],
  "includeDetails": true,
  "includeEpisodes": true,
  "maxItems": 3,
  "mode": "searchShows",
  "releasedAfter": "",
  "releasedBefore": "",
  "searchQuery": "true crime",
  "showIds": [],
  "startUrls": []
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredWhat to collect from Spotify.
searchQuerystringoptionalKeyword to search for in the selected search mode, for example 'true crime', 'daily news' or a host name.
showIdsarrayoptionalSpotify show IDs, spotify:show: URIs or open.spotify.com/show/ links. Used by mode=getShow.
episodeIdsarrayoptionalSpotify episode IDs, spotify:episode: URIs or open.spotify.com/episode/ links. Used by mode=getEpisode.
startUrlsarrayoptionalMixed show and episode links. Show links are read when mode=getShow, episode links when mode=getEpisode. Regional /intl-xx/ links and embed links are accepted.
includeDetailsbooleanoptionalFetch complete show or episode metadata for every search result, including descriptions, ratings, topics, release times, paywall flags and preview audio. Turn off for a faster, lighter search.
includeEpisodesbooleanoptionalWhen mode=getShow, also export the show's episode archive. Turn off to export only the show record.
releasedAfterstringoptionalOptional YYYY-MM-DD date. Episodes older than this are skipped. In getShow mode, paging stops once the archive passes this date.
releasedBeforestringoptionalOptional YYYY-MM-DD date. Episodes newer than this are skipped.
maxItemsintegeroptionalMaximum number of show and episode records to save. Search modes have a source ceiling of about 1,000 matching results.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/SH8hDoxwDDjn0zVMr/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
