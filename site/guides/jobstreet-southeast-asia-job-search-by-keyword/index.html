    Fix common problems

    Why is salary missing on some jobs?

    Many employers do not publish a salary. When the posted label contains no real salary — for example "Weekends Off, Remote" — the salary fields are omitted rather than guessed.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
