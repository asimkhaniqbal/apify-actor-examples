Use Nike Product Catalog, Colorway & Price Scraper with Python

Search Nike.com by keyword or style code, browse 40 shoe/clothing categories across 18 marketplaces, or fetch full product-page detail including sizes, stock status and every colorway of a style.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
modestringrequiredWhat to fetch. `startUrls` auto-detects each pasted Nike search, category or product URL and overrides the other modes when provided.
searchQueriesarrayoptionalOne or more keywords, product names or style codes (e.g. `air max`, `dunk low`, `CW2288-111`). Used with mode=search.
countrystringoptionalNike storefront market for search, category browsing and non-prefixed URLs. Prices are returned in the marketplace's local currency.
categorystringoptionalCurated Nike catalog category to browse. Works in every supported country; pass several categories by using `startUrls` with category links instead.
startUrlsarrayoptionalPaste any nike.com search (`/w?q=...`), category (`/w/...`) or product (`/t/...` or `/u/...`) URLs. Locale-prefixed links such as `nike.com/gb/t/...` set the marketplace automatically. When supplied, these URLs override `mode`.
productUrlsarrayoptionalFull Nike.com product page URLs, e.g. `https://www.nike.com/t/air-force-1-07-mens-shoes-jBrhbr/CW2288-111`. `/u/` Nike By You URLs are accepted too.
styleCodesarrayoptionalNike style or style-color codes, e.g. `CW2288-111` or `CW2288`. The actor resolves each code to its Nike product page and returns full detail. For Nike By You products use the 10-digit style-color code (e.g. `6484638358`).
minPriceintegeroptionalDrop products priced below this amount (current price, in the marketplace's currency).
maxPriceintegeroptionalDrop products priced above this amount (current price, in the marketplace's currency).
minDiscountintegeroptionalKeep only products discounted by at least this percentage. 0 disables the filter.
onSaleOnlybooleanoptionalOnly emit products with an active discount.
includeAllColorwaysbooleanoptionalBy default only the representative colorway shown on Nike's grid is emitted per style. Enable to emit every available colorway as its own record, each with its own real price, color, image and product URL.
includeProductDetailsbooleanoptionalFor search, category and URL modes, fetch each listed product's detail page and add description, features, sizes, stock, images and all colorways. Adds one HTTP request per emitted record.
includeReviewsbooleanoptionalAdd the product's rating, review count, AI review summary and the three most recent reviews. Applies to product details, or to listings when `includeProductDetails` is enabled.
genderstringoptionalFilter to a single gender facet in search and pasted search URLs. Not supported by Nike's API for country=TH or TW; ignored there.
productTypestringoptionalFilter to a single Nike product type.
attributeFilterstringoptionalKeep only products carrying a specific Nike merchandising tag. Applies to search, category and URL modes.
filtersarrayoptionalOptional Nike facet labels, exactly as shown in the site's filter panel. Use `Group: Value` for an exact group, e.g. `Sports: Running`, `Color: Black`, `Brand: Nike`, `Width: Wide`, `Size: 10`, or a bare value such as `Running`. Unknown labels are skipped with a log warning.
sortBystringoptionalOrder results. Nike's public wall API has no reliable server-side sort, so the actor sorts the fetched records locally.
maxItemsintegeroptionalHard cap on emitted records across all queries, categories and URLs.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/rAtHpbmP3D6ZggkWJ/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.
