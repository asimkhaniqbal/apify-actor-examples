    Fix common problems

    Do I need an Apify proxy or any credentials?

    No. The actor reads Walmart without an account. It chooses its network path automatically and only changes it if Walmart returns a bot challenge.

    Why does my search return fewer rows than Walmart shows?

    Walmart caps listing pagination at 10-25 pages per query. Split the query by brand, facet, price band or sort order to go deeper.

    Why is brand or UPC missing from some search rows?

    Walmart's search cards omit brand/UPC for many categories. Turn on enrichDetails or use product mode to read the full item page.

    More from the publisher:

    • Why does free shipping require extra time?

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
