Use Walmart.com Product Search & Price Filter Scraper with Python

Search Walmart.com by keyword and filter results by price, rating, review count, free shipping, stock status, brand or seller, with sponsored placements flagged apart from organic results.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "enrichDetails": false,
  "excludeOutOfStock": true,
  "excludeSponsored": false,
  "freeShippingOnly": false,
  "maxConcurrency": 4,
  "maxItems": 3,
  "maxPages": 1,
  "maxReviews": 5,
  "mode": "search",

FieldTypeRequiredDescription
modestringoptionalWhat to scrape: keyword search, a category shelf, full product pages, or customer reviews.
searchQueriesarrayoptionalOne or more keywords to search on walmart.com (mode = search). Each query is walked page by page.
categoryUrlsarrayoptionalWalmart category links starting with /browse/ or /cp/ (mode = browse), e.g. https://www.walmart.com/browse/electronics/3944.
productUrlsarrayoptionalWalmart product links (mode = products or reviews), e.g. https://www.walmart.com/ip/20042402979. Short /ip/ links and alphanumeric product IDs also work.
itemIdsarrayoptionalWalmart numeric item IDs (the number at the end of a product link), one per line (mode = products or reviews).
maxItemsintegeroptionalHard cap on emitted records for the whole run. In review mode this caps review rows.
maxPagesintegeroptionalMaximum search or category pages to walk per query/URL (about 40 products per page). Walmart caps its own listing at 25 pages.
sortBystringoptionalWalmart listing order for search and browse modes.
minPricenumberoptionalOnly keep products at or above this price. Applied by Walmart's own price filter.
maxPricenumberoptionalOnly keep products at or below this price. Applied by Walmart's own price filter.
minRatingnumberoptionalOnly keep products rated at least this (0-5). Products with no rating yet are kept.
minReviewCountintegeroptionalOnly keep products with at least this many reviews. Products with no review count are kept.
freeShippingOnlybooleanoptionalOnly keep products with free shipping. Search/browse rows are automatically enriched from product pages so this filter is accurate.
excludeOutOfStockbooleanoptionalDrop products Walmart marks out of stock.
excludeSponsoredbooleanoptionalDrop paid/sponsored placements and keep organic search results only.
brandsarrayoptionalOnly keep these brands, using Walmart's own brand filter. Enter names exactly as Walmart shows them, e.g. DEWALT.
sellerContainsstringoptionalOnly keep products whose seller name contains this text (case-insensitive), e.g. Walmart, Pro Seller.
facetstringoptionalAny Walmart listing facet as type:value, e.g. retailer_type:Walmart, special_offers:Rollback, customer_rating_range_facet_new_filter_v0:4 - 5 Stars, exclude_oos:Show available items only.
enrichDetailsbooleanoptionalOpen each search/browse product page to add brand, UPC, model, description, specifications, images, return policy and review breakdown. Slower and uses more requests.
maxConcurrencyintegeroptionalHow many product or review pages to fetch at the same time (1-10). Higher is faster but more aggressive.
maxReviewsintegeroptionalMaximum customer reviews to read per product in review mode. Walmart only publishes reviews that contain text.
reviewSortstringoptionalHow Walmart should order customer reviews.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/WkaCjcP0oFPMJYAI6/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
