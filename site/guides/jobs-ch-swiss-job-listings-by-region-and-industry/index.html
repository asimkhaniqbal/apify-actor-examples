    Jobs.ch Swiss Job Listings by Region & Industry: export to CSV, Excel or JSON

    Scrape job listings from jobs.ch, Switzerland's largest job board. Search by keyword or browse by canton, industry, occupational field, or contract type, with filters for workload and seniority. Returns title, company, location, and job URL.

    Fix common problems

    Do I need a proxy, cookie or API key?

    No. Every request is anonymous and direct. Existing tasks that still send a proxy object keep running; the value is ignored.

    Why did I get fewer rows than maxItems?

    Either jobs.ch had no more matches, the 2,000-row cap was reached, or maxPages stopped the crawl. The run's status message says which.

    Why are some fields missing on some jobs?

    jobs.ch does not include every field on every posting, and the actor omits empty values rather than inventing placeholders. Detail fields require includeDetails: true.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
