    TikTok Account Stats & Repost History Scraper: export to CSV, Excel or JSON

    Look up TikTok accounts for follower/like/video stats, recent videos, and reposted content in one run. Optional session cookie unlocks a profile's full video history. No cookie required for account stats or reposts.

    What people export it for

    • Influencer vetting — pull follower counts, engagement counters and recent performance for a shortlist of creators.
    • Follower growth tracking — schedule a stats-only run to build a time series of followers, hearts and video counts.
    • Competitor monitoring — watch posting cadence and engagement for brand accounts with date-windowed runs.
    • Repost analysis — see exactly which outside content a creator chooses to amplify.
    • Playlist research — export curated playlists as structured video lists.
    • Live campaign checks — confirm whether an account is live and capture the stream details in the same run.

    Fix common problems

    Do I need a TikTok account, cookies or a proxy?

    No. The actor reads public profile data exactly as any logged-out visitor could. There is nothing to configure beyond your input list. (Older versions accepted sessionCookie, cookies and ttwid; those fields were removed because they never changed what the actor returns — old saved tasks that still send them keep working unchanged.)

    Why did a monitoring run return no video rows?

    Either the account posted nothing since the previous run, or the checkpoint already covers its newest video. The run still succeeds and still emits the profile row, so a scheduled stats-only watch keeps working.

    Why does an account show no reposts?

    Many accounts genuinely never repost. When an account has no publicly visible reposts, the run still succeeds and simply emits no repost rows.

    More from the publisher:

    • Why can reposts be missing when I ask for both videos and reposts?
    • Why are some fields missing from a row?

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
