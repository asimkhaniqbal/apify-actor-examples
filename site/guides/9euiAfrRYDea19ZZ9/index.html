FieldTypeRequiredDescription
modestringrequiredWhat to fetch from ESPN.
leaguestringoptionalLeague slug. The sport is derived automatically.
leaguesarrayoptionalOptional multi-league override for modes that iterate leagues (scoreboard, odds, standings, teams, teamDetail, news, players, schedule, rankings), e.g. ["nba","nfl"].
datePresetstringoptionalDate window for scoreboard and odds. ESPN accepts one date per request, so ranges are fetched one day at a time.
startDatestringoptionalFirst date for datePreset=custom, in YYYYMMDD or YYYY-MM-DD.
endDatestringoptionalLast date for datePreset=custom (inclusive), in YYYYMMDD or YYYY-MM-DD. Maximum 366 days.
seasonintegeroptionalESPN season year for standings, schedule, players and rankings (e.g. 2025). Leave blank for the current season.
seasonTypestringoptionalFilter a team schedule by season phase (ignored for soccer schedules, which ESPN reports as one league season).
teamIdsarrayoptionalTeams for teams/teamDetail/schedule/players. Accepts 2, BOS or nba/BOS. Get IDs from mode=teams.
eventIdsarrayoptionalGames for gameDetail/odds. Accepts 401909904 or nba/401909904. Get IDs from mode=scoreboard.
athleteQueriesarrayoptionalPlayer names to search, e.g. ["LeBron James", "Jannik Sinner"].
athleteIdsarrayoptionalESPN athlete IDs for direct profiles, e.g. ["1966"].
rankingTypestringoptionalWhich poll to return. 'all' includes every poll ESPN publishes for the league.
statusFilterstringoptionalFilter scoreboard, odds or schedule rows by game state.
liveOnlybooleanoptionalKeep only in-progress games (scoreboard and odds).
newsScopestringoptionalLeague news is capped at 50 articles by ESPN. Global pages the ESPN now feed and filters to the selected league.
includeTeamDetailsbooleanoptionalFetch each team's record, venue and next event. Adds one request per team.
includeGameDetailsbooleanoptionalAttach the full game summary to every team-sport game. Adds one request per game.
includePlayerStatsbooleanoptionalAttach latest season stats to player rows and the player box score to gameDetail. Adds requests per player.
includeGameLogbooleanoptionalAttach the current-season game log to each player. Adds one request per athlete.
includePlayByPlaybooleanoptionalInclude the full play-by-play list in gameDetail (scoring plays are always included).
maxItemsintegeroptionalHard cap on data records. Notice rows explain unsupported or empty requests.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/9euiAfrRYDea19ZZ9/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
