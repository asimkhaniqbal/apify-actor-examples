Use LinkedIn Post Reactor Identity & Reaction Type Scraper with Python

Scrape the reactors on LinkedIn posts with name, headline, profile URL, and the specific reaction type they left, filterable by reaction type and date using your own LinkedIn session.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
postUrlsarrayrequiredLinkedIn post URLs or bare activity IDs. Accepts full post URLs (feed/update/urn:li:activity:... or /posts/...) or plain numeric activity IDs.
cookiestringrequiredYour LinkedIn session cookie. Accepts: (1) the li_at value from browser DevTools, or (2) full cookies JSON array exported from an extension like EditThisCookie.
maxReactorsPerPostintegeroptionalMaximum number of reactors to scrape per post. LinkedIn typically exposes up to 1000.
reactionTypeFilterarrayoptionalOnly include reactors who gave these reaction types. Leave empty to include all reaction types.
reactionTypesarrayoptionalAlternative multi-select filter using LinkedIn's raw API reaction codes. Leave empty to include all.
minDatestringoptionalOnly include reactions newer than this ISO date (YYYY-MM-DD). Optional.
languagestringoptionalPreferred LinkedIn locale for the session (affects headline/text language where applicable).
proxyConfigurationobjectoptionalOptional Apify proxy configuration. Residential proxy recommended for best results.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/NvggfHSdNu8V6APDG/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
