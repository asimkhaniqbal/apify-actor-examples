Use YouTube Channel Video Catalog & Profile Scraper with Python

Get a YouTube channel's profile details (subscribers, description, links, verification) together with its video, Shorts, playlist or live-stream catalog, for one channel or many at once.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "channelUrls": [
    "https://www.youtube.com/@Apify"
  ],
  "includeAbout": true,
  "includeCourses": false,
  "includeExactMetrics": true,
  "includeLiveVideos": false,
  "includeMembersOnly": false,
  "includePlaylists": false,
  "includePodcasts": false,
  "includeReleases": false,
  "includeShorts": false,
  "maxVideos": 3
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
channelUrlsarrayrequiredYouTube channel URLs, handles (@username), or channel IDs (UCxxx). Accepts any format.
maxVideosintegeroptionalMaximum number of videos to scrape per channel. Set to 0 to get only channel info without videos.
sortVideosBystringoptionalHow to sort the channel's video listings. If YouTube does not offer the chosen sort for a channel, newest-first is used.
sortShortsBystringoptionalHow to sort the channel's Shorts listing (when includeShorts is enabled). Falls back to newest-first when the channel offers no Shorts sort.
includeAboutbooleanoptionalExtract total views, join date, location, country, and external links from the channel About page.
includeShortsbooleanoptionalScrape the channel Shorts tab and include Shorts in the output.
maxShortsintegeroptionalMaximum number of Shorts to return (when includeShorts is enabled).
includeLiveVideosbooleanoptionalScrape the channel Live/Streams tab and include live, upcoming, and past streams.
maxLiveVideosintegeroptionalMaximum live/stream videos to return (when includeLiveVideos is enabled).
includePlaylistsbooleanoptionalScrape the channel Playlists tab and include playlist metadata in the output.
maxPlaylistsintegeroptionalMaximum number of playlists to scrape (when includePlaylists is enabled).
includePodcastsbooleanoptionalScrape the channel Podcasts tab and include podcast shows (when the channel has one).
maxPodcastsintegeroptionalMaximum number of podcast shows to return (when includePodcasts is enabled).
includeCoursesbooleanoptionalScrape the channel Courses tab and include course playlists (when the channel has one).
maxCoursesintegeroptionalMaximum number of courses to return (when includeCourses is enabled).
includeReleasesbooleanoptionalScrape the channel Releases tab and include release playlists (when the channel has one).
maxReleasesintegeroptionalMaximum number of releases to return (when includeReleases is enabled).
includeMembersOnlybooleanoptionalAlso list members-only videos (titles and public metadata) when YouTube offers the Members-only filter for this channel. Rows carry isMembersOnly and are added in addition to maxVideos. Playback still requires the membership.
includeExactMetricsbooleanoptionalAlso fetch each video's exact view and like counts, duration, publish date, category, and description. Turn off for faster, cheaper runs with listing-page values only.
marketstringoptionalCountry used for regional content availability and localized results (YouTube gl parameter).
languagestringoptionalLanguage for YouTube's interface text (relative dates like "2 days ago"). Titles and descriptions stay in the creator's own language.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/fNm0e9I6ncv8nf6jt/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

YouTube channel profile metadata and video, Shorts, playlist, podcast, course, release, and live-stream rows with exact views, likes, and publish dates.

Questions before you run

Which inputs are required?

The published required fields are channelUrls

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
