    Fix common problems

    Why is spend missing on some ads?

    Meta publishes spend and impressions ranges only for political/issue ads and EU-regulated advertising. The actor returns those fields when the source has them and omits them otherwise — it never fills a gap with a guess.

    Why did my political search for an EU country return all ad types?

    Meta's political/issue archive does not cover EU/EEA countries; EU political ads live in the general transparency stream, so the actor automatically searches all types there and says so in the run log.

    Why does ad_text sometimes contain {{product.brand}}?

    Dynamic-creative (DCO/DPA) ads are stored with template placeholders; Meta resolves them only when the ad is delivered. The actor keeps the served text untouched in ad_text, records the placeholder in template_body/template_tokens, and attaches resolved_ad_text/resolved_title when the payload's cards contain the resolved creative instead of inventing one.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
