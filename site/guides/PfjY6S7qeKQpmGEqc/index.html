Use Craigslist Classifieds Scraper with Category Attributes with Python

Scrape Craigslist search results and individual posts across any city subdomain, with category-specific attributes for jobs, housing, autos, and for-sale posts. No login or proxy required.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "maxItems": 3,
  "proxyConfiguration": {
    "useApifyProxy": false

  "startUrls": [
    {
      "url": "https://sfbay.craigslist.org/search/jjj"

  ]

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
startUrlsarrayrequiredCraigslist search URLs or direct post URLs. Examples: https://sfbay.craigslist.org/search/jjj, https://newyork.craigslist.org/search/hhh, or a full post URL like https://sfbay.craigslist.org/eby/grd/d/hayward-item/7918207144.html
searchTermstringoptionalOptional keyword; appended to each search URL as ?query=<term>. Ignored for direct post URLs.
maxItemsintegeroptionalMaximum posts to return across all start URLs.
scrapeDetailsbooleanoptionalFetch each post's page for full description, attributes, coordinates and images. Off = listing-card data only (title, url, price, location).
minPriceintegeroptionalOptional minimum price filter (USD). Applied to the numeric portion of the listing price when present.
maxPriceintegeroptionalOptional maximum price filter (USD). Applied to the numeric portion of the listing price when present.
hasImagebooleanoptionalWhen true, only include posts whose `images` array is non-empty.
proxyConfigurationobjectoptionalApify proxy. Craigslist typically works from datacenter IPs with no proxy — leave off for lowest cost.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/PfjY6S7qeKQpmGEqc/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
