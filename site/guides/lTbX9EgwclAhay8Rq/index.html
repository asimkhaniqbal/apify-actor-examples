Use Ozon.ru Product Pricing, Ratings & Seller Scraper with Python

Search, browse categories, or fetch full product details from Ozon.ru with pricing, discount, rating breakdown, seller profile, spec, and variant data via a required Russian residential proxy.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to collect.
searchQueriesarrayoptionalOne or more keywords, e.g. `iphone`, `телевизор`, `кофемашина`. Each query is collected in order.
categoryUrlsarrayoptionalFull Ozon category/brand URLs or bare slugs, e.g. `https://www.ozon.ru/category/smartfony-15502/` or `smartfony-15502`.
productUrlsarrayoptionalFull Ozon product URLs, short `ozon.ru/t/...` links, or bare numeric SKU/product IDs.
sellerUrlsarrayoptionalOzon seller storefront URLs, slugs, or numeric seller IDs, e.g. `https://www.ozon.ru/seller/dubaidutyfree/`.
sortBystringoptionalResult ordering for search, category, and seller catalog listings.
sortReviewsstringoptionalHow product reviews are ordered.
storefrontstringoptionalWhich Ozon market to read. Prices use the local currency: RUB for Russia, BYN for Belarus, KZT for Kazakhstan.
minPriceintegeroptionalDrop products cheaper than this amount in the selected storefront currency.
maxPriceintegeroptionalDrop products pricier than this amount in the selected storefront currency.
minRatingnumberoptionalDrop products rated below this value on the 0-5 scale.
inStockOnlybooleanoptionalOnly keep products that are currently available.
maxItemsintegeroptionalHard cap on emitted records. In seller mode this includes the seller profile row.
maxReviewsPerProductintegeroptionalHow many review rows to collect for each product. Set 0 to collect only question rows.
includeProductDetailsbooleanoptionalFor search and category rows, also fetch the product page for description, full specifications, gallery, and variants.
includeOtherSellersbooleanoptionalAdd the buybox list of other sellers for each product.
includeSellerDetailsbooleanoptionalAdd the seller's legal name, registration number, address, and confirmed brands to product rows.
includeSellerProductsbooleanoptionalEmit the seller's catalog products as product rows in addition to the seller profile.
includeQuestionsbooleanoptionalAlso emit buyer questions and their answers for each product.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/lTbX9EgwclAhay8Rq/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
