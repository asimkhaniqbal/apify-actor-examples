Use Google Maps Route & Distance Matrix Scraper with Python

Get driving, walking, bicycling or transit routes between two locations - distance, duration, traffic and turn-by-turn steps - or build a travel-time matrix across many origins and destinations in one run.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
modestringoptionalWhat to scrape: one route (with optional waypoints), a distance matrix, or a list of Google Maps directions URLs.
stopsarrayoptionalOrdered stops for route mode: 2–10 locations. The first is the origin, the last is the destination, and everything in between becomes a waypoint.
originsarrayoptionalStarting locations for matrix mode. Each origin is paired with every destination below.
destinationsarrayoptionalEnding locations for matrix mode. Each destination is paired with every origin above.
directionsUrlsarrayoptionalGoogle Maps directions links for URLs mode. Canonical /maps/dir/ links and short share links are both accepted; waypoints and travel mode are read from the link when present.
maxPairsintegeroptionalMaximum number of origin × destination pairs to request in matrix mode. Pairs beyond this cap are left out.
travelModestringoptionalHow to travel between the stops.
avoidTollsbooleanoptionalDriving only — ask Google Maps to avoid toll roads. If no toll-free route exists, Google may still return a toll route.
avoidHighwaysbooleanoptionalDriving only — ask Google Maps to avoid highways and motorways. If no practical alternative exists, Google may still return a highway route.
avoidFerriesbooleanoptionalDriving only — prefer routes without ferry crossings. If every route uses a ferry, the result is still returned and marked with avoidanceUnmet.
departureTimestringoptionalOptional ISO 8601 departure time as local time at the origin, for example 2026-06-16T10:30:00. Used for driving traffic estimates and transit schedules. A timezone offset is accepted but ignored; walking and bicycling ignore the field.
maxAlternativesintegeroptionalMaximum number of route alternatives to return per trip, including Google's recommended route. Applies to route and URLs modes. Google usually supplies up to 3 alternatives.
maxItemsintegeroptionalGlobal cap on the number of records pushed to the dataset.
includeStepsbooleanoptionalAdd turn-by-turn steps with instruction, distance, duration, maneuver, coordinates and route geometry for every returned route.
includeStreetViewbooleanoptionalAdd a Street View panorama ID and thumbnail URL to each step where Google publishes one. This also enables step details.
languagestringoptionalLanguage for instructions and other localized text.
unitsstringoptionalPreferred distance units for the formatted distance fields. Meter values stay unchanged.
requestDelayMsintegeroptionalPause between directions requests. A small delay keeps large matrix runs polite and reduces rate limiting.
proxyConfigurationobjectoptionalOptional fallback proxy. The actor first requests Google Maps directly and only retries through this proxy if the direct request is blocked.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/nsNiNL5MalNOLsSyK/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
