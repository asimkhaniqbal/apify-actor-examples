Use eBay Item, Store & Store Category Detail Extractor with Python

Extract detailed product data from eBay individual item pages, seller store fronts, and store category pages, or search by keyword across 8 marketplaces, with item specifics, images, seller trust signals and shipping/return terms.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "marketplace": "https://www.ebay.com",
  "maxItems": 3,
  "proxy": {
    "apifyProxyGroups": [
      "RESIDENTIAL"
    ],
    "useApifyProxy": true
  },
  "searchQueries": [],
  "startUrls": [
    {
      "url": "https://www.ebay.com/sch/i.html?_nkw=iphone+15&_sop=12"
    }
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
startUrlsarrayoptionalList of eBay URLs to scrape. Supports individual item pages (/itm/), search result pages (/sch/), category pages (/b/), and seller store pages (/str/). Optional if searchQueries is provided instead.
searchQueriesarrayoptionalPlain keyword searches — no need to construct a URL. Each keyword is searched on the selected marketplace. Optional if startUrls is provided instead.
marketplacestringoptionalWhich eBay country site to use for searchQueries. Ignored for startUrls entries, which use whatever domain is already in the URL.
maxItemsintegeroptionalMaximum number of items to scrape. Applies mainly to store/category/search pages.
proxyobjectoptionalApify proxy configuration. Residential proxy is required — eBay's bot protection redirects every datacenter IP to a captcha page. Keep the default RESIDENTIAL prefill unless you have a trusted alternative.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/ue8AF0IdZnL8KILaW/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
