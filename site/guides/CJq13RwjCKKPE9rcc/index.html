Use Facebook Page & Profile Finder by Keyword or URL with Python

Find Facebook Pages or public profiles by keyword, or scrape a list of Facebook URLs directly, and get back contact info, category, ratings, follower counts, reviews, and recent posts.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
modestringrequiredChoose whether to discover Pages/profiles by keyword or read the Facebook URLs you already have.
searchQueriesarrayoptionalKeywords to search on Facebook (mode=search), e.g. 'coffee shop', 'dentist Berlin'. A pasted facebook.com/search/pages/?q=... URL is accepted too. Either this or startUrls is required.
searchTypestringoptionalSearch for Pages, public profiles, or both. Applies to mode=search.
locationstringoptionalA city or country added to every keyword, e.g. 'Berlin' or 'Kansas City, Missouri'. Facebook search is relevance-ranked, so this narrows results toward that place; it is not a strict geographic filter.
locationUidsarrayoptionalOptional numeric Facebook Place IDs, one page search per UID, e.g. 108591349161413 from facebook.com/places/<id>/. maxResults is distributed across the UIDs and duplicate pages are removed. Results can include nearby businesses; this is not a strict city boundary.
categoryFilterstringoptionalOptional case-insensitive text filter on a page's category, e.g. 'dentist' or 'restaurant'. Applied after page details are read; leave empty for all categories.
startUrlsarrayoptionalDirect Facebook Page or profile URLs to read (mode=urls), e.g. https://www.facebook.com/McDonalds, https://www.facebook.com/profile.php?id=..., /people/... or /p/.... Either startUrls, startIds or searchQueries is required.
startIdsarrayoptionalNumeric Facebook IDs or @handles to read (mode=urls), e.g. 100064458773195 or @McDonalds. Combine with startUrls if you have both. Either startUrls, startIds or searchQueries is required.
maxResultsintegeroptionalUpper bound on rows per search query (mode=search) or in total (mode=urls). Facebook may return fewer when the index is exhausted. Deep searches use extra networking automatically.
fetchPageDetailsbooleanoptionalOpen each result to add category, contact details, follower counts, ratings and reviews links. Turn off for a fast identity-only list of names, URLs, IDs and verification badges.
includeReviewsbooleanoptionalFetch up to 10 real reviews per page when Facebook publishes them. Adds one request per result.
addDetailbooleanoptionalAdd creation date, whether the Page is currently running ads, and its public Page Transparency ID. Adds one request per result.
includePostsbooleanoptionalAdd up to maxPosts recent posts from the Page/profile timeline (text, timestamp, permalink, media and engagement when visible).
maxPostsintegeroptionalMaximum recent posts to keep per result when includePosts is on. Facebook may serve fewer when the timeline is empty or restricted.
verifiedOnlybooleanoptionalKeep only results Facebook marks as verified. Unverified or unknown results are dropped.
rehostImagesbooleanoptionalCopy profile and cover images into Apify storage so their URLs stay valid, instead of returning Facebook's signed CDN links (which expire after about five days). Adds one download per image.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/CJq13RwjCKKPE9rcc/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
