Use Immowelt Germany Rent & Buy Listings Scraper with Python

Scrape Immowelt.de - one of Germany's largest real-estate portals. Search rental and for-sale apartments and houses by city, price, rooms, living space, and amenities, or scrape a specific Immowelt search-results URL.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
modestringrequiredHow to find listings.
citystringoptionalGerman city or town name, e.g. `Berlin`, `München`, `Hamburg`, `Köln`, `Frankfurt am Main`.
distributionTypestringoptionalWhether to search rental or for-sale listings.
estateTypestringoptionalBroad property category to search. 'Temporary / furnished living (Wohnen auf Zeit)' is immowelt's furnished short-/mid-term rental category (spans apartments and houses) — it is rent-only, so Rent or buy is automatically switched to 'For rent' for it. The four commercial categories (Office, Retail, Storage / production, Gastronomy & hospitality) are immowelt's business real-estate ('Gewerbeimmobilien') categories. 'Agricultural / forestry land' is a separate, low-volume category (typically a handful of listings per city, since farmland/forestry parcels are rural) for both buying and (rarely) renting land- and forestry-use plots. Property sub-type / Additional features are not applied server-side for 'Temporary / furnished living', any commercial category, or 'Agricultural / forestry land' (price/rooms/area filters still apply).
estateSubTypestringoptionalOptional narrower property sub-type. Apartment sub-types only apply when Property type = Apartment; house sub-types only apply when Property type = House; plot sub-types only apply when Property type = Plot / land. Not applicable when Property type = Temporary / furnished living, any commercial category (Office, Retail, Storage / production, Gastronomy & hospitality), or Agricultural / forestry land.
minPriceintegeroptionalMinimum monthly cold rent (mieten) or purchase price (kaufen) in EUR.
maxPriceintegeroptionalMaximum monthly cold rent (mieten) or purchase price (kaufen) in EUR.
minRoomsintegeroptionalOnly listings with at least this many rooms. Set equal to Max rooms for an exact room count.
maxRoomsintegeroptionalOnly listings with at most this many rooms.
minAreaintegeroptionalDrop listings smaller than this, in square meters (living space for apartments/houses, usable floor area for commercial categories, plot size for Grundstück / Agricultural / forestry land — the latter can run into the millions of m² for large forest tracts).
maxAreaintegeroptionalDrop listings larger than this, in square meters (living space for apartments/houses, usable floor area for commercial categories, plot size for Grundstück / Agricultural / forestry land — the latter can run into the millions of m² for large forest tracts).
energyClassarrayoptionalOnly keep listings with one of the selected German energy efficiency classes (A+ = most efficient, H = least efficient). Applied client-side against the energy class immowelt.de publishes for each listing — not every listing discloses one, so this filter drops listings with no disclosed energy class.
excludeGroundFloorbooleanoptionalSkip apartments/houses located on the ground floor. Has no effect for property types that don't disclose a floor (Plot / land, commercial categories).
featuresarrayoptionalExtra amenity/feature to require (only one is applied per run — see note below, and the run's status message will say when the requested feature isn't filterable for the chosen property type). Verified reliable combinations: `Balcony / terrace`, `Garden`, and `Furnished` work for Apartment and House; `Parking space` only for House; `Fitted kitchen`, `Wheelchair accessible`, `WBS required`, `Shared flat (WG)`, `Swap apartment`, `Top floor`, and `Ground floor` only for Apartment. `Cellar / basement`, `Pool`, `Private offers only`, and `Needs renovation` are not reliably filterable by immowelt.de for any property type currently. None are supported for Plot / land, Temporary / furnished living, Agricultural / forestry land, or any commercial category.
sortBystringoptionalRe-order the returned listings. Immowelt only returns its first results page over plain HTTP, so this sorts within that page (useful when Max items is lower than the page size) rather than re-querying the whole site.
searchUrlstringoptionalA full Immowelt search-results URL, e.g. `https://www.immowelt.de/suche/mieten/wohnung/berlin/berlin-10115/ad08de8634`. Build one on immowelt.de using any filter combination, then paste it here.
maxItemsintegeroptionalHard cap on emitted records. Immowelt search-result pages return up to ~30-40 listings per query (varies by city/property type), so values above 40 have no additional effect.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/CYHgaHuFfQWHxpnpj/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
