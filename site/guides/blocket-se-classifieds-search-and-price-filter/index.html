    Blocket.se Classifieds Search & Price Filter Tool export

    Search Blocket.se by keyword across all categories, cars, electronics, or furniture, with a price range filter in SEK, and location, condition, and seller details per listing.

    This tutorial runs Blocket.se Classifieds Search & Price Filter Tool through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 6 columns its publisher puts first: title, price, location, category, condition and adUrl.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    The columns you can export

    The Actor's build declares 6 output fields in 1 dataset view ("Blocket Listings"). The export below keeps these, under the labels the publisher gave them:

    Default export columns
    FieldColumn headerWhat it holds
    titletitleListing headline

    Copy it from Console, Settings, API and Integrations.

    Choose the input

    1 field is required:

    Keep the first export small. These fields cap how many results a run collects, and so what it costs:
