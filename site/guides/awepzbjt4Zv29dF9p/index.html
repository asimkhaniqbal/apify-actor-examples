Use Twitch Live Stream, Channel & VOD Metadata Extractor with Python

Get Twitch top live streams, channel profiles, category directories, VOD metadata and clip details, or resolve any twitch.tv URL into structured data.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
modestringrequiredWhat to fetch.
searchQuerystringoptionalFree-text query for `mode=search` — matches channels, categories, and videos.
searchTypestringoptionalRestrict search results to one index. `all` returns channels, categories, and videos.
channelNamestringoptionalTwitch channel login or channel URL, e.g. `lirik` or `https://www.twitch.tv/lirik`.
channelNamesarrayoptionalBatch channel logins or channel URLs. Duplicates and the single `channelName` are merged.
categorySlugstringoptionalCategory slug (`just-chatting`), exact name (`Just Chatting`), or directory URL.
videoIdstringoptionalTwitch VOD ID or VOD URL, e.g. `2766365638`.
videoIdsarrayoptionalBatch VOD IDs or VOD URLs. Duplicates and the single `videoId` are merged.
clipSlugstringoptionalTwitch clip slug or clip URL, e.g. `AcceptablePleasantAuberginePanicVis-EVdxDQ1vsQAQZpBS`.
clipSlugsarrayoptionalBatch clip slugs or clip URLs. Duplicates and the single `clipSlug` are merged.
twitchUrlsarrayoptionalChannel, VOD, clip, or category URLs. Category and channel `/videos` and `/clips` tabs are supported.
languagestringoptionalFilter live streams, VODs, and clips to one broadcast language. Leave on `(any)` for no filter.
streamSortstringoptionalSort live streams by viewers (high to low or low to high), recently started, or recommended.
streamTagsarrayoptionalOnly live streams carrying all of these freeform tags, e.g. `English`, `DropsEnabled`, `NoBackseating`.
streamTypestringoptionalRestrict channel or category VODs to one broadcast type. Leave blank for all types.
videoSortstringoptionalSort channel or category VODs by publish time or view count.
clipPeriodstringoptionalTime window over which clips were created.
clipSortstringoptionalSort clips by views or trending score.
includeChannelClipsbooleanoptionalAlso fetch and emit top clips for each channel.
includeChannelVideosbooleanoptionalAlso fetch and emit recent VODs for each channel.
minViewersCountintegeroptionalDrop live streams (and categories) below this viewer count.
minViewCountintegeroptionalDrop VODs and clips below this total view count.
minFollowersCountintegeroptionalDrop channels and live streams below this follower count. VODs and clips are unaffected.
maxFollowersCountintegeroptionalDrop channels and live streams above this follower count. Useful for finding smaller creators.
onlyLivebooleanoptionalDrop channel profile records for channels that are not live right now. Their VODs and clips are still returned.
containsKeywordstringoptionalCase-insensitive substring filter on stream, VOD, and clip titles.
maxItemsintegeroptionalHard cap on emitted records. Twitch source caps still apply (e.g. about 1,000 clips per category).

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/awepzbjt4Zv29dF9p/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
