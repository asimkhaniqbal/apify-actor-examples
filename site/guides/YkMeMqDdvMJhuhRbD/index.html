Use Yahoo News Trending, Category & Keyword Feed by Region with Python

Get Yahoo News trending top stories, category feeds, or keyword-filtered headlines across six regional editions, with source, publish date, image, and category for each article.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

  "region": "us",

    "Trump"
  ]

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredScraping mode: search by keyword, browse news categories, or get trending top stories.
regionstringoptionalYahoo News regional edition to scrape. Each region publishes a different subset of category feeds — see the Categories field for what's available once you pick a region.
searchQueriesarrayoptionalOne or more keywords to search for (required for search mode). Articles from all of the selected region's category feeds are filtered by these keywords. E.g. 'AI', 'climate change', 'Apple iPhone'.
categoriesarrayoptionalOne or more Yahoo News categories to scrape (required for browseCategory mode). Availability depends on the selected Region: US supports all 11; UK/Canada support Top Stories, World, Finance, Sports; Australia supports Top Stories, World; Singapore supports Top Stories, World, Sports; Japan supports Top Stories, Domestic, World, Business, Entertainment, Sports, IT, Science, Local. Categories not available for the chosen region are ignored with a warning.
maxItemsintegeroptionalMaximum total articles to return across all queries or categories (1–1000).
keywordstringoptionalOptional: only return articles whose title or summary contains this keyword (case-insensitive).
sourceFilterstringoptionalOptional: only return articles from sources whose name contains this string (case-insensitive). E.g. 'Reuters', 'AP', 'BBC'.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/YkMeMqDdvMJhuhRbD/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
