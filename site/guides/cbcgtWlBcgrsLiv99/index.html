Use Google Maps Business Finder with Hours, Ratings & Location with Python

Find public Google Maps businesses by search term or place URL and get name, address, phone, website, category, rating, review count, hours and coordinates.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringoptionalSearch mode uses a text query; placeUrls mode scrapes specific Maps URLs; placeIds mode resolves canonical ChIJ Place IDs through Google's public URL API.
searchQuerystringoptionalWhat to search for on Google Maps. Include location in the query for best results (e.g., 'coffee shop in New York'). Used when mode is 'search'.
locationstringoptionalOptional location to append to the search query (e.g., 'Los Angeles, CA'). Leave blank if location is already in the search query.
placeUrlsarrayoptionalList of Google Maps place URLs to scrape directly. Used when mode is 'placeUrls'. Each URL should be a full Google Maps place URL.
placeIdsarrayoptionalCanonical Google Place IDs beginning with ChIJ. The actor resolves them anonymously through Google's public Maps URL API.
maxResultsintegeroptionalRequested number of places to collect **per search**. With a batch of search terms or locations, every search gets its own allowance, so one busy term cannot use up the others. Records stop when the public feed ends, this ceiling is reached for that search, or the bounded runtime deadline expires.
languagestringoptionalLanguage for Google Maps interface and results.
proxyConfigurationobjectoptionalProxy settings for the scraper. Using Apify Proxy is recommended for reliable results.
searchTermsarrayoptionalRun several search terms in one go, e.g. ["coffee shops", "dentists"]. Used with mode = search. Each term is searched in every location you provide, and every search gets its own maxResults allowance.
locationsarrayoptionalRun the search in several places in one go, e.g. ["New York, NY", "Austin, TX"]. Used with mode = search. Each term is searched in each location.
minRatingnumberoptionalOnly keep businesses rated at or above this value. Leave empty to keep every rating. A business with no published rating does not satisfy a minimum, so it is skipped.
maxRatingnumberoptionalOnly keep businesses rated at or below this value. Useful for finding under-served or low-rated prospects.
minReviewsintegeroptionalOnly keep businesses with at least this many reviews. Use it to filter out brand-new listings with almost no history.
maxReviewsintegeroptionalOnly keep businesses with at most this many reviews. Useful for finding smaller independent businesses.
openNowbooleanoptionalOnly keep businesses Google currently shows as open.
hasWebsitebooleanoptionalOnly keep businesses that publish a website on their Google Maps listing.
hasPhonebooleanoptionalOnly keep businesses that publish a phone number on their Google Maps listing.
nameFilterstringoptionalOnly keep businesses whose name contains this text, for example "pizza" or "Starbucks".
includeClosedbooleanoptionalWhen off, businesses Google marks as permanently closed are skipped.
excludeCategoriesarrayoptionalSkip businesses whose category contains any of these words, for example ["hotel", "casino"].

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/cbcgtWlBcgrsLiv99/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
