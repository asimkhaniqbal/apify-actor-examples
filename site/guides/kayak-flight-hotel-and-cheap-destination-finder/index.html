    Kayak Flight, Hotel & Cheap Destination Finder: export to CSV, Excel or JSON

    Searches Kayak for flight prices between two cities, cheap destinations from an origin airport, or hotel rates for a stay, with airline, price, duration and booking link per result.

    This tutorial runs Kayak Flight, Hotel & Cheap Destination Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: recordType, flightId, hotelName, origin, destination, destinationCountry, departDate and returnDate.

    What people export it for

    • Fare comparison: compare airlines and providers for a route and dates.
    • Travel inspiration: find cheap destinations from your home airport under a budget.
    • Hotel rate checks: pull nightly and total rates with ratings and amenities.
    • Price tracking: schedule the same search and store each run's dataset.
    • URL re-scraping: turn saved Kayak search links into structured data.

    Fix common problems

    Why do some records say accessMethod: flight-routes?

    Kayak blocked the live search for that route. The record comes from Kayak's flight-route page and is a snapshot, so treat its price as indicative and re-run later for a live fare.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
