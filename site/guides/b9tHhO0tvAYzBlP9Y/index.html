Use New Jersey Business Registry Lookup & Name Checker with Python

Look up New Jersey registered businesses by name, keyword or entity ID, and check whether a candidate business name is available for a new filing. Returns entity ID, entity type, city and incorporation date.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "businessName": "Amazon",
  "cityFilter": "",
  "entityIds": [],
  "entityTypeContains": "",
  "keywords": [
    "Amazon"
  ],
  "maxItems": 25,
  "mode": "byName",
  "proxyConfiguration": {
    "useApifyProxy": true
  }
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredWhat to fetch.
businessNamestringoptionalFor mode=byName: name or partial name to search for, e.g. `Amazon` (contains match). For mode=availability: a candidate name WITHOUT a business designator (no `LLC`, `Inc`, `Corp`, etc. -- the source rejects those) to check whether it conflicts with an already-registered name.
keywordsarrayoptional1-5 keywords; results contain ALL of them (in any order) somewhere in the registered business name, e.g. `["Amazon", "LLC"]`.
entityIdsarrayoptionalExact 10-digit New Jersey entity ID(s) to look up, e.g. `0450567823`.
entityTypeContainsstringoptionalCase-insensitive substring filter against the full entity type description, e.g. `Limited Liability` or `Corporation`. Leave blank for no filter.
cityFilterstringoptionalExact (case-insensitive) match against the registered business's on-file city. Leave blank for no filter.
maxItemsintegeroptionalHard cap on emitted records. The source's registered-business searches return all matches in a single response (no server pagination); this cap is applied client-side.
proxyConfigurationobjectoptionalUses Apify's free datacenter (AUTO) proxy group to get a fresh IP if a request is rate-limited by the source. Residential proxy is never used by this actor.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/b9tHhO0tvAYzBlP9Y/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
