Use Allegro.pl Listings by Search, Category or URL with Python

Find Allegro.pl products by keyword search, category page, or direct offer URL, with price, seller rating, condition, shipping, and rating details, filterable by price range and free shipping.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

sortBystringoptionalOrder of results for search, category, seller and product-offer listings.
conditionstringoptionalFilter listings by item condition.
minPriceintegeroptionalLowest price in PLN. Leave empty for no minimum.
maxPriceintegeroptionalHighest price in PLN. Leave empty for no maximum.
freeShippingOnlybooleanoptionalUse Allegro's free-delivery (Smart!) filter for listing modes.
buyNowOnlybooleanoptionalExclude auctions and keep only offers you can buy immediately.
superSellerOnlybooleanoptionalKeep only offers from Allegro Super Sellers.
includeSponsoredbooleanoptionalInclude sponsored placements in listing results. Turn off for organic results only.
includeDetailsbooleanoptionalOpen each offer from search, category, seller and product-offer listings to add stock, GTIN, full specs, company identity, warranty and returns. Slower and uses more requests.
maxItemsintegeroptionalMaximum records to return. Listing modes cap each source at 6,000 offers (100 pages).
maxReviewsPerProductintegeroptionalMaximum reviews to collect for each product in reviews mode.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/yTGdPYNIY8yiaWGK5/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
