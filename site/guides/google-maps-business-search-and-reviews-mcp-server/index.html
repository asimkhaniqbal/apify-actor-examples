    Search Google Maps businesses or pull reviews for a specific place through one actor, usable as a normal run or as an MCP tool for AI agents. Returns ratings, contact info, hours and flattened reviews.

    Fix common problems

    Why might a run return fewer records than requested?

    Google's own public result set and review surface set the ceiling. The actor returns everything it can observe and never pads the count.

    Is a proxy required?

    No. Batch runs go direct first; if Google serves a challenge, the actor retries through the automatic Apify proxy pool. MCP tool calls are direct-only and return a retryable error object if Google serves a challenge. You can leave proxyConfiguration empty.

    Why is a field missing from one record?

    Only fields Google publishes for that record are included. Empty values are removed rather than emitted as null.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
