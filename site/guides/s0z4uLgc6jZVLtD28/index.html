Use Jobs.ch Swiss Job Listings by Region & Industry with Python

Scrape job listings from jobs.ch, Switzerland's largest job board. Search by keyword or browse by canton, industry, occupational field, or contract type, with filters for workload and seniority. Returns title, company, location, and job URL.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to fetch. `search` runs a free-text keyword search (leave the query blank to browse every job). `byRegion` browses a Swiss canton/language-region. `byIndustry` browses an industry/category. `byEmploymentType` browses a contract type. `byCategory` browses an occupational field / job function.
searchQuerystringoptionalFree-text keyword to search job titles/descriptions (mode=search). Leave blank to browse all jobs matching the other filters. Combinable with every filter below in any mode.
regionstringoptionalBrowse jobs by Swiss canton / language-region (required for mode=byRegion; optional filter in every other mode).
locationstringoptionalOptional free-text refinement by city or place name (e.g. "Zürich", "Geneva", "Basel"). Combinable with `region`.
industrystringoptionalBrowse jobs by industry sector (required for mode=byIndustry; optional filter in every other mode).
employmentTypestringoptionalBrowse/filter by contract type (required for mode=byEmploymentType; optional filter in every other mode).
employmentGradeMinintegeroptionalLower bound of the workload/employment-grade range, in percent (e.g. 80 for an 80-100% role).
employmentGradeMaxintegeroptionalUpper bound of the workload/employment-grade range, in percent.
positionstringoptionalOptional filter by seniority/position level.
categorystringoptionalBrowse/filter by occupational field — the job's function (e.g. IT, Sales, Finance), distinct from `industry` (the employer's business sector). Required for mode=byCategory; optional filter in every other mode.
publishedSincestringoptionalOptional filter to only return jobs first published within this time window.
languageSkillstringoptionalOptional filter to only return jobs that require this working language.
companySegmentstringoptionalOptional filter by employer size/segment.
includeDescriptionbooleanoptionalWhen enabled, fetches each job's detail page to add the full job description, benefits, required skills, apply URL and salary (only when the employer discloses it — most Swiss listings do not). This roughly doubles the number of requests per run.
localestringoptionalLanguage of the jobs.ch site to scrape from — affects the language of translated fields (title/company are unaffected; job counts and set are identical across locales).
maxItemsintegeroptionalMaximum number of job listings to return. jobs.ch returns 20 listings per page.
proxyConfigurationobjectoptionalOptional. jobs.ch is a plain public site that normally does not require a proxy; this is used only as an automatic fallback if the datacenter IP gets temporarily rate-limited.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/s0z4uLgc6jZVLtD28/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
