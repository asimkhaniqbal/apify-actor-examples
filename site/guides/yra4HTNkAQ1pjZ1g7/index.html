FieldTypeRequiredDescription
modestringrequiredWhat to run. `search` searches Fiverr by keyword or browses search/category URLs. `gigDetails` fetches full details for gig URLs. `sellerProfiles` fetches seller profiles. `sitemapDirectory` lists entries from Fiverr's public sitemaps. Legacy mode names are accepted and mapped automatically.
searchQueriesarrayoptionalKeywords to search on Fiverr (mode=search), e.g. `logo design` or `voice over`. One search is run per query.
searchUrlsarrayoptionalFiverr search or category URLs to browse (mode=search), e.g. `https://www.fiverr.com/search/gigs?query=logo%20design` or a `/categories/...` URL. Filters already in the URL are preserved.
gigUrlsarrayoptionalFull Fiverr gig URLs to fetch, e.g. `https://www.fiverr.com/username/gig-slug` (mode=gigDetails).
sellerUrlsarrayoptionalFiverr seller usernames or profile URLs, e.g. `michael7878` or `https://www.fiverr.com/michael7878` (mode=sellerProfiles).
sitemapTypestringoptionalWhich Fiverr sitemap directory to list (mode=sitemapDirectory).
searchKeywordstringoptionalOnly keep sitemap entries whose URL or slug contains this keyword (mode=sitemapDirectory). Also filters gig titles in detail and search modes when set. Case-insensitive. Leave empty for no filtering.
maxShardsintegeroptionalNumber of sitemap shard files to scan for gigs (up to 7), sellers (up to 6) or tags (up to 2). Values above the available shard count are capped.
categoryLevelstringoptionalOnly keep category entries at this level (mode=sitemapDirectory, sitemapType=categories).
ideaTypestringoptionalOnly keep Logo Maker entries of this type (mode=sitemapDirectory, sitemapType=logomakerIdeas).
categorystringoptionalOnly keep results in this Fiverr category. Applies to category directory entries, and to gig details and enriched search results when the page reports that category slug. Leave empty for all categories.
sortBystringoptionalSort live search results (mode=search).
sellerLevelsarrayoptionalKeep only these seller levels (mode=search). Values: `top_rated_seller`, `level_two_seller`, `level_one_seller`, `na` (new seller). Leave empty for all levels.
sellerLanguagesarrayoptionalKeep only sellers who speak these languages (mode=search), using ISO codes such as `en`, `es`, `de`, `fr`, `hi`, `ur`.
sellerCountriesarrayoptionalKeep only sellers living in these countries (mode=search), using ISO-2 codes such as `US`, `GB`, `DE`, `PK`, `IN`.
deliveryTimestringoptionalKeep only gigs with this delivery speed (mode=search).
proOnlybooleanoptionalKeep only Fiverr Pro gigs (mode=search).
onlineOnlybooleanoptionalKeep only sellers who are online now (mode=search).
agencyOnlybooleanoptionalKeep only agency-run gigs (mode=search).
hourlyOnlybooleanoptionalKeep only gigs that offer an hourly rate (mode=search).
facetsarrayoptionalOptional category-specific filters for search, as `key:value` strings, e.g. `style:flat_minimalist` or `file_format:svg`. Unknown values are skipped with a warning.
minRatingnumberoptionalOnly keep gigs or sellers with an average rating at or above this value (0-5).
minReviewsintegeroptionalOnly keep gigs or sellers with at least this many reviews.
minPriceUsdnumberoptionalOnly keep gigs whose lowest package price is at or above this amount (USD).
maxPriceUsdnumberoptionalOnly keep gigs whose lowest package price is at or below this amount (USD).
includeGigDetailsbooleanoptionalFetch each search result's gig page for packages, reviews, FAQ and the full seller card (mode=search). Also preserves the legacy discoverAndFetchDetails path.
includePackagesbooleanoptionalInclude package pricing, delivery, revisions, features and paid extras on gig details.
includeFaqbooleanoptionalInclude the gig's public FAQ list when present.
includeSellerGigsbooleanoptionalInclude the seller's gig list on seller profile records.
includeSellerReviewsbooleanoptionalInclude the seller's latest reviews and rating breakdown on seller profile records.
includeMarketSummarybooleanoptionalEmit one summary row per search query with result count, price range, seller-level mix and top seller countries.
maxPagesPerQueryintegeroptionalMaximum result pages to read per search query or URL. Fiverr may stop earlier; this is an upper bound.
maxItemsintegeroptionalHard cap on emitted records.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/yra4HTNkAQ1pjZ1g7/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
