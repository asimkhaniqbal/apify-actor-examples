    Odysee Video Search by Keyword, Channel & Tag: export to CSV, Excel or JSON

    Search Odysee by keyword, browse a creator's channel, or filter by content tag, and get each video's title, description, duration, tags, view count, and publish date.

    Fix common problems

    Why is views missing on some records?

    It is only missing if Odysee's counter endpoint fails for that item or you turned includeStats off. A value of 0 means Odysee reported zero tracked views.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
