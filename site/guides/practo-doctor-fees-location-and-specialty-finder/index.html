    Practo Doctor Fees, Location & Specialty Finder: export to CSV, Excel or JSON

    Search Practo.com doctor listings by Indian city and medical specialty, and get physician name, clinic name and address, geo-coordinates, consultation fee and profile link for each doctor.

    This tutorial runs Practo Doctor Fees, Location & Specialty Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: name, displaySpecialty, city, locality, clinicName, consultationFeeValue, experienceYears and nextAvailableAt.

    Get an API token

    Copy it from Console, Settings, API and Integrations.

    Choose the input

    2 fields are required:

    • city: Indian city whose Practo doctor directory you want to search.
    • specialty: Doctor specialty to search for in the chosen city.
