    Fix common problems

    Do I need a Trustpilot account, cookies, or a proxy?

    No. The actor reads public Trustpilot pages and handles the site's connection check itself. You do not configure a proxy.

    Why did I get fewer reviews than I asked for?

    Either the company has fewer reviews than requested, or it has more than the public views can expose. The status message says which. For big brands, request up to 1,000 to use the star slices efficiently.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
