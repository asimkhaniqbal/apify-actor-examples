Use Pinterest Pin Comments & Activity Extractor with Python

Pull public comments, replies, reactions, and Tried It activity for one or more Pinterest Pins, along with each Pin's title, creator, board, and engagement summary.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "commentSort": "source",
  "domain": "www.pinterest.com",
  "includePinSummary": true,
  "includeReplies": false,
  "maxActivity": 3,
  "maxComments": 3,
  "maxRepliesPerComment": 0,
  "minHelpfulCount": 0,
  "minLikeCount": 0,
  "mode": "commentsAndActivity",
  "sinceDate": "",
  "untilDate": "",
  "urls": [
    "https://www.pinterest.com/pin/142567144448888376/"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringoptionalChoose comments with replies, Tried It activity, both, or only the Pin summary.
urlsarrayoptionalOne or more numeric Pinterest Pin links or IDs, e.g. https://www.pinterest.com/pin/142567144448888376/. Legacy pinUrls and startUrls inputs are still accepted in code.
domainstringoptionalRegional Pinterest site used for every request. Use the region shown in the Pin link.
maxCommentsintegeroptionalTop-level comments to collect per Pin; replies are counted separately. Legacy limit input is still accepted in code.
includeRepliesbooleanoptionalFetch public replies for comments that have them.
maxRepliesPerCommentintegeroptionalReply rows to collect for each top-level comment. Set to 0 to skip replies.
maxActivityintegeroptionalTried It and other public activity rows to collect per Pin.
includePinSummarybooleanoptionalEmit one pinCommentsSummary row with the Pin, creator, board, media, commerce and engagement context.
commentSortstringoptionalSource keeps Pinterest's ranking; newest and oldest sort the fetched comments by their published date.
minLikeCountintegeroptionalDrop comment, reply and activity rows whose published like count is lower. Rows without a published count are kept.
minHelpfulCountintegeroptionalDrop comment, reply and activity rows whose published helpful count is lower. Rows without a published count are kept.
sinceDatestringoptionalOptional inclusive date filter (YYYY-MM-DD) for comments, replies and activity. Leave empty for no lower bound.
untilDatestringoptionalOptional inclusive date filter (YYYY-MM-DD) for comments, replies and activity. Leave empty for no upper bound.
proxyConfigurationobjectoptionalOptional Apify proxy override. The actor works directly and falls back to the automatic Apify proxy without user setup.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/QFDd89Ia1Lh4fLqIg/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

One Pin summary row per accessible Pin plus public comment, reply and Tried It activity rows selected by the input mode.

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
