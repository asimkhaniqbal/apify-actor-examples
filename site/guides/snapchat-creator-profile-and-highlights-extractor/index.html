Use Snapchat Creator Profile & Highlights Extractor with Python

Turn Snapchat usernames into structured profile records with bio, subscriber count, verification status, story highlights, Spotlight videos, AR lenses, and related creators.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "includeActiveStory": false,
  "includeComments": false,
  "includeHighlightSnaps": false,
  "includeLenses": false,
  "includeSpotlightMeta": false,
  "usernames": [
    "brentrivera"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
usernamesarrayrequiredSnapchat usernames or profile URLs. Accepts brentrivera, @brentrivera, https://www.snapchat.com/add/brentrivera and https://www.snapchat.com/@brentrivera.
includeLensesbooleanoptionalInclude lenses published by the profile.
includeSpotlightMetabooleanoptionalMerge each Spotlight's view, share, comment, boost and recommend counts, caption, hashtags and AI metadata into the record.
includeActiveStorybooleanoptionalInclude the currently live public story snaps with media and preview URLs.
includeHighlightSnapsbooleanoptionalAdd the full snap list to each curated highlight. Can make records much larger.
includeCommentsbooleanoptionalInclude the public comment threads Snapchat embeds on the profile page. Full thread pagination is a separate actor.
maxRelatedAccountsintegeroptionalCap the related accounts listed inside each record. 0 excludes them. Leave blank for no limit.
maxHighlightsPerUserintegeroptionalCap curated highlights and Spotlight slots per profile. 0 excludes both. Leave blank for no limit.
maxSnapsPerHighlightintegeroptionalUsed only when includeHighlightSnaps is on. 0 means no limit; 1-500 caps each highlight.
maxItemsintegeroptionalStop after this many profile records. Leave blank for no cap.
relatedProfilesLimitintegeroptionalAfter the supplied profiles, scrape up to this many unique accounts from their related lists (one hop only). 0 disables expansion.
proxyConfigurationobjectoptionalOptional. Public Snapchat profiles work without a proxy.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/FpzhExyefgz9gLqBd/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

One record per Snapchat profile with identity fields, highlight and Spotlight media, contacts, engagement totals, related accounts and an explicit status for personal or not-found accounts.

Questions before you run

Which inputs are required?

The published required fields are usernames

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
