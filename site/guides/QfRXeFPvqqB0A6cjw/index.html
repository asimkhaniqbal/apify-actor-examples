Use Shopee Shop Profile, Item & Category Scraper with Python

Collect Shopee shop profiles with ratings and followers, shop product feeds, full item detail pages, and curated category listings across six Southeast Asian markets.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "includeChildren": false,
  "includeFeaturedItem": false,
  "includeShopCategories": false,
  "market": "MY",
  "maxItems": 1,
  "mode": "shopProfile",
  "shopUrl": "watsons.my"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredWhat to collect.
marketstringoptionalShopee market. Used for categoryTree, mallShops and bare IDs; a full URL keeps its own market.
shopUrlstringoptionalShop username, numeric shop ID, /shop/<id> path, or full Shopee shop URL (mode=shopProfile).
itemUrlstringoptionalFull item URL, -i.<shopid>.<itemid>, shopid.itemid, or /product/<shopid>/<itemid> (mode=itemByUrl).
categoryIdstringoptionalNumeric category ID from categoryTree mode, or a category name. Leave blank for the whole tree (mode=categoryTree).
includeChildrenbooleanoptionalInclude child categories (mode=categoryTree). When categoryId is blank, false returns only top-level categories.
includeShopCategoriesbooleanoptionalAdd the shop's own category list to the shop record (mode=shopProfile).
includeFeaturedItembooleanoptionalAdd the featured product card published on the shop page; on itemByUrl, merge it when the item matches.
maxItemsintegeroptionalHard cap on emitted records. Use 500 for a complete category tree.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/QfRXeFPvqqB0A6cjw/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
