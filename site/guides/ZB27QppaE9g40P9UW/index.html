Use Yandex News Story Clusters Across Russia & the CIS with Python

Search or browse Yandex News and get story clusters with every linked article, topic tags, source names and publication dates across Russian and CIS editions.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to scrape. `searchNews` searches keywords, `browseCategory` reads a rubric feed, `topStories` reads the homepage sections, and `byStoryUrls` resolves specific story clusters.
searchQueriesarrayoptionalOne or more keywords or phrases (mode=searchNews). Russian and English queries are supported. The daily-test prefill uses one query.
categorystringoptionalRubric to browse (mode=browseCategory). `all` reads all 16 rubrics in one run.
storyUrlsarrayoptionalDzen News story or instory URLs, or bare cluster UUIDs (mode=byStoryUrls). A bare numeric persistent ID is not a valid cluster URL.
maxStoriesintegeroptionalMaximum number of story clusters to return across the whole run. Yandex search depth varies by query.
sortOrderstringoptionalOrder of the returned search clusters (mode=searchNews). Yandex search itself is relevance-ranked; these options sort the returned set.
timeRangestringoptionalKeep clusters published in this window (mode=searchNews). Applied to the results Yandex returns. A custom date range overrides this field.
publishedAfterstringoptionalInclusive start date in YYYY-MM-DD format (mode=searchNews). Leave blank for no lower bound.
publishedBeforestringoptionalInclusive end date in YYYY-MM-DD format (mode=searchNews). Leave blank for no upper bound.
includeDomainsarrayoptionalKeep a cluster when at least one linked article is from one of these domains (for example `rbc.ru`).
excludeDomainsarrayoptionalDrop a cluster when any linked article is from one of these domains.
includePublishersarrayoptionalKeep a cluster when any linked source name contains one of these values (case-insensitive).
excludePublishersarrayoptionalDrop a cluster when any linked source name contains one of these values (case-insensitive).
includeKeywordsarrayoptionalKeep a cluster when its headline, summary or an article headline/summary contains at least one of these values.
excludeKeywordsarrayoptionalDrop a cluster when its headline, summary or an article headline/summary contains any of these values.
includeDetailsbooleanoptionalFetch the cluster page for topic labels, source-reported counts, images, country/region, comments and likes.
includeArticlesbooleanoptionalEmit one record per linked article in every cluster. Turn this off for a story-only dataset.
maxArticlesPerStoryintegeroptionalMaximum article records and article pages fetched per cluster. Yandex returns 100 articles per page.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/ZB27QppaE9g40P9UW/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
