Use Yandex News Story Clusters Across Russia & the CIS with Python

Search or browse Yandex News and get story clusters with every linked article, topic tags, source names and publication dates across Russian and CIS editions.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
modestringrequiredScraping mode: search by keyword, browse a category, or get trending stories.
searchQueriesarrayoptionalOne or more search queries (required for searchNews mode). E.g. 'Яндекс', 'Ukraine', 'Apple'.
categoryUrlsarrayoptionalYandex News category page URLs (required for browseCategory mode). Use dzen.ru/news/rubric/* URLs. Confirmed working slugs: computers, politics, world, sport, business, science, society, culture, auto, health. Legacy news.yandex.ru/*.html URLs are auto-converted.
domainstringoptionalRegional Yandex News edition to scrape (via dzen.ru).
maxStoriesintegeroptionalMaximum number of story clusters to scrape per query or category (1–200).
sortOrderstringoptionalSort order for search and category results.
languagestringoptionalContent language filter. Sets Accept-Language header and Yandex language preference.
proxyConfigurationobjectoptionalRequired. Yandex/Dzen only serves Russian IPs. Use Apify Residential proxy with country=RU for reliable access.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/ZB27QppaE9g40P9UW/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
