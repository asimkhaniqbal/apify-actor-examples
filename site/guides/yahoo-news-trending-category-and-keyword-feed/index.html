    Fix common problems

    Why did US category results used to be empty?

    Yahoo retired the old news.yahoo.com/rss/<section> feeds in 2026. The revamp reads the live www.yahoo.com/news/<section> pages instead, so categories work again.

    Why does search sometimes return fewer than maxItems?

    Yahoo's news search index exposes a finite number of results per query. The actor also drops duplicates and non-article cards, so the final count can be below the requested maximum. The status message reports the real count.

    Why do a few search results point outside Yahoo?

    Yahoo News search occasionally links straight to a publisher instead of a Yahoo-hosted copy. Those records keep the search-card fields; detail enrichment only opens Yahoo-hosted article pages.

    More from the publisher:

    • Why are some fields absent on some records?

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
