    Fix common problems

    Do I need a proxy or Google account?

    No. The actor handles its own access and needs no cookies, logins, API keys or proxy configuration.

    Why is resultsTotal sometimes a small number?

    It is Google's own estimate on that specific render. It fluctuates between pages and query types, so use it as a rough signal rather than a stable search-volume metric.

    Why are paidResults, knowledgePanel, localPack or topStories often empty?

    Google only renders those features for some queries. Ads are sparse even on commercial terms; local packs need local intent; knowledge panels need an entity. Their absence is normal, not an extraction failure.

    More from the publisher:

    • Why is aiOverview empty?
    • Why did site: return fewer results than expected?

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
