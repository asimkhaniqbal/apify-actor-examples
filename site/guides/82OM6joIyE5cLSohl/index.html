Use TikTok Keyword Search & Discovery Scraper with Python

Search TikTok by keyword or phrase and get matching videos with engagement stats, author profiles, music metadata, hashtags, and location tags, with optional discovery expansion for more results.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "enableExpansion": false,
  "excludeAds": false,
  "expansionSources": [
    "suggestions",
    "hashtags",
    "sounds"

  "includeHashtagMetadata": true,
  "maxExpansionQueriesPerSeed": 3,
  "maxResultsPerQuery": 3,

FieldTypeRequiredDescription
searchTypestringrequiredVideos: keyword video search. Photos: slideshow/photo search. Hashtags: hashtag metadata plus its top videos (uses the Hashtags field).
queriesarrayoptionalKeywords or phrases to search for (searchType=videos or photos). Each query is searched independently.
hashtagsarrayoptionalHashtags to look up (searchType=hashtags). The # is optional, e.g. coffee or #coffee.
maxResultsPerQueryintegeroptionalMaximum posts to collect per query or hashtag, before filters. TikTok itself usually returns about 150-220 posts per query even when you ask for more. For hashtags, the metadata row is not counted against this limit.
sortBystringoptionalClient-side sort applied after collecting results. TikTok's web search does not support server-side sorting, so this only reorders the posts TikTok returned.
publishedWithinstringoptionalClient-side filter that drops posts older than the selected window, based on each post's creation time. TikTok ranks results by relevance, not date, so a narrow window can return fewer posts than requested; the actor scans up to 5x the requested count (capped at 500) to fill it.
minDurationSecondsintegeroptionalDrop videos shorter than this. Leave blank for no minimum.
maxDurationSecondsintegeroptionalDrop videos longer than this. Leave blank for no maximum.
excludeAdsbooleanoptionalDrop posts TikTok flags as paid advertisements.
minLikeCountintegeroptionalDrop posts with fewer likes than this. Leave blank for no minimum.
minViewCountintegeroptionalDrop posts with fewer plays/views than this. Leave blank for no minimum.
uniqueAuthorsbooleanoptionalKeep at most one post per creator, so the results read like a creator shortlist. When a sort is selected, the top-ranked post from each creator is kept.
maxPostsPerAuthorintegeroptionalOptional cap on how many posts one creator may contribute. Ignored when One Post Per Author is on.
enableExpansionbooleanoptionalAfter each keyword search, run extra searches derived from its own results: related searches, its top hashtags and its most-reused sound. Increases run time and the number of posts found. Videos only.
expansionSourcesarrayoptionalWhich discovery sources to use when expansion is on. All three can be combined.
maxExpansionQueriesPerSeedintegeroptionalMaximum number of extra searches to run per keyword when expansion is on. Each one costs roughly as much run time as the original search.
includeHashtagMetadatabooleanoptionalFor hashtag searches: emit a metadata row with the hashtag's post count, view count, description and images. Also attaches metadata to hashtag-expansion posts when expansion is on.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/82OM6joIyE5cLSohl/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.
