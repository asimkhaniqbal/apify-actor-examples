Use Glassdoor Job Listings Salary & Rating Scraper with Python

Pull Glassdoor job listings by keyword and location or from a single company's jobs page, with salary estimates, employer ratings, Easy Apply status, and extracted skills per role.

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredSearch by keyword and location, or scrape specific Glassdoor URLs and job IDs.
searchQueriesarrayoptionalJob titles, skills, or company names to search for (mode=search). One search is run per query.
locationstringoptionalCity, state, or country, e.g. 'New York, NY', 'London', 'Berlin'. Leave empty for the selected country's whole market.
countrystringoptionalWhich Glassdoor country site to search.
startUrlsarrayoptionalGlassdoor search, job, or company jobs page URLs. Job URLs return one detailed record each.
jobIdsarrayoptionalGlassdoor job listing IDs to refresh directly, e.g. '1010224897915'. The country site decides the domain.
postedWithinstringoptionalOnly include jobs posted within this window.
employmentTypestringoptionalFilter by the type of employment.
senioritystringoptionalFilter by the role's seniority level.
minRatingstringoptionalOnly include employers rated at least this well on Glassdoor.
minSalaryintegeroptionalOnly include jobs paying at least this much per year, in the country's currency. Leave empty for no minimum.
maxSalaryintegeroptionalOnly include jobs paying at most this much per year, in the country's currency. Leave empty for no maximum.
easyApplyOnlybooleanoptionalOnly return jobs you can apply to directly on Glassdoor.
remoteOnlybooleanoptionalOnly return remote jobs. Remote-only searches run market-wide because Glassdoor rejects city-scoped remote filters.
companySizestringoptionalFilter by the employer's employee-count band.
industrystringoptionalFilter by the employer's industry.
jobFunctionstringoptionalNarrow the search to one kind of role.
radiusstringoptionalHow far around the location to search. Only used when a location is set.
sortBystringoptionalOrder of the results. Sponsored listings may stay pinned at the top.
maxItemsintegeroptionalMaximum number of job listings to return across all queries and slices.
includeDetailsbooleanoptionalFetch each job page for the full description, exact dates, benefits, requirements, coordinates, apply URL, and company profile. Slower and uses more requests.
maximizeCoveragebooleanoptionalRun additional searches split by date, job type, rating, and salary to get past a single search's depth limit.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/DSfF2NaAOpJo6ZUsx/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
