Use General Chiropractic Council Register Scraper with Python

Search the General Chiropractic Council's public register of UK-regulated chiropractors by name, postcode radius, or registration number, with practice addresses, contact details, qualifications, and regulatory history.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "fetchDetails": false,
  "includeNonPractising": false,
  "includeRemovedSuspended": false,
  "maxItems": 3,
  "mode": "search",
  "name": "Smith",
  "registrationNumbers": [
    "01913"
  ]
}

FieldTypeRequiredDescription
modestringrequiredChoose how to query the register.
namestringoptionalFull or partial name, e.g. `Smith` or `Julia Smith`. Use at least 3 characters. When combined with a location, the name is applied as a filter inside that area.
postcodestringoptionalUK postcode such as `SW1A 1AA`. Results are returned nearest-first within the site's 30-mile radius.
locationstringoptionalTown, city, or UK postcode such as `Manchester`, `Edinburgh`, or `CF10 1EP`. Results are nearest-first within the site's 30-mile radius.
genderstringoptionalOnly return chiropractors of this gender. Gender is not published for removed or interim-suspended records.
registrationStatusstringoptionalOnly return records with this exact status. Non-practising and removed/suspended records are included automatically when their status is selected.
includeNonPractisingbooleanoptionalInclude chiropractors who are registered but not currently practising in the UK.
includeRemovedSuspendedbooleanoptionalInclude chiropractors who have been removed from the register or are suspended.
registeredAfterstringoptionalISO date `YYYY-MM-DD`; keeps chiropractors first registered on or after this date.
registeredBeforestringoptionalISO date `YYYY-MM-DD`; keeps chiropractors first registered on or before this date.
qualificationContainsstringoptionalCase-insensitive text filter on the qualification, e.g. `AECC`, `McTimoney`, or `Doctor of Chiropractic`.
registrationNumbersarrayoptionalExact GCC registration numbers, e.g. `01913` or `1913`. Leading zeros are added automatically.
fetchDetailsbooleanoptionalOpen each matching profile to collect gender, first-registered date, qualification, full practices, contacts, and regulatory actions. Turn off for a faster name/registration/status list.
maxItemsintegeroptionalHard cap on emitted records.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/nnU6SFiDP7MgEYLqO/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
