Use AliExpress Multi-Region Search, Store & Review Scraper with Python

Search AliExpress or fetch product, store, and review records by ID or URL across 18 regional storefronts and 42 currencies, with price, rating, and ship-from/ship-to filters.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringoptionalWhat to scrape. search: text-query results. byProduct: product detail by ID. byStore: store profile by ID. byReviews: customer reviews for product IDs. byUrl: parse any AliExpress URL (search, item, store, or feedback).
searchQuerystringoptionalFree-text search query, e.g. "phone case", "led strip", "running shoes". Required when mode=search.
productIdsarrayoptionalAliExpress numeric product IDs (e.g. 1005010155028387). Each ID becomes one fetch in byProduct, or one batch of reviews in byReviews.
storeIdsarrayoptionalAliExpress numeric store IDs from /store/{id} URLs.
urlsarrayoptionalAny mix of AliExpress URLs: search (/wholesale or /w/...), product (/item/{id}.html), store (/store/{id}), or feedback (/pc/searchEvaluation.do?productId={id}). Region is auto-detected from the host.
regionstringoptionalAliExpress regional sub-domain to query. com is the global English storefront; us is the United States storefront; the rest are language-localized variants.
currencystringoptionalISO-4217 currency code. Sent via the aep_usuc_f locale cookie; AliExpress may override it with the proxy IP's local currency. Output currencyCode reflects the actual currency returned by AliExpress. For deterministic currency, pair with useProxy and a residential proxy in the target country.
languagestringoptionalLocale that AliExpress should render text in (b_locale cookie).
sortBystringoptionalHow AliExpress should sort the search results.
priceMinintegeroptionalMinimum price (in the selected currency). Records below this are excluded.
priceMaxintegeroptionalMaximum price (in the selected currency). 0 disables the upper bound.
ratingMinnumberoptionalMinimum star rating (0–5, accepts decimals like 4.5). Records below are excluded; products with no rating are kept (the user opted into a filter, not into requiring the field).
shipFromstringoptionalISO 3166-1 alpha-2 country code of the warehouse the item ships from (CN by default).
shipTostringoptionalISO 3166-1 alpha-2 country to ship to (also drives currency / locale defaults).
maxItemsintegeroptionalHard cap on emitted records.
maxPagesintegeroptionalMaximum pagination pages per search query (60 items per page).
enrichReviewsbooleanoptionalIf true, fetch up to maxReviewsPerProduct customer reviews for every product record.
maxReviewsPerProductintegeroptionalCap on how many reviews to keep per product (when enrichReviews=true, or in mode=byReviews). 0 disables.
useProxybooleanoptionalRoute requests through Apify proxy. AliExpress is generally accessible without a proxy from datacenter IPs; enable only if you see frequent rate limits.
autoEscalateOnBlockbooleanoptionalIf a request is blocked or rate-limited, transparently switch to Apify residential proxy for retries.
proxyConfigurationobjectoptionalApify proxy configuration. Used only when useProxy is enabled.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/fViwyNdEyDapUpGXy/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
