Use AliExpress Multi-Region Search, Store & Review Scraper with Python

Search AliExpress or fetch product, store, and review records by ID or URL across 18 regional storefronts and 42 currencies, with price, rating, and ship-from/ship-to filters.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to collect. search: keyword results. byProduct: product lookup by ID or URL. byStore: store lookup. byReviews: customer reviews. byUrl: auto-detect from pasted AliExpress links.
searchQueriesarrayoptionalOne or more keywords, e.g. "phone case" or "wireless earbuds". Each query is scraped up to maxPages pages.
productIdsarrayoptionalNumeric AliExpress product IDs or item URLs. Both 1005… and 3256… ID formats are accepted.
storeIdsarrayoptionalNumeric store IDs or /store/… URLs.
urlsarrayoptionalAny mix of search, item, store and review URLs. The mode is detected per URL.
regionstringoptionalCountry used for prices, availability and the storefront locale. Global leaves the region to the requesting IP.
currencystringoptionalOptional ISO-4217 currency. Leave blank to use the region's usual currency. The currency actually returned is recorded in every record.
languagestringoptionalStorefront language and the language used to translate review text.
sortBystringoptionalHow keyword results are ordered. AliExpress does not expose a newest sort.
priceMinnumberoptionalMinimum price in the selected currency. 0 disables the lower bound.
priceMaxnumberoptionalMaximum price in the selected currency. 0 disables the upper bound.
ratingMinnumberoptionalMinimum star rating from 0 to 5. Products without a rating are skipped when a threshold is set.
shipFromstringoptionalOnly show items stocked in this country. Leave blank for any warehouse.
freeShippingOnlybooleanoptionalOnly show items advertised with free shipping.
choiceOnlybooleanoptionalOnly show AliExpress Choice items.
fourStarPlusbooleanoptionalOnly show items rated 4.0 or higher. The actor enforces the 4.0 threshold after AliExpress returns its filtered page.
includeSponsoredbooleanoptionalInclude promoted product cards; they are marked isSponsored in the output.
includeWelcomeGiftsbooleanoptionalInclude $0.00 new-shopper gift cards; they are marked isWelcomeGift and have no normal price.
maxItemsintegeroptionalHard cap on records emitted by the run.
maxPagesintegeroptionalMaximum result pages per query (60 products per page, up to 60 pages).
includeReviewsbooleanoptionalFetch customer reviews for each product (slow and adds records to the product).
maxReviewsPerProductintegeroptionalReview cap per product when reviews are fetched. 0 uses the default of 20.
reviewFilterstringoptionalWhich reviews to collect.
includeProductStatsbooleanoptionalAdd each product's average rating and total review count to review records.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/fViwyNdEyDapUpGXy/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.
