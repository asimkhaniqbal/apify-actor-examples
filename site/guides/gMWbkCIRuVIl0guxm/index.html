Use Google Maps Business Lead Finder with Email & Social Links with Python

Search Google Maps by business type and location and get back listing details enriched with email addresses and social profiles pulled from each business's own website.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "categoryFilter": [],
  "extractEmailsFromWebsite": true,
  "language": "en",
  "locationQuery": "",
  "maxContactPagesPerWebsite": 2,
  "maxEmailsPerWebsite": 5,
  "maxPlacesPerSearch": 3,
  "mode": "searchPlaces",
  "onlySaveResults": "allPlaces",
  "placeIds": [],
  "placeMinimumStars": "",
  "placeUrls": [],

    "coffee shops in Austin TX"

  "websiteFilter": "allPlaces",
  "websites": []
}

FieldTypeRequiredDescription
modestringoptionalChoose how to find businesses. Search Google Maps by phrase, enrich a list of websites you already have, or look up specific Google Maps places.
searchQueriesarrayoptionalNatural-language searches such as 'coffee shops in Austin TX' or 'plumbers near Chicago'. Include the place in the phrase, or use the location field below. Each phrase is searched separately.
locationQuerystringoptionalAdds a shared location to every search phrase, for example 'Austin, TX, USA'. Leave empty when your phrases already contain the place.
websitesarrayoptionalWebsites to extract contacts from, one per line. Bare domains such as 'example.com' are accepted.
placeUrlsarrayoptionalGoogle Maps place links, copied from the address bar or from a previous export.
placeIdsarrayoptionalCanonical Google Place IDs starting with 'ChIJ'.
maxPlacesPerSearchintegeroptionalMaximum businesses to keep for each search phrase. Google returns a ranked window of roughly 160-220 places per phrase; asking for more simply returns what the source has.
languagestringoptionalLanguage of the Google Maps interface and listing text.
extractEmailsFromWebsitebooleanoptionalVisit each business website to collect contact details. Disable for a faster run with Google Maps data only.
maxEmailsPerWebsiteintegeroptionalMaximum email addresses to keep for one business website.
maxContactPagesPerWebsiteintegeroptionalHow many pages to read on each website: the homepage plus contact, about, legal, privacy or careers pages. More pages find more contacts but take longer.
onlySaveResultsstringoptionalSave every business, only businesses where an email was found, or only businesses with any contact detail (email, website phone or social profile).
placeMinimumStarsstringoptionalKeep only businesses rated at least this high. Places without a rating are left out when a minimum is set.
categoryFilterarrayoptionalKeep places whose Google Maps category contains all words of at least one entry, for example 'coffee' or 'italian restaur'. Leave empty for no category filter.
websiteFilterstringoptionalKeep all places, only places with a website, or only places without one.
skipClosedPlacesbooleanoptionalCheck each place's public status and leave out businesses marked closed. This adds one small request per place.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/gMWbkCIRuVIl0guxm/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
