Use Jobicy Remote Job Listings Scraper with Python

Search remote job listings from Jobicy by keyword, region, and seniority level. Returns job title, company, salary range, job type, category, and a direct application link for each role.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "keyword": "",
  "maxItems": 3,
  "mode": "search"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringoptionalSearch the live Jobicy feed, fetch specific job URLs/IDs, or check stored job IDs. Leave blank for search.
keywordstringoptionalFull-text search across Jobicy job content (3-50 characters). Leave blank to browse. Examples: python, marketing, product designer.
geostringoptionalKeep jobs open to this location or region. Jobicy treats worldwide roles as eligible for every location. Legacy display names such as United States or worldwide are mapped in code. Jobicy lists Malaysia in its taxonomy but its jobs API rejects that slug, so Malaysia is not offered.
industrystringoptionalKeep jobs in one Jobicy category. Leave blank for all categories.
jobTypestringoptionalKeep one employment type. Leave blank for all types.
jobLevelstringoptionalKeep one seniority level. Leave blank for all levels. Legacy Any is accepted and keeps listings Jobicy labels Any.
postedWithinDaysintegeroptionalKeep jobs published in the last N days. 0 means no date limit. Jobicy exposes the last 7 days.
salaryDisclosedOnlybooleanoptionalKeep only listings where Jobicy publishes a salary range.
minAnnualSalaryUsdintegeroptionalKeep USD listings whose annualised maximum salary meets this figure. Hourly pay is annualised at 2,080 hours; monthly pay at 12 months. 0 disables this filter.
excludeKeywordsarrayoptionalDrop jobs whose title or company contains any of these terms (case-insensitive).
onlyActivebooleanoptionalCheck each listing's current status with Jobicy and keep only active jobs.
includeDetailsbooleanoptionalFetch each job page for its exact expiry date, company website and applicant countries. Adds requests; unavailable pages are skipped.
jobUrlsarrayoptionalJobicy job URLs or numeric job IDs. Used only with mode byUrls or status.
maxItemsintegeroptionalMaximum job listings to return (1-5,000). Jobicy's live window usually contains about 1,000-1,500 jobs.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/egBcBsVnU7LdO9mTp/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

Jobicy remote jobs with full descriptions, industries, job types, seniority, locations, salary (and annualised USD figures), optional expiry/company website/applicant countries, and live listing status.

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
