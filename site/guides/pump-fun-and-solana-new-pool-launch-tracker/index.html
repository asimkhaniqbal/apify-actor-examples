    Fix common problems

    Why is a holder count or social link missing for some rows?

    Those fields are filled only when the public token profile has them. Newly created mints often have no profile data yet. Detail lookups include holder and developer fields whenever the source publishes them.

    Why are there fewer rows than maxItems?

    The source ran out of matching pools, the age/DEX/market filters removed the rest, or the automatic fetch cap for a filtered feed was reached. Loosen the filters or raise maxItems.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
