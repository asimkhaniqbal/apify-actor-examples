Use Wholesale Marine Parts & Pricing Scraper with Python

Search or browse Wholesale Marine's boat parts, electronics, and outdoor gear catalog by keyword, category, or brand, with live pricing, stock status, SKUs, images, and ratings per product.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to fetch.
searchQuerystringoptionalFree-text product, part-number or UPC search (mode=keyword_search), e.g. `propeller`, `8M0097854`, `652480100512`.
extraSearchQueriesarrayoptionalOptional additional keyword queries for the same run (mode=keyword_search). Duplicates are removed.

extraCategoryPathsarrayoptionalAny additional category slug, path or URL (mode=category_browse), including subcategories not in the dropdown.
brandSlugstringoptionalPick a brand to browse (mode=brand_browse).
extraBrandSlugsarrayoptionalAny additional brand slug, name or URL (mode=brand_browse).
productUrlsarrayoptionalWholesale Marine product URLs or slugs to fetch in full detail (mode=direct_product_url).
sortOrderstringoptionalOrder for keyword/category/brand results. `relevance` is the site's best-match order for keyword search; category and brand use featured order for it. Ignored by full_catalog.
fullCatalogSortstringoptionalOrder for mode=full_catalog: newest, best selling, featured, or the store's default catalog order.
minPriceintegeroptionalDrop products priced below this amount.
maxPriceintegeroptionalDrop products priced above this amount.
inStockOnlybooleanoptionalDrop products whose inventory says they are out of stock. Listing pages already show in-stock products only; this also affects brand, full-catalog and product-URL runs.
includeDetailsbooleanoptionalEnrich listing results with SKU, stock, specifications, variants, images and description. Adds Storefront API requests; turn off for a faster, card-only run.
includeRatingsbooleanoptionalFetch each product's customer rating and review count from the store's review widget. Adds one request per product.
includeDescriptionHtmlbooleanoptionalAdd the original (cleaned) product description HTML, including specification and fitment tables. Increases record size.
maxItemsintegeroptionalHard cap on emitted product records.
maxItemsPerQueryintegeroptionalCap for each keyword query or category batch. Brand and full-catalog runs use maxItems instead.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/3TB30kbBWMkj0uRW7/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
