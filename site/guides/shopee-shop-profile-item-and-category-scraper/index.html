    What people export it for

    • Seller intelligence — compare shop ratings, follower counts, response times and official badges across markets
    • Catalogue enrichment — add descriptions, images, attributes and option groups to an existing product list
    • Category mapping — build a local category taxonomy with IDs and parent paths for each Shopee market
    • Marketplace monitoring — track the featured product's public price, discount, rating and sold count over time
    • Mall discovery — collect the shops promoted in a market's mall directory for outreach or benchmarking
    • Multi-market research — run the same shop or item across eight catalogues with the correct currencies

    Fix common problems

    Do I need an account, cookies or a proxy?

    No. The actor reads public pages and requires no login, cookies or proxy configuration.

    Why can't I search by keyword or list every item in a category?

    Shopee gates keyword search and category item listings behind a login/anti-bot wall for automated visitors. This actor deliberately uses the public shop, item and category surfaces instead.

    Why are price, rating, sold count or stock missing on some items?

    Shopee hides those fields from logged-out visitors on most item pages. They are included when the item is the shop's featured product, whose public card carries them. The featured field tells you which records have them. The public card comes from a translation mirror that can rate-limit (HTTP 429); in that case the shop record is still returned but the card is omitted.

    More from the publisher:

    • Why are some fields missing?

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
