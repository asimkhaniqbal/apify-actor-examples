    Fix common problems

    Why are there fewer links than the old version?

    The old actor reported soft-404 and WAF pages as profiles. Ten such sites were removed from the catalog, and the remaining generic claims now pass the decoy check. Set verifyClaims=false to see the raw claimed rows.

    Why are NSFW sites missing?

    They are excluded unless includeNsfw=true. The catalog marks 16 adult entries.

    A site I need is missing. Can I add it?

    The catalog is pinned and covers 428 sites. Use sites to confirm whether a site is supported; unknown values are logged and ignored. The catalog can be refreshed with scripts/refresh_catalog.py when upstream adds sites.

    More from the publisher:

    • Do I need cookies, an API key or a proxy?
    • Why do some sites return unknown or waf?

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
