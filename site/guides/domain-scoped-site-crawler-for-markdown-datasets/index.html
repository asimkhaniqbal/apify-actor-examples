    Domain-Scoped Site Crawler for Markdown Datasets: export to CSV, Excel or JSON

    Crawl a website from one or more start URLs, staying on the same domain, and get back clean Markdown, text, or HTML per page with title, description, and crawl depth. Built for feeding LLM, RAG, or knowledge-base pipelines.

    This tutorial runs Domain-Scoped Site Crawler for Markdown Datasets through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 5 columns its publisher puts first: url, title, depth, wordCount and httpStatusCode.

    Get an API token

    Copy your token from Apify Console, Settings, API and Integrations and keep it in an environment variable rather than in the script.

    Choose the input

    1 field is required:

    • startUrls: One or more URLs to start crawling from. The crawler follows links found on these pages and stays on the domain of the first start URL.

    Keep the first export small. These fields cap how many results a run collects, and so what it costs:

    • maxCrawlDepth (default 10, maximum 100)

    The input reference lists every field.

    Run it and write a CSV

    call() starts the run and waits until it finishes, however long that takes; the results land in the run's default dataset, which the loop reads page by page.

    Download Excel or JSON

    The API can run the Actor and hand back the dataset as a file in one request. format takes xlsx, csv, json, jsonl, xml or html, and fields keeps only the columns you list. The request waits up to 300 seconds; a longer run answers HTTP 408 and carries on, so use the Python script for big runs.

    Fix common problems

    • HTTP 401: the token is missing or wrong; run echo $APIFY_TOKEN in the same shell.
    • An empty file: open the run in Console and read its log; it usually names the input that matched nothing.
    • Odd characters in Excel: open the CSV through Data, From Text/CSV and pick UTF-8, or download xlsx instead.

    Each export run is billed on Apify: $0.99 per 1,000 results on the Free plan plus a start fee and platform usage. The price table works out runs of 100 to 10,000.
