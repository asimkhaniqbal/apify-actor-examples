    Domain-Scoped Site Crawler for Markdown Datasets: export to CSV, Excel or JSON

    Crawl a website from one or more start URLs, staying on the same domain, and get back clean Markdown, text, or HTML per page with title, description, and crawl depth. Built for feeding LLM, RAG, or knowledge-base pipelines.

    This tutorial runs Domain-Scoped Site Crawler for Markdown Datasets through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 5 columns its publisher puts first: url, title, depth, wordCount and httpStatusCode.

    The columns you can export

    The Actor's build declares 5 output fields in 1 dataset view ("Crawled Pages"). The export below keeps these, under the labels the publisher gave them:

    Default export columns
    FieldColumn headerWhat it holds
    urlURLURL that was requested
    titleTitleOpenGraph title, JSON-LD headline, or <title>
    depthDepthCrawl depth (0 = start URL)
    wordCountWordsWord count of text
    httpStatusCodeStatusHTTP status of the response

    Swap in any field from the output reference to export it too.

    What people export it for

    • LLM training and fine-tuning data — turn documentation, blogs, and help centers into structured Markdown with source metadata
    • RAG pipelines and semantic search — per-page content with optional heading-aware chunks and tokenCount, plus canonical URLs, dates, and hashes for clean indexing and re-indexing
    • Knowledge-base and chatbot grounding — keep a site's content current with scheduled incremental crawls
    • Content migration and archival — export a whole site to Markdown while keeping authorship and publication dates
    • Competitive and market research — compare content across sites with consistent fields per page

    Get an API token

    Copy it from Console, Settings, API and Integrations.

    Choose the input

    1 field is required:

    • startUrls: One or more URLs to start crawling from. The crawler follows links found on these pages and stays on the domain of the first start URL.

    Keep the first export small. These fields cap how many results a run collects, and so what it costs:

    • maxCrawlDepth (default 10, maximum 100)
