Use Pinterest Pins, Profiles and Boards Collector with Filters with Python

Collect public Pinterest Pins, profiles, boards, search results and comments by keyword or URL, with filters for saves, creator followers, verification, ads and shoppable Pins.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringoptionalChoose a collection type. Auto-detect accepts mixed public Pinterest Pin, profile, board, board-section, search and idea links.
keywordsarrayoptionalOne or more words or phrases for the search modes.
pinUrlsarrayoptionalPublic Pin links, numeric Pin IDs, or opaque feed IDs. Opaque IDs are kept as list rows without a detail page.
usernamesarrayoptionalUsernames, @usernames, or public profile links.
boardUrlsarrayoptionalPublic board links or username/board paths. A three-part board-section link is routed to that section's Pins.
ideaUrlsarrayoptionalPublic idea-topic links such as /ideas/beauty/935541271955/. Pinterest exposes a list-only feed capped at about 17 Pins.
startUrlsarrayoptionalPin, profile, board, board-section, search and idea links for Auto-detect.
maxItemsintegeroptionalMaximum number of emitted records, including comment and section rows. Set to 0 for no user cap.
maxPagesintegeroptionalMaximum feed pages per search, profile, or board. 0 follows Pinterest's cursors until the source ends.
minSavesintegeroptional0 means no minimum. For a positive value, keep only Pins where Pinterest supplies a numeric save count at or above it.
minCreatorFollowersintegeroptional0 means no minimum. Keep Pins only when Pinterest supplies a creator follower count at or above this value.
verifiedOnlybooleanoptionalKeep only rows that Pinterest explicitly marks as verified.
requireOutboundLinkbooleanoptionalKeep only Pins with a public destination link supplied by Pinterest.
imageOnlybooleanoptionalExclude Pins that Pinterest identifies as video.
excludeAdsbooleanoptionalExclude Pins that Pinterest marks as promoted or sponsored.
commerceOnlybooleanoptionalKeep only Pins with source-backed product, price, or shopping metadata.
includeCommentsbooleanoptionalAdd one real public comment row per collected numeric Pin. Comment rows count toward Maximum records.
maxCommentsintegeroptionalMaximum public comment rows to add per Pin when comments are enabled.
enrichDetailsbooleanoptionalCheck each collection Pin's public detail page for more accurate creator, engagement, link, and media fields. Slower and uses more requests.
resolveNumericIdsbooleanoptionalWhen a creator feed contains only opaque IDs, read the creator's public RSS feed to recover openable numeric Pin IDs.
proxyConfigurationobjectoptionalLeave empty for direct-first collection with the actor's automatic fallback. A supplied proxy is used only after a direct empty or blocked response.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/HhVE3zC5rfGcXFgpl/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
