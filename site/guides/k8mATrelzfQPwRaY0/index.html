Use Yandex SERP & Knowledge Graph Scraper with Python

Query Yandex across 17 regional domains and get organic results, ads, knowledge graph cards, inline images and videos, and related searches per page, with language, region and recency filters.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
modestringrequiredSearch by keyword or parse existing Yandex SERP URLs.
queriesarrayoptionalOne or more search queries (mode=search). Each query is processed separately.
serpUrlsarrayoptionalYandex search-result URLs, one per page (mode=byUrls). Direct Yandex URLs and translated Yandex URLs are accepted.
domainstringoptionalRegional Yandex front. yandex.com is the international entry point; Yandex may serve it from its Russia front (reported as servedDomain).
languagestringoptionalYandex interface and search language. Match it to your query language to keep result text untranslated.
regionstringoptionalNamed Yandex region preset. Leave empty to use Yandex's default region. regionId overrides this value.
regionIdintegeroptionalNumeric Yandex region ID (lr). Overrides the Region preset. For example 213 is Moscow and 983 is Turkey.
maxPagesintegeroptionalNumber of result pages to read per query (1-25). Yandex serves at most 25 pages.
startPageintegeroptionalZero-based page to start from (0-24). Use it to resume a deep result window.
maxItemsintegeroptionalGlobal cap on unique items across all queries and pages (1-10,000). In rows mode this is the row count; in pages mode it caps the items inside page records.
timeFilterstringoptionalLimit results by recency. The values map to Yandex's own past-day, past-two-weeks and past-month filters.
fixTyposbooleanoptionalLet Yandex correct misspelled queries. Turn it off for exact-match searches.
includeAdsbooleanoptionalInclude sponsored Yandex Direct rows with their click URL and displayed domain.
includeBlocksbooleanoptionalInclude knowledge graph, AI answer, inline images, inline videos, products, local companies and weather when present.
includeRelatedSearchesbooleanoptionalInclude the related-search suggestions shown below the results (requires Include SERP Blocks).
outputFormatstringoptionalPage records preserve the existing dataset shape; rows emit one flat record per result or block item.
failIfEmptybooleanoptionalFail the run when no records were produced, instead of finishing with an empty dataset.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/k8mATrelzfQPwRaY0/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
