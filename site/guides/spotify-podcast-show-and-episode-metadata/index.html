    Spotify Podcast Show & Episode Metadata Extractor: CSV and Excel export

    Search Spotify podcast shows and episodes, fetch a show's full episode list, resolve a show or episode by link, and browse categories by market - with descriptions, durations, release dates and preview URLs.

    Fix common problems

    Why are some fields missing from a record?

    Empty values are omitted. Not every publisher supplies a description, rating, topic list, trailer, preview clip or video flag.

    Why does a search return fewer records than maxItems?

    Spotify exhausted its public result set for that query, or the date window filtered the remaining episodes. The run status reports what was emitted.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
