    eMAG Multi-Market Product & Price Scraper: export to CSV, Excel or JSON

    Search, browse or fetch product details across eMAG's Romania, Bulgaria, Hungary and Poland storefronts: prices in local currency, discount percentage, ratings, stock status, seller and specifications.

    This tutorial runs eMAG Multi-Market Product & Price Scraper through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: productId, partNumberKey, name, price, currency, originalPrice, discountPercent and rating.

    Fix common problems

    Why are some fields missing on a search row?

    Listing pages expose card-level data. Brand, description, specifications and the full offer table live on the product page, so use getProductDetails or getProductOffers for those.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
