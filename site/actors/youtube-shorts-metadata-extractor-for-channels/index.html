    YouTube Shorts Metadata Extractor for Channels & Hashtags is an Apify Actor published by Vexaloom Labs. It accepts 11 input fields, none of them required at the top level. Each result can carry up to 38 declared fields, including title, type, videoId, viewCount, likes and duration. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Collect YouTube Shorts from a channel's Shorts tab, a hashtag feed, keyword search results, a list of Shorts links, or a sound — and turn each one into a row with exact view and like counts, comment count, publish date, duration, category, sound title, caption languages and the uploader's channel profile.

    What this actor does

    • Five ways in: a channel's Shorts tab (channel), a hashtag's Shorts feed (hashtag), YouTube search filtered to Shorts (search), specific Shorts URLs/IDs (direct), or other Shorts that use the same sound as seed links (sound)
    • Channel sorting: newest, most popular or oldest first, matching the buttons YouTube shows on the Shorts tab
    • Exact per-Short metrics: exact views, likes, comment count, duration, publish date, upload date, category and sound — pulled from each Short's own page, not the rounded listing values
    • Captions: whether captions exist and which language tracks are available
    • Channel profile on every channel-mode row: subscribers, description, join date, location, links, avatar, banner, total views, total videos and verification
    • Deep back-catalogs: page through a channel's entire Shorts list (up to 10,000 per channel per run)
    • Fast listing-only mode: turn includeDetails off to skip per-Short pages and return titles, links, thumbnails and displayed view counts quickly
    • Members-only Shorts (optional): includeMembersOnly also collects a channel's members-only Shorts when YouTube offers that filter on its Shorts tab; when the filter is not rolled out for the channel the run notes it and returns the public listing
    • Exact numbers only or nothing: a field YouTube does not expose for a given Short is omitted instead of emitted as null or a guess; long-form videos are never mixed in

    Use cases

    • Benchmark a creator's Shorts — exact views, likes and comments for their entire Shorts back-catalog, sorted by newest or most popular
    • Trend and hashtag research — see what creators and videos are active under a hashtag right now, then drill into exact engagement
    • Keyword discovery — find Shorts around a topic with YouTube search and rank them by exact performance
    • Sound tracking — group Shorts by the sound they use (Original Sound vs licensed tracks)
    • Content cadence monitoring — schedule a run with oldestPostDate to collect only recent uploads
    • Data enrichment — paste a list of Shorts links and receive clean rows with full metadata for each

    Error and status rows

    • A channel, hashtag or search query that cannot be read produces an error row in the same dataset: recordType: "error" with sourceType, source, errorCode (CHANNEL_NOT_FOUND, NO_SHORTS, HASHTAG_EMPTY, SEARCH_EMPTY, INVALID_SHORT_URL) and an error message. The run itself still succeeds.
    • When a run finds no Shorts at all, the dataset gets one status row instead: recordType: "status", status: "no_results", plus the inputs you supplied.

    Questions

    Do I need a YouTube account, API key or proxies?

    No. The actor reads YouTube's public pages and picks its network route automatically; there is nothing to configure.

    Why do some rows miss likes or commentsCount?

    YouTube hides those counters for some Shorts, or the page was briefly gated; the actor retries and falls back to its secondary source, and simply omits what is genuinely unavailable rather than guessing.

    What is the difference between viewCount and viewCountText?

    With includeDetails on, viewCount is the exact number from the Short's page and viewCountText is YouTube's display string (e.g. "30M views"). With includeDetails off, only the displayed value is available.

    How deep can a channel's Shorts history go?

    To the end of the channel's public Shorts list, up to 10,000 rows per channel per run. maxShorts caps each source.

    How deep can a hashtag go?

    YouTube's hashtag Shorts feed exposes one page (roughly 36–37 Shorts) and rejects further pages. The actor fills the rest of maxShorts from YouTube search results for "#tag shorts", which keeps returning Shorts that carry the tag.

    What does sound mode return?

    For each seed link you provide, the actor lists other Shorts that use the same sound (8–15 per seed) and tags them with matchedSoundTitle. The seed itself is not included; a seed whose sound has no feed yields a SOUND_UNAVAILABLE error row.

    Can I get members-only Shorts?

    Yes, when YouTube offers the Members only filter on that channel's Shorts tab — the filter is a gradual rollout, so the actor retries the tab a few times and, when it is not offered, says so in the status message and returns the public listing. Members-only Shorts count toward maxShorts and cost up to two player requests each; they carry isMembersOnly: true. YouTube sometimes serves the filter with an empty listing on datacenter networks — the actor then says so and returns the public listing.

    Which sort orders are supported?

    The three YouTube offers on the Shorts tab: newest, most popular and oldest. If a channel does not show those buttons, the run falls back to newest order and says so in the status message.

    Are view counts live?

    They are exact at the moment of scraping. YouTube updates counters continuously, so repeated runs can show slightly different numbers.

    Is this affiliated with YouTube?

    No. This is an independent tool and is not affiliated with, endorsed by, or sponsored by YouTube or Google.
