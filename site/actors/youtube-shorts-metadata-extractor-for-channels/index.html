    YouTube Shorts Metadata Extractor for Channels & Hashtags is an Apify Actor published by Vexaloom Labs. It accepts 11 input fields, none of them required at the top level. Each result can carry up to 38 declared fields, including title, type, videoId, viewCount, likes and duration. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    YouTube Shorts Metadata Extractor for Channels & Hashtags uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 11 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    inputModeInput ModestringWhere to find Shorts. 'channel' reads a channel's Shorts tab, 'hashtag' a hashtag's Shorts feed, 'search' YouTube search results filtered to Shorts, 'direct' specific Shorts URLs or video IDs, 'sound' finds other Shorts that use the same sound as seed Shorts.Default "channel"; Allowed channel, hashtag, search, direct, sound
    channelUrlsChannel URLsarrayYouTube channel URLs, handles (@username), or channel IDs (UCxxx). Required when inputMode is 'channel'.Default ["https://www.youtube.com/@MrBeast"]
    hashtagsHashtagsarrayHashtags to scrape Shorts from (e.g. #cooking, sports). Required when inputMode is 'hashtag'. Include or omit the # prefix.Example ["#shorts"]
    searchQueriesSearch QueriesarrayKeywords to search on YouTube, keeping only Shorts results. Required when inputMode is 'search'.Example ["cooking shorts"]
    shortUrlsShorts URLs or IDsarrayShorts URLs, youtu.be links, watch URLs, or 11-character video IDs. Required when inputMode is 'direct'; used as the sound seeds when inputMode is 'sound'.Default ["https://www.youtube.com/shorts/pfUG56htjBc"]
    sortShortsBySort Shorts BystringOrder of the channel's Shorts tab, matching the buttons YouTube shows: newest first (default), most popular, or oldest first. Falls back to newest when a channel does not offer the chosen order.Default "newest"; Allowed newest, popular, oldest
    maxShortsMax Shorts Per SourceintegerMaximum number of Shorts to return per channel, hashtag or search query (per run in direct mode).Default 3; Allowed 1 to 10000
    includeDetailsInclude Exact DetailsbooleanVisit each Short's page for exact views, likes, comment count, publish date, duration, category, sound and captions. Turn off for a faster, cheaper listing-only run (views as displayed, no likes or dates).Default true
    includeMembersOnlyInclude Members-Only ShortsbooleanChannel mode only. Also collect members-only Shorts when YouTube offers the 'Members only' filter on that channel's Shorts tab (a gradual rollout — the actor retries the tab a few times and notes it in the status message when unavailable). Member rows count toward maxShorts and cost up to two player requests each.Default false
    oldestPostDateOldest Post DatestringOnly include Shorts published on or after this date. Format: YYYY-MM-DD. Leave empty to include all. Works in channel, search and direct modes; hashtag mode needs 'Include Exact Details' because dates come from each Short's page.Example ""
    marketMarket / RegionstringYouTube market/region for localized content. Affects the language of metadata returned.Default "US"; Allowed US, GB, CA, AU, DE, FR, JP, KR and 23 more
