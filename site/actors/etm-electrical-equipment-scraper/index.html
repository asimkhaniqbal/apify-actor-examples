Each result can carry up to 22 declared fields, including name, brand, price, priceRetail, priceLegalEntity and currency. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    ETM Electrical Equipment Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    modeModestring requiredWhat to collect from ETM.ru. Search finds products by keyword; Browse categories and Browse a brand page through the catalog; Product details returns full cards; Category & brand breakdown maps the assortment.Default "search"; Allowed search, byCategory, byBrand, productDetails, categoryFacets
    searchQueriesSearch queries (mode=search)arrayOne or more keywords in Russian, e.g. автомат (circuit breaker), кабель (cable), розетка (socket). The legacy single-value field searchQuery is still accepted.Example ["автомат"]

Old category ids that ETM has moved (e.g. 501010_…) redirect to the current page.Example ["5004_avtomaticheskie_vykljuchateli"]
    brandBrand (filter for search / byCategory; required for byBrand)stringAccepts a brand id+slug (432_iek), a numeric ETM brand id (432), a brand URL (https://www.etm.ru/brand/953_navigator), or a brand-filtered catalog URL. In search and byCategory modes it filters results to that manufacturer; in byBrand mode it selects the brand to browse. Get brand ids from the Category & brand breakdown mode.
    productUrlsProduct URLs, IDs or ETM codes (mode=productDetails)arrayProduct page URLs (https://www.etm.ru/cat/nn/7416742), bare numeric product ids (7416742), or ETM codes (ETM7416742).Default []; Example ["https://www.etm.ru/cat/nn/7416742"]
    maxItemsMax itemsintegerHard cap on emitted product records for the whole run. Search result sets are capped by ETM at 1,000 products; a category can hold up to 100,000.Default 10; Allowed 1 to 10000
    includeDetailsEnrich search/category rows with full product detailsbooleanWhen enabled, every search or category row is followed to its product page and enriched with specifications, images, certificates, variants, package data and stock breakdown. Costs one extra request per product.Default false
    onlyNewOnly new productsbooleanUse ETM's 'Только новинки' filter.Default false
    onlyDiscountedOnly discounted productsbooleanUse ETM's 'Со скидкой' filter.Default false
    madeInRussiaOnly made in Russia / EAEUbooleanUse ETM's 'Сделано в России / ЕАЭС' filter.Default false
    inStockOnlyHide products that cannot be suppliedbooleanUse ETM's 'Скрыть непоставляемые товары' filter.Default false
    includeDiscontinuedInclude discontinued productsbooleanBy default ETM hides products it has discontinued. Enable this to include them.Default false
    cityCity for prices and stockstringETM prices and availability are city-specific. Pass an ETM city id (77 = Moscow, 78 = Saint Petersburg) or a city name such as Москва or Санкт-Петербург. Unknown names fall back to Moscow.Default "77"
    trackPriceHistoryTrack price history between runsbooleanStore each product's price in the run's key-value store and add previousPrice, priceChange, priceChangePct and a rolling priceHistory[] to later runs. Useful for scheduled price monitoring.Default false
