Each result can carry up to 6 declared fields, including companyName, country, city, employees, products and companyUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Europages is the directory most European manufacturers, wholesalers and service companies use to list themselves for cross-border trade. This actor searches it by product keyword, browses it by category or by country, or pulls a company's own profile directly from its URL, and returns the location, size and contact details each listing publishes.

    What this actor does

    • Four modes: searchCompanies (keyword search), searchByCategory (search scoped to a product/service category term), searchByCountry (browse listings for one country, defaults to a generic "manufacturer" query when no keyword is given), and companyDetails (fetch specific profile URLs directly)
    • Country filter restricts any search mode to one of 25 European markets
    • Paginates automatically through Europages' result pages until maxItems is reached or the listing runs out
    • Captures contact and sizing data — employee range, phone, website, and quality certifications, when the profile publishes them
    • Empty fields are omitted — a field only appears on a record when Europages actually published that value

    Use cases

    • Supplier sourcing — shortlist manufacturers or distributors for a product category in a target country
    • Lead list building — collect company name, phone and website for outbound sales in a European market
    • Market mapping — count and compare how many listed suppliers exist per country for a product line
    • Certification screening — filter prospective suppliers down to ones advertising ISO/CE certification
    • Profile refresh — re-fetch a known set of companyUrls to check for updated contact details

    Questions

    Does searchByCategory return different results from searchCompanies?

    No — both run the same keyword search; searchByCategory is just a naming convenience for when your query is a product/service category rather than a free-text phrase.

    What happens if I use searchByCountry without a query?

    As long as country is set, the actor searches with a generic manufacturer keyword so you still get a browsable set of listings for that country. If both query and country are blank, the run stops and asks for a keyword.

    Why are employees, phone or certifications missing on some records?

    Europages only shows these fields when the company itself filled them in on its profile; the actor never fills in a guessed or placeholder value.

    Can I search without restricting to a country?

    Yes — set country to an empty string to search across all of Europages' 25 supported countries.

    Does this require a Europages account or login?

    No — the actor reads only the public search and profile pages that are visible to anyone without signing in.

    How many pages does a search mode fetch?

    It keeps paging until it reaches maxItems or Europages returns fewer than 5 results on a page, which signals the end of that result set.

    Is this affiliated with Europages?

    No, this is an independent third-party actor that reads Europages' public pages. It is not affiliated with, endorsed by, or sponsored by Europages SA.
