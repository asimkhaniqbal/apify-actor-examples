    Europages European Manufacturer & Supplier Finder is an Apify Actor published by Vexaloom Labs. It accepts 13 input fields, and mode is required. Each result can carry up to 7 declared fields, including companyName, country, city, employeeCount, supplierTypes and vatId. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Europages European Manufacturer & Supplier Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    modeModestring requiredSearch by keyword, browse a product category, browse a country, or fetch specific company profile URLs. Legacy mode names are accepted for saved tasks.Default "search"; Allowed search, category, country, company, searchCompanies, searchByCategory, searchByCountry, companyDetails
    searchQueriesSearch keywordsarrayProduct, service or industry keywords to search on Europages, e.g. food processing equipment, packaging machinery, cnc machining. Required for search, category and country modes. One search per keyword.Default ["food processing equipment"]
    categoryCategory (mode=category)stringA Europages product/service category name or slug to browse, e.g. packaging, industrial valves, food-processing-equipment. Used when searchQueries is empty.Default ""

    supplierTypesSupplier typearrayOnly return suppliers with at least one of these business roles. Leave empty for every type.Default []; Allowed Production, CustomerSpecificManufacturing, Distribution, Service, Wholesaler

    verifiedOnlyVerified companies onlybooleanOnly return companies whose Europages profile is verified.Default false
    sortBySort orderstringRelevance keeps Europages' own ranking; Distance sorts by distance from the proxy location.Default "relevance"; Allowed relevance, distance

    maxItemsMax suppliersintegerMaximum number of company records to return across all keywords and countries.Default 20; Example 3; Allowed 1 to 5000
    maxPagesMax result pages per keywordintegerEuropages returns 30 companies per page and caps a single search at 100 pages (about 3,000 companies).Default 100; Example 1; Allowed 1 to 100
    partitionByCountrySplit large searches by countrybooleanWhen more than 3,000 suppliers are requested without a country filter, search each Europages country separately and deduplicate the results.Default true; Example false
