    Arbeitnow Global Job Board Extractor is an Apify Actor published by Vexaloom Labs. It accepts 13 input fields, none of them required at the top level. Each result can carry up to 7 declared fields, including title, company, location, remote, jobTypes and postedAt. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What it can do”, “Input”, “Output”, “How the modes work”, “Limitations and FAQ” and “Use cases”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 7 fields in 1 dataset view, and the README documents 14 more. Fields without a value can be left out of a record.

    What it costs

    Arbeitnow Global Job Board Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 13 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringChoose how to find jobs. Search uses Arbeitnow's own search and filters; By URLs reads the exact listing pages you paste.Default "search"; Allowed search, byUrls
    searchQuerySearch querystringKeyword matched by Arbeitnow's search across job title, company and description (e.g. "python developer", "data engineer", "sales"). Leave blank to list all jobs matching the other filters.Example "python developer"
    categoryCategory or citystringUse one of Arbeitnow's own topic, city or collection pages, such as Python, Berlin, Remote, Visa sponsorship or English speaking. Choose 'Any' for no category filter.Default "any"; Allowed any, english speaking, visa sponsorship, jobs with relocation, 4 day work week, ai, android, backend and 49 more
    tagsTagsarrayKeep jobs carrying every tag listed here (case-insensitive), e.g. ["Software Development", "Remote"]. Tags are Arbeitnow's category/tech labels, not free-text keywords.
    companiesCompaniesarrayKeep jobs from these companies. Accepts company names, company slugs or company page URLs, e.g. ["Zattoo", "https://www.arbeitnow.com/jobs/companies/n8n"]. Any match is kept.
    locationLocation containsstringKeep jobs whose location text contains this phrase (case-insensitive), e.g. "Berlin", "Munich" or "Germany". Leave blank for any location.Example ""
    urlsJob URLsarrayUsed only in 'Scrape these job URLs' mode. Paste full Arbeitnow job links, e.g. https://www.arbeitnow.com/jobs/companies/zattoo/senior-backend-engineer-python-berlin-435689.
    remoteRemote onlybooleanOnly return jobs that Arbeitnow flags as remote. Arbeitnow's flag is sparse; the Remote category also finds jobs whose location or title says remote.Default false
    jobTypesJob typesarrayKeep jobs whose employment labels contain any of these phrases, e.g. ["Full Time"], ["Internship"], ["Werkstudent"], ["Freelance"]. Leave empty for all types.
    datePostedPosted withinstringArbeitnow's feed holds roughly the last seven days of jobs. Choose a shorter window for fresher listings.Default "7d"; Allowed 24h, 3d, 7d
    sortBySort resultsstringNewest returns the most recently posted jobs first. Relevance uses Arbeitnow's keyword ranking when a search query is set.Default "newest"; Allowed newest, relevance
    includeDetailsFetch detail-page extrasbooleanOpen each selected job page to add the company logo, expiry date, employment type and curated benefits (visa sponsorship, relocation, English-friendly). Slower but richer.Default false
    maxItemsMaximum jobsintegerStop after this many matching jobs. The whole current feed is about 5,900 jobs; larger runs take longer and read more pages.Default 50; Example 3; Allowed 1 to 5000
