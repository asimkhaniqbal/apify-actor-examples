    Google Shopping Price Comparison & Deal Finder is an Apify Actor published by Vexaloom Labs. It accepts 17 input fields, none of them required at the top level. Each result can carry up to 46 declared fields, including query, position, title, price, currency and merchant. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “What you get”, “Inputs”, “Examples”, “Coverage and honest limits” and “Practical use”.

    What it costs

    Google Shopping Price Comparison & Deal Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
