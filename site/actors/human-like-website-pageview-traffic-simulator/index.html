    What it costs

    Human-Like Website Pageview Traffic Simulator uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 14 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    targetUrlsTarget URLsarrayPublic pages you own or are authorized to test. Legacy startUrls is accepted when this is empty.Example [{"url": "https://example.com"}]
    pageviewsPageviewsintegerTotal page loads to attempt, including followed pages. 1-1000.Default 10; Example 1; Allowed 1 to 1000
    pagesPerVisitPages per visitintegerMaximum pages in one visit (1-10), subject to the total pageview budget; above 1 attempts same-site link clicks when clicks are enabled.Default 1; Allowed 1 to 10
    visitStyleVisit stylestringHuman adds dwell, mouse and scroll behaviour. Quick loads the page and leaves without scrolling or clicks.Default "human"; Example "quick"; Allowed human, quick
    dwellSecondsDwell (seconds)integerTarget seconds on each page for human visits, varied slightly. Internal clicks may extend the measured time. Ignored by quick style.Default 20; Example 1; Allowed 1 to 300
    referrerModeReferrerstringReferrer shown to the site: direct, search engine, social network, or a custom URL.Default "direct"; Allowed direct, search, social, custom
    customReferrerCustom referrer URLstringFull http(s) URL used when Referrer is Custom URL.
    scrollScroll pagesbooleanScroll each page during human visits. Scroll depth is omitted when scrolling is off or no range is measurable; a very short page with a tiny overflow can report 100.Default true; Example false
    clickInternalLinksClick internal linksbooleanAttempt one visible same-site link per page during human visits. Ads, forms and external links are never clicked.Default true; Example false
    deviceMixDevice mixstringDevice profile for each visit. Mobile and tablet use Android Chromium emulation.Default "mixed"; Example "desktop"; Allowed desktop, mobile, tablet, mixed
    visitCountryVisit country (optional)stringOptional. Route visits through a residential proxy in this country for geo QA. Adds proxy usage.Default "none"; Allowed none, AD, AE, AF, AG, AI, AL, AM and 242 more
    blockAdsBlock adsbooleanBlock known ad domains. Analytics requests still load so tag firing can be measured.Default true; Example false
    blockImagesBlock imagesbooleanSkip images, fonts and media for faster, cheaper visits. Analytics still loads.Default false
    utmSourceTest-source tag (utm_source)stringOptional utm_source label appended to target URLs, e.g. traffic-test. Recommended to mark test visits.
