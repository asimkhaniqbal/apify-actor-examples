Google Search Results Scraper: Organic & SERP Boxes

Search Google and get organic results plus AI Overview, knowledge panel, People Also Ask, related searches, local pack, top stories and ads for each query, across 48 countries with language and date filters.

Open on ApifyGitHub source

Input schema

Input fields, types, required flags, descriptions, defaults, and prefills come from the published definition. Prefill examples are distinct from defaults.

FieldTypeRequiredDescription
queriesarrayrequiredList of Google Search queries. Each query will be searched separately and results combined in the output. Blank/whitespace-only entries are dropped before searching (a warning is logged with the count).
maxResultsintegeroptionalMaximum number of organic results to return per search query.
countryCodestringoptionalCountry for the search. Determines the Google domain and the searcher-location (gl) signal sent to Google, and is also used to steer the automatic GOOGLE_SERP/RESIDENTIAL proxy chain toward an exit IP in that country (skipped only if you set a custom Proxy configuration below). Leave empty for US (google.com); if Precise Location (uule) is set and this is left empty, the country is instead derived from the uule value itself.

FieldTypeRequiredDescription
queriesarrayrequiredList of Google Search queries. Each query will be searched separately and results combined in the output. Blank/whitespace-only entries are dropped before searching (a warning is logged with the count).
maxResultsintegeroptionalMaximum number of organic results to return per search query.
countryCodestringoptionalCountry for the search. Determines the Google domain and the searcher-location (gl) signal sent to Google, and is also used to steer the automatic GOOGLE_SERP/RESIDENTIAL proxy chain toward an exit IP in that country (skipped only if you set a custom Proxy configuration below). Leave empty for US (google.com); if Precise Location (uule) is set and this is left empty, the country is instead derived from the uule value itself.
restrictResultsCountrystringoptionalOnly return pages whose content originates from/targets this country (Google's cr parameter). This is different from Country above (which only sets the searcher's location/gl and the Google domain) - e.g. set this to Germany to only get results from German sites regardless of which Google domain or Country is used above. Leave empty for no restriction.
languageCodestringoptionalLanguage for the Google interface/UI itself (hl parameter). E.g. 'en', 'de', 'fr', 'es'. Leave empty for default. This does NOT restrict which language the matched pages are written in - use 'Restrict results language' for that.
restrictResultsLanguagestringoptionalOnly return results for pages written in this language, regardless of the UI language above (Google's 'lr' parameter). Enter a bare language code like 'en' or 'de'. To match documents in any of several languages, separate codes with a comma, e.g. 'en,fr' (sent to Google as an OR: lang_en|lang_fr). Leave empty for no restriction.
maxPagesPerQueryintegeroptionalMaximum number of search result pages to crawl per query. More pages means more results but slower execution.
resultsPerPageintegeroptionalNumber of results per page (Google 'num' parameter). Allowed values: 10, 20, 30, 40, 50, 100. Google has largely stopped honoring this for organic results since late 2023 and typically still returns roughly 7-10 organic results per page fetch regardless of this setting - use Max Pages Per Query to fetch more results instead.
timePeriodstringoptionalFilter results by time period. Leave empty for any time.
safeSearchstringoptionalFilter explicit content from results (Google's safe= parameter). Leave empty for the account/default setting.
mobileResultsbooleanoptionalIf enabled, returns results for the mobile version of Google Search. Desktop results are returned by default.
forceAiOverviewCapturebooleanoptionalIf enabled, forces every fetch into a slower, JavaScript-rendering mode and waits specifically for Google's AI Overview to finish loading, so 'aiOverview' can actually populate. By default the actor uses a fast fetch mode that never runs Google's JavaScript, so 'aiOverview' is almost always null regardless of whether Google shows one for your query - leaving this off means you should not expect AI Overview data. Turning it on makes each request noticeably slower and more resource-intensive, and it is still not a guarantee: Google may genuinely not render an AI Overview for a given query. For best results with this option, set Proxy Configuration to the Web Unblocker group. If that fetch fails, the actor falls back to the default fetch mode so other results are still returned, with 'aiOverview' left null.
csvFriendlyOutputbooleanoptionalIf enabled, outputs one organic/paid result per row instead of one SERP page per row. Suitable for CSV/Excel export. This is a lossy reshape: organic rows carry query, page, type, position, title, url, displayedUrl, snippet, siteLinks; paid rows carry query, page, type, title, url. AI Overview, knowledge panel, People Also Ask, related queries, local pack, top stories, sports table, and all opt-in extra boxes (weather, time zone, currency/unit converter, jobs, videos, shopping) are NOT included in any row - use the default JSON output if you need that data.
includeExtraBoxesbooleanoptionalIf enabled, also extracts weather, time-zone, currency converter, unit converter, stock, jobs pack, video pack, shopping pack, and dictionary boxes when present on the results page.
proxyConfigurationobjectoptionalChoose Apify proxy settings. Leave unset and the scraper automatically tries Google SERP, then RESIDENTIAL, then Apify Web Unblocker, then your account default - the GOOGLE_SERP and RESIDENTIAL attempts are automatically steered to an exit IP in your Country (or, if Country is left empty, the country derived from Precise Location/uule) so the proxy's real geolocation lines up with what you asked Google for instead of fighting it. This automatic steering only applies to the default chain; if you set a custom Proxy configuration here yourself (e.g. pinning apifyProxyGroups), set its own apifyProxyCountry too if geo-targeting matters.
uulestringoptionalOptional Google-encoded location string for city-level geo-targeting, more precise than Country when honored. It encodes a canonical place name (e.g. 'New York,New York,United States') as the literal prefix 'w+CAIQICI' followed by base64 - example for New York: w+CAIQICIH05ldyBZb3JrLE5ldyBZb3JrLFVuaXRlZCBTdGF0ZXM=. Easiest way to get one for your city: paste its canonical name (as it appears in Google Ads Geo Targets, e.g. https://developers.google.com/google-ads/api/data/geotargets) into a third-party uule builder such as valentin.app/uule.html and copy the resulting string starting with 'w+CAIQICI'. If Country above is left empty, its country is automatically derived from this value and used for both the gl signal and proxy-country steering, so you don't need to set both fields redundantly for the same location. Caveat: Google does not always honor this parameter even so - country-level targeting is reliable, but city-level precision beyond the country match is best-effort and its hit rate varies noticeably by city/region in our testing: it can fall back to the proxy IP's actual geographic location (which can be a different city or region, sometimes far from the encoded one) instead of the encoded one. Treat uule as a best-effort hint, not a guarantee, and spot-check results rather than assuming they reflect the targeted city. Leave empty to use Country only.
dateFromstringoptionalOnly include results published on or after this date (YYYY-MM-DD). Must be used together with Date to.
dateTostringoptionalOnly include results published on or before this date (YYYY-MM-DD). Must be used together with Date from.
exactPhrasebooleanoptionalIf enabled, wraps each query in quotes so Google matches it as an exact phrase (e.g. "running shoes") instead of matching the words independently and in any order.
sitestringoptionalRestrict results to this domain, e.g. nike.com. Unlike the other operators below, this one is verified: every organic result is checked against this domain and off-domain results Google slips in are dropped.
intitlestringoptionalRestrict results to pages that contain this word in the title, e.g. running. Sent to Google as-is; unlike Site above, results are not verified against it, so Google may still include pages that don't actually match.
intextstringoptionalRestrict results to pages that contain this word in the body text, e.g. discount. Sent to Google as-is; unlike Site above, results are not verified against it, so Google may still include pages that don't actually match.
inurlstringoptionalRestrict results to pages that contain this word in the URL, e.g. blog. Sent to Google as-is; unlike Site above, results are not verified against it, so Google may still include pages that don't actually match.
fileTypestringoptionale.g. pdf, doc, xls. Sent to Google as-is; unlike Site above, results are not verified against it, so Google may still include pages that don't actually match.
excludeTermsstringoptionalWords to exclude from results by prefixing them with '-', e.g. jaguar. Separate multiple words with a comma or space, e.g. 'jaguar, cats'.

Google Search Results Scraper: Organic & SERP Boxes

Run any search term through Google and get back a structured breakdown of the results page — not just the ten blue links, but the AI Overview, knowledge panel, People Also Ask, related searches, local pack, top stories, sports tables, and ads that Google surrounds them with. Point it at a list of queries, pick a country and language, and it returns one structured record per query/page.

What this actor does

  • Searches one or more queries across 48 countries with language targeting, time filters, custom date ranges, and city-level geo-targeting
  • Extracts organic results with position, title, displayed URL, snippet, and sitelinks, plus every SERP feature box Google renders for that query
  • Applies Google search operators (site:, intitle:, intext:, inurl:, filetype:, exclusions, exact phrase) directly in the query
  • Supports mobile SERP rendering, multi-page pagination per query, and an optional one-row-per-result CSV layout
  • Every feature field is always present in a page record; when Google doesn't render that feature for the query, its value is null rather than a placeholder

Output per search result page

Each run produces one record per query (per page, if maxPagesPerQuery > 1). Most feature fields are null unless Google actually renders that feature for the query — that's normal, not a bug. Paging stops early once maxResults organic results are collected or Google shows no next page.

Always attempted:

  • searchQuery — object with term, page, countryCode, languageCode and resultsPerPage used for this record
  • organicResults — array of {position, title, url, displayedUrl, snippet, siteLinks}, trimmed so the query never exceeds maxResults in total. url is Google's own redirect link, not the destination; use displayedUrl for the real domain
  • aiOverview — Google's AI-generated summary text and cited sources, when rendered
  • knowledgePanel — entity info panel for people, places, or organizations
  • peopleAlsoAsk — array of related questions (question text only; Google loads answers on click, so they aren't in the static page)
  • relatedQueries — array of {query, url} suggested searches
  • localPack — local business/map results, with rating, reviewCount, and address parsed regardless of UI language
  • topStories — news carousel results
  • sportsTable — title, headers, and rows for sports-standings-style queries
  • paidResults — ad slots, when Google renders any for the query (often null even for commercial terms)
  • resultsTotal — Google's own rough estimate of total matches; expect it to fluctuate between pages of the same query
  • hasNextPage — whether another results page is available

Opt-in via includeExtraBoxes:

  • weatherBox — temperature, condition, precipitation, humidity, wind, plus the box's raw text
  • timeZoneBox — local time, date, day of week, and timezone abbreviation for the queried place
  • currencyConverterBox — from/to amount and currency, exchange rate, and as-of timestamp
  • unitConverterBox — category, from/to amount and unit, and the conversion formula
  • jobsPack — job listing title, company, location, and source
  • videoPack — video carousel title, URL, channel, duration, and position
  • shoppingPack — product title, price, original price, seller, rating, and review count (no product URL — Google's shopping grid has no real link in the static page)
  • dictionaryBox — headword, phonetic, part of speech, and one entry per sense with definition and example
  • stockBox — raw text of a stock-price box when Google renders one (no structured price/change fields, unlike the other boxes above)

Error rows: a query that fails outright, or returns nothing because Google blocked every attempt, produces {"type": "error", "query": ..., "reason": ...} in place of its page records, in both output layouts.

One-row-per-result CSV mode (csvFriendlyOutput): reshapes output to one organic or paid result per row with query, page, type, position, title, url, displayedUrl, snippet, siteLinks (organic) or query, page, type, title, url (paid). AI Overview, knowledge panel, and every other box above are not available in this mode — use the default output if you need them.

Two verticals are currently out of scope and never populated: Images (Google serves placeholder image data, not real URLs, in the static page) and Flights.

FAQ

Is this an official Google product? No. This is an independent, third-party actor that reads publicly available Google Search result pages. It isn't affiliated with, endorsed by, or sponsored by Google.

How fresh is the data? Every run fetches live results at the moment it runs; there's no caching.

How many results can I get per query? Up to 200 organic results (maxResults) across up to 10 pages (maxPagesPerQuery). Since Google usually returns about 7–10 organic results per page, reaching high maxResults values also needs a higher maxPagesPerQuery; the default of one page gives roughly 10 results.

Does it work for non-English searches? Yes. Set countryCode and languageCode for localized results. localPack's rating, review count, and address, and resultsTotal, are parsed structurally rather than by matching English text, so they populate correctly across many languages and number formats.

Can I filter by date? Yes, two ways: timePeriod for a relative range, or dateFrom/dateTo for an absolute range (set together). When both are set, the custom range takes priority.

Why is paidResults often empty? Google renders zero ads for a large share of queries, even commercial ones. Treat it as best-effort; organic, AI Overview, and other fields are unaffected.

I set site — why did I get fewer results than maxResults? Google only keeps showing matching pages from that domain while it has them; once it runs out it starts slipping in unrelated domains without marking them. This actor checks every result against your domain and drops ones that don't belong, so a smaller but accurate result set is expected once a site's matching pages run out.

Why is aiOverview usually null? Google injects its AI Overview via client-side JavaScript, which the actor's default fast fetch doesn't render. Enable forceAiOverviewCapture to specifically wait for it — this is slower per query and still best-effort, since Google may genuinely not show an AI Overview for a given query.

Does the organic url field link straight to the destination site? No — it's Google's own redirect link, and the token inside it isn't decodable back to a destination. Use displayedUrl for the visible domain instead.

Why do some intitle/intext/inurl/fileType results not actually match? Only site is checked result by result. The other operators are sent to Google as part of the query, and Google doesn't strictly enforce them, so treat them as relevance hints rather than a guarantee. The one extra check: when intitle and intext are used together, results that share no words at all with your query and operators are dropped.
