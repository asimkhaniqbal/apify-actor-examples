    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search two keywords on gist and pastebin). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 1000), maxItemsPerSource (default 10, maximum 500) and maxPastesToScan (default 250, maximum 2000) cap how many results a run collects, and so what it costs.

    What it costs

    Paste Site Keyword Leak Finder (Pastebin, Gist & More) uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    modeModestring requiredChoose how to find public pastes.Default "searchKeywords"; Allowed searchKeywords, byUrls, recentPastes
    searchKeywordsSearch keywordsarrayWords or phrases to look for in public paste content (mode=searchKeywords). Each keyword is searched independently.Default []; Example ["test"]
    startUrlsPaste URLsarrayDirect links to public Pastebin, Gist, Ideone, Paste.org, or paste.gg pastes (mode=byUrls).Default []
    sourcesPaste sitesarrayWhich public paste sites to include: pastebin, gist, ideone, paste_org, paste_gg. The default is all five.Default ["pastebin", "gist", "ideone", "paste_org", "paste_gg"]; Example ["gist"]
    maxItemsMaximum resultsintegerHard limit on the total number of paste records returned.Default 50; Example 3; Allowed 1 to 1000
    maxItemsPerSourceMaximum results per siteintegerLimit on how many matching pastes or recent pastes are returned from each site.Default 10; Example 3; Allowed 1 to 500
    maxPastesToScanMaximum pastes to scanintegerHow many recent public pastes to inspect per site. Pastebin archive scans are capped at 250 keys per run.Default 250; Example 10; Allowed 1 to 2000
    syntaxesPastebin syntax archivesarrayOptional Pastebin syntax archives to scan in addition to the main archive. Leave empty for the main archive only.Default []; Allowed text, python, javascript, json, sql, xml, bash, c and 22 more
