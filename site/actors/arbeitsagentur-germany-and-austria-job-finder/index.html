    Arbeitsagentur Germany & Austria Job Finder is an Apify Actor published by Vexaloom Labs. It accepts 22 input fields, none of them required at the top level. Each result can carry up to 61 declared fields, including title, employer, city, region, publishedDate and salary. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What you can do”, “Input”, “Output”, “Typical uses” and “Good to know”.

    What it costs

    Arbeitsagentur Germany & Austria Job Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    searchSearch keywordstringWords to search for in job titles and descriptions, e.g. Softwareentwickler, Krankenpfleger, Lagerhelfer. Leave empty to browse all current postings.Default "Softwareentwickler"
    locationLocationstringCity, postal code or region to search around, e.g. Berlin, 10115, Bayern. For all Austrian jobs use Österreich.Default ""
    radiusSearch radius (km)integerRadius around the location. Only applied when a location is set.Default 25; Allowed 0 to 200

    publishedWithinPublished withinstringOnly jobs published in the selected window. Arbeitsagentur supports today, 1, 7, 14 and 28 days.Default "all"; Allowed all, today, 1, 7, 14, 28
    sortBySort results bystringOrder of the returned jobs.Default "relevance"; Allowed relevance, newest, modified, start-date, distance
    homeOfficeHome officestringRequire home office or a minimum home-office share.Default "all"; Allowed all, possible, at-least-50, full
    salaryDisclosureSalary disclosurestringOnly jobs that disclose an annual salary or an hourly wage.Default "all"; Allowed all, annual, hourly
