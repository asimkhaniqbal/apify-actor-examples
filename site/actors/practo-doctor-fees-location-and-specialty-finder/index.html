    Practo Doctor Fees, Location & Specialty Finder is an Apify Actor published by Vexaloom Labs. It accepts 3 input fields, and city and specialty are required. Each result can carry up to 6 declared fields, including name, specialty, city, clinicName, consultationFee and profileUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Practo Doctor Fees, Location & Specialty Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
