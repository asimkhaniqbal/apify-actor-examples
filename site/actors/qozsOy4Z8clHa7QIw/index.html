TikTok Playlist Discovery & Video Order Scraper

Scrape TikTok playlists - discover all playlists for a profile, get playlist metadata, and extract all videos. Supports playlist URLs, IDs, and profile URLs. No cookies required.

Open on ApifyGitHub source

Input schema

Input fields, types, required flags, descriptions, defaults, and prefills come from the published definition. Prefill examples are distinct from defaults.

FieldTypeRequiredDescription
playlistUrlsarrayoptionalPlaylist URLs, e.g. https://www.tiktok.com/@natgeo/playlist/Cinematic-7509464647364283178. Collection URLs pasted here are detected automatically.
playlistIdsarrayoptionalNumeric TikTok playlist IDs (15–20 digits). If an ID belongs to a public collection, the collection route is tried automatically.
collectionUrlsarrayoptionalPublic collection URLs, e.g. https://www.tiktok.com/@user/collection/places-to-go-7154034669288196891.

FieldTypeRequiredDescription
playlistUrlsarrayoptionalPlaylist URLs, e.g. https://www.tiktok.com/@natgeo/playlist/Cinematic-7509464647364283178. Collection URLs pasted here are detected automatically.
playlistIdsarrayoptionalNumeric TikTok playlist IDs (15–20 digits). If an ID belongs to a public collection, the collection route is tried automatically.

collectionIdsarrayoptionalNumeric TikTok collection IDs (15–20 digits).
profileUrlsarrayoptionalTikTok profile URLs. Every public playlist on each profile is discovered, up to the per-profile limit.
usernamesarrayoptionalTikTok handles with or without @. Every public playlist on each profile is discovered.
modestringoptionalReturn playlist/collection metadata rows, video rows, or both.
maxPostsPerPlaylistintegeroptionalMaximum videos to return from each playlist or collection. Set high enough to cover the full list.
maxPlaylistsPerProfileintegeroptionalMaximum playlists to process for each profile or username target.
maxItemsintegeroptionalStop after this many dataset rows across all targets, including status rows. Use 0 for no global limit.

TikTok Playlist & Collection Scraper

Collect every public video in a TikTok playlist or collection, in the creator's order, plus the playlist details that make the data usable: cover image, owner, owner stats, view/like/comment counts, sound metadata, media URLs, hashtags, mentions and slideshow images.

Give it a playlist URL, a collection URL, a numeric ID, a profile URL or a plain @handle. It returns one row per playlist or collection, one row per video, and clear status rows when a target cannot be read. No login, cookies or proxy setup are needed.

What this actor does

  • Scrapes playlists (/@user/playlist/...) and public collections (/@user/collection/...)
  • Accepts full URLs, numeric playlist/collection IDs, profile URLs and handles — mix them in one run
  • Returns the full ordered video list, not just the first visible page
  • Discovers every public playlist on a profile, up to a limit you set
  • Adds the playlist cover, creator identity, creator stats, shareMeta for collections and a scrapedAt timestamp
  • Captures slideshow posts as slideshows with their ordered image URLs
  • Reports invalid, private, empty, blocked and partial targets as rowType: "status" rows
  • Deduplicates videos by post ID and omits empty fields at every depth

All rows share rowType, scrapedAt and (when applicable) playlistId, playlistName, playlistType and playlistUrl.

Video row (rowType: "post")

Ordering and completeness

positionInPlaylist follows the order TikTok serves for that playlist or collection. It is not sorted by publish date, because creators deliberately order series, tutorials and trip lists. Every page is read until the source reports no more videos or your maxPostsPerPlaylist / maxItems limit is reached.

Collections can report more videos than are publicly accessible (deleted, private or region-locked items are still counted). The actor returns every accessible video once and never invents filler rows.

Use cases

  • Archiving a creator's series before videos disappear
  • Researching how publishers group content into themed playlists
  • Auditing collection-based campaigns and their engagement
  • Building ordered video libraries from travel, education or recipe collections
  • Tracking creator output, follower growth and playlist size over time
  • Feeding ordered short-form video datasets into a CMS, dashboard or model

FAQ

Do I need cookies or a login? No. The actor reads public pages without credentials.

Do I need to configure a proxy? No. The actor chooses its own connection automatically.

Why is positionInPlaylist not sorted by date? Playlists and collections have a creator-defined order. The position preserves that order, which is usually the point of scraping a playlist.

How many videos will I get? All publicly accessible videos, up to maxPostsPerPlaylist per target and maxItems overall. A playlist reported as 34 videos with 34 public items returns 34 rows.

Why does a collection say 651 videos but return fewer? TikTok counts unavailable entries in the collection total. Only publicly accessible videos can be returned.

What happens with a bad or private target? The run finishes successfully and emits a status row explaining the outcome instead of a fake playlist row.

Are the video and image URLs permanent? No. TikTok's CDN URLs are signed and expire after a few hours. Use postUrl as the stable reference and re-run when you need fresh media URLs.

Can I combine playlists, collections and profiles in one run? Yes. Add any mix of the input arrays. Duplicate targets are processed once.

What does maxItems count? Every dataset row, including playlist, video and status rows.
