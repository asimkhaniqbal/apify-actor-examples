    X Post, Reply & Profile Lookup by Link or ID is an Apify Actor published by Vexaloom Labs. It accepts 12 input fields, and tweetUrls is required. Each result can carry up to 9 declared fields, including type, text, author.username, createdAt, likeCount and retweetCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (one post with its replies). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxReplies (default 20, maximum 500), maxQuotes (default 50, maximum 500) and maxRetweeters (default 50, maximum 500) cap how many results a run collects, and so what it costs.

    What it costs

    X Post, Reply & Profile Lookup by Link or ID uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    tweetUrlsPost links, post IDs or profile handlesarray requiredPaste the posts you want to collect. You can also paste post IDs, x.com/i/web/status links, twitter.com links, profile links or bare handles (a profile input returns that profile's public details).Example ["https://x.com/NASA/status/2107095768821576019"]
    includeRepliesInclude repliesbooleanCollect the replies X shows for each post, walked forward from the post's publication time.Default true
    maxRepliesMaximum replies per postintegerHow many replies to collect for each post (0-500). Posts with very large threads may return fewer because X does not expose every reply to logged-out visitors.Default 20; Example 3; Allowed 0 to 500
    includeQuotesInclude quote postsbooleanCollect the posts that quote each requested post, with their text, author and engagement counts.Default false
    maxQuotesMaximum quote posts per postintegerHow many quote posts to collect for each requested post (0-500).Default 50; Allowed 0 to 500
    includeRetweetersInclude retweeter handlesbooleanCollect the handles of accounts that reposted each requested post. X only exposes a search-index sample of visible reposts, so this is an approximate, recent-biased list.Default false
    maxRetweetersMaximum retweeters per postintegerHow many retweeter handles to collect for each post (0-500).Default 50; Allowed 0 to 500
    includeQuotedTweetInclude the post each result quotesbooleanWhen a collected post quotes another post, attach the quoted post's text, author and metrics.Default true
    includeParentTweetInclude the post being replied tobooleanWhen a collected post is a reply, attach the post it answers under parentTweet.Default true
    includeThreadAncestorsInclude the full thread above a replybooleanWhen a requested post is a reply, walk up to 10 posts back to the start of the thread and attach them under threadAncestors (root first).Default false
    includeMediaInclude images and videosbooleanInclude image links, video links and video variants for each post.Default true
    includeAuthorProfileInclude author profile detailsbooleanAttach the author's public profile details (followers, bio, verification) to every post, reply and quote row under author and authorProfile.Default true
