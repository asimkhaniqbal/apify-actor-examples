    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search pins). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 20000) and maxComments (default 10, maximum 20000) cap how many results a run collects, and so what it costs.

    What it costs

    Pinterest Pins, Profiles and Boards Collector with Filters uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    modeWhat to collectstringChoose a collection type.     keywordsSearch wordsarrayOne or more words or phrases for the search modes.Default []
    pinUrlsPin URLs or IDsarrayPublic Pin links, numeric Pin IDs, or opaque feed IDs. Opaque IDs are kept as list rows without a detail page.Default []; Example ["142567144448888376"]
    usernamesPinterest usernamesarrayUsernames, @usernames, or public profile links.Default []
    boardUrlsBoard or section URLsarrayPublic board links or username/board paths. A three-part board-section link is routed to that section's Pins.Default []
    ideaUrlsIdea topic URLsarrayPublic idea-topic links such as /ideas/beauty/935541271955/. Pinterest exposes a list-only feed capped at about 17 Pins.Default []
    startUrlsMixed Pinterest URLsarrayPin, profile, board, board-section, search and idea links for Auto-detect.Default []
    maxItemsMaximum recordsintegerMaximum number of emitted records, including comment and section rows. Set to 0 for no user cap.Default 50; Example 1; Allowed 0 to 20000
    maxPagesMaximum pagesintegerMaximum feed pages per search, profile, or board. 0 follows Pinterest's cursors until the source ends.Default 0; Allowed 0 to 2000
    minSavesMinimum savesinteger0 means no minimum. For a positive value, keep only Pins where Pinterest supplies a numeric save count at or above it.Default 0; Allowed 0 to 10000000
    minCreatorFollowersMinimum creator followersinteger0 means no minimum. Keep Pins only when Pinterest supplies a creator follower count at or above this value.Default 0; Allowed 0 to 1000000000
    verifiedOnlyVerified accounts onlybooleanKeep only rows that Pinterest explicitly marks as verified.Default false
