    YouTube Channel Video Catalog & Profile Scraper is an Apify Actor published by Vexaloom Labs. It accepts 21 input fields, and channelUrls is required. Each result can carry up to 49 declared fields, including title, videoId, viewCount, duration, publishedTimeText and url. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Point this actor at a YouTube channel and get its full public catalog back — the latest uploads, the complete back-catalog, Shorts, live and upcoming streams, playlists, podcast shows and channel courses — with exact view and like counts, publish dates, durations and descriptions, plus the channel profile: subscribers, description, links, country, join date, total views and verification.

    What this actor does

    • Complete video catalog: newest, most popular or oldest first, paged through the channel's entire upload list
    • Exact per-video metrics: exact view count, exact like count, publish date, exact duration, description and category (when YouTube makes it publicly visible)
    • Every public surface: Shorts (with its own sort), live/upcoming/past streams, playlists, podcast shows, courses and music releases
    • Channel profile: subscribers, video count, handle, description, avatar, banner, country, join date, total views, external links, verification, keywords
    • Members-only listings: optionally list members-only videos (titles and public metadata) when YouTube offers that filter for the channel
    • Bulk channels: paste URLs, handles (@name) or channel IDs, one per line
    • Empty fields are omitted — empty text and missing numbers are left out instead of emitted as null

    Use cases

    • Channel research — map a creator's complete output, posting cadence and growth metrics
    • Competitor analysis — compare catalogs, view/like counts and publishing frequency across a niche
    • Content auditing — inventory every video on a channel to find gaps and evergreen performers
    • Influencer vetting — subscriber counts, verification, country and engagement signals in one run
    • Media monitoring — track news and live channels, including upcoming broadcasts
    • ML datasets — exact counts, ISO dates and descriptions ready for analysis

    Surface arrays

    shorts, playlists, liveVideos, podcasts, courses and releases are attached to the first video row of each channel (or to the channel-only row when maxVideos is 0) and are never repeated on every row.

    • shorts[] — videoId, title, viewCountText, url, thumbnailUrl, type: "short"; exact metrics are added when includeExactMetrics is on
    • playlists[] — playlistId, title, url, thumbnailUrl, videoCountText, videoCount, lastUpdatedText
    • liveVideos[] — the same video fields as a normal row, including isLive, isUpcoming and concurrentViewersText
    • podcasts[] — podcastShowId, title, url, thumbnailUrl, episodeCountText, episodeCount, lastUpdatedText
    • courses[] / releases[] — playlistId, title, url, thumbnailUrl, videoCountText, videoCount

    Questions

    Do I need a YouTube API key?

    No. The actor reads public YouTube pages and YouTube's own web endpoints; no API key, login or cookie is required.

    Which sort orders are available?

    Newest, most popular and oldest — for both long-form videos and Shorts. If a channel does not offer a chosen order, newest-first is used and the run log says so.

    Why are some counts exact and others text only?

    YouTube shows rounded labels like 466M subscribers on channel pages. The actor keeps that label in its *Text field and never expands it into a fake exact number. Exact viewCount and likeCount come from each video's own metadata.

    What does includeExactMetrics do?

    It fetches each video's exact views, likes, publish date, category and description. Turning it off makes runs faster and cheaper but returns listing-page values only.

    How far back does the catalog go?

    The actor pages through the channel's entire upload list, up to your maxVideos setting (maximum 10,000 per channel). Channels with tens of thousands of uploads are limited only by that cap.

    What can I learn about members-only or age-restricted videos?

    Titles, publish dates, durations and like counts are public for members-only videos when the channel shows them in its Members-only filter — those rows carry isMembersOnly: true and are added in addition to your maxVideos setting. Age-restricted videos are listed like any other video, with their public title, views, likes and duration; only playback is age-gated. Members-only and age-gated playback still requires a logged-in session; the actor never logs in.

    Are live streams included?

    Yes, with includeLiveVideos: active streams include isLive and a concurrentViewersText (for example "2K watching"), scheduled premieres carry isUpcoming, and past streams come back with durations.

    How fresh is the data?

    Data is fetched live at run time — there is no cache. Every run reflects the channel's current state. If a channel's catalog page cannot be fetched at all, the actor falls back to YouTube's public channel feed and returns that channel's latest 15 uploads instead of an empty result.

    Do I need to set up a proxy?

    No. The actor uses a working public connection to YouTube automatically. Just fill in the input and run it.

    Is this affiliated with YouTube?

    No. This is an independent tool and is not affiliated with, endorsed by, or sponsored by YouTube or Google.
