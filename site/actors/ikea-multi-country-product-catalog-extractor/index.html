    IKEA Multi-Country Product Catalog Extractor is an Apify Actor published by Vexaloom Labs. It accepts 19 input fields, and mode is required. Each result can carry up to 11 declared fields, including productId, name, typeName, price, rating and ratingCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    IKEA Multi-Country Product Catalog Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredHow to find products.Default "search"; Allowed search, byProductIds, byUrls, byCategory
    searchQuerySearch querystringFree-text query, e.g. bookcase, BILLY, sofa, kallax. Used by Search by keyword. Results are paged from IKEA's own listing API.Default "bookcase"
    productIdsProduct IDs (mode=byProductIds)arrayIKEA article numbers (e.g. 20522046). Dots, spaces, and full product URLs are accepted and normalized. One per line.Default []
    productUrlsProduct URLs (mode=byUrls)arrayFull IKEA product-page URLs, e.g. https://www.ikea.com/us/en/p/billy-bookcase-white-20522046/. One per line. The country and language in each URL are used for that product.Default []
    categoryCategorystringIKEA category key. Required by Browse a category; ignored by the other modes.Default ""; Allowed , products, fu001, fu002, fu003, fu004, st001, st002 and 26 more
    countryCountry / StorefrontstringIKEA market storefront (ISO 3166-1 alpha-2 code). Prices use this market's currency.Default "us"; Allowed us, gb, ie, ca, au, nz, in, sg and 42 more
    languageLanguagestringStorefront language; falls back to the country's primary language when the combination is not served.Default "en"; Allowed en, de, fr, it, es, pt, nl, sv and 22 more
    sortBySort bystringSort order applied by IKEA's listing API.Default "RELEVANCE"; Allowed RELEVANCE, PRICE_LOW_TO_HIGH, PRICE_HIGH_TO_LOW, NEWEST, RATING, MOST_POPULAR, NAME_ASCENDING, WIDTH and 2 more
    minPriceMinimum priceintegerExclude products priced below this value (storefront currency). Products with no listed price are excluded when this filter is set.Allowed 0 to 100000
    maxPriceMaximum priceintegerExclude products priced above this value (storefront currency). Products with no listed price are excluded when this filter is set.Allowed 0 to 100000
    minRatingMinimum customer ratingintegerExclude products rated below this value (0-5). Unrated products are kept.Allowed 0 to 5
    inStockOnlyIn-stock onlybooleanExclude products that IKEA marks as out of stock or not sellable online.Default false
