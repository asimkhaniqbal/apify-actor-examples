    ZipRecruiter Job Search Results & Salary Scraper is an Apify Actor published by Vexaloom Labs. It accepts 19 input fields, none of them required at the top level. Each result can carry up to 76 declared fields, including title, company, city, state, salary and workplaceTypes. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword search with filters). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 10000) and maxSearches (default 100, maximum 100) cap how many results a run collects, and so what it costs.

    What it costs

    ZipRecruiter Job Search Results & Salary Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 19 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat do you want to scrape?stringSearch job postings, scrape URLs you already have, or get salary benchmarks for a role and location.Default "search"; Allowed search, byUrls, salary
    searchQueriesSearch keywordsarrayJob titles or keywords, e.g. registered nurse or software engineer. Every keyword is searched in every location below.Default []; Example ["registered nurse"]
    locationsLocationsarrayCities, states, ZIP codes or United States for a nationwide search. Every keyword is searched in every location.Default ["United States"]; Example ["Chicago, IL"]
    companyNameCompany namestringOnly jobs from this employer, e.g. Visa. Leave the keywords empty to browse every open role at the company.Default ""
    startUrlsZipRecruiter URLsarraySearch, job, company or salary URLs. Use this with Scrape specific URLs; filters already in a search URL are kept.Default []
    jobTypeJob typestringEmployment-type filter for keyword searches.Default "any"; Allowed any, full_time, part_time, contract, contract_to_hire, temporary, as_needed, other and 1 more
    workplaceWorkplace typestringWork arrangement for keyword searches.Default "any"; Allowed any, remote, hybrid, onsite
    experienceLevelsExperience levelsarrayRestrict to one or more seniority levels. Empty means no filter.Default []; Allowed no_experience, junior, mid, senior
    daysPostedPosted within (days)integerOnly jobs posted within the last N days. 0 means any time.Default 0; Allowed 0 to 30
    radiusMilesSearch radius (miles)integerDistance around each location. 0 uses ZipRecruiter's default.Default 0; Allowed 0 to 100
    salaryMinMinimum annual salary (USD)integerOnly jobs whose advertised annual pay reaches this amount. 0 means no lower bound.Default 0; Allowed 0 to 1000000
    salaryMaxMaximum annual salary (USD)integerOnly jobs whose advertised annual pay stays at or below this amount. Best effort; 0 means no upper bound.Default 0; Allowed 0 to 1000000
