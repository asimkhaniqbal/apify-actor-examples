    LinkedIn Trending Posts & Top Voices Feed Scraper is an Apify Actor published by Vexaloom Labs. It accepts 20 input fields, none of them required at the top level. Each result can carry up to 19 declared fields, including authorName, authorFollowers, authorIsInfluencer, postedAt, headline and content. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    LinkedIn Trending Posts & Top Voices Feed Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 20 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to scrape. 'Top Content directory' crawls LinkedIn's public curated topic pages; 'Top Voices class' reads a quarterly LinkedIn News honoree list; 'Post URLs' enriches specific public posts.Default "auto"; Example "topContent"; Allowed auto, topContent, topVoices, postUrls
    topicsTopicsarrayPick one or more Top Content topics or subtopics, or paste any /top-content/... path or URL (custom values are accepted). Topic page = ~9-10 ranked posts; subtopics add ~20 more pages each. (mode=topContent/auto)Example ["artificial-intelligence"]
    maxDepthTopic DepthstringHow deep to crawl each selected topic. 2 = the topic page only (~10 posts); 3 = topic + its 20 subtopics; 4 = subtopics + their leaves (very large; use maxPosts). (mode=topContent/auto)Default "2"; Allowed 2, 3, 4
    startUrlsStart URLs (exact Top Content pages)arrayExact /top-content/... pages to scrape instead of expanding topics. Each page returns its ranked posts only. (mode=topContent/auto)Default []
    postUrlsPost URLsarrayPublic LinkedIn post URLs to enrich directly: /posts/..., /feed/update/urn:li:activity|share|ugcPost:..., or country subdomains. (mode=postUrls/auto)Default []
    topVoiceClassUrlsTop Voices Class URLsarrayLinkedIn News Top Voices class articles (/pulse/...). Leave empty to use the latest US class. (mode=topVoices/auto)Default []
    maxVoicesMax HonoreesintegerMaximum Top Voices honorees to return after deduplication. (mode=topVoices)Default 100; Allowed 1 to 500
    maxPostsMax PostsintegerMaximum posts to deliver after deduplication, filtering and sorting. Depth 2 across one topic usually has fewer than 10 unique posts; deeper crawls have more.Default 50; Example 3; Allowed 1 to 5000
    sortBySort BystringOrder of the delivered posts. 'LinkedIn rank' preserves each page's editorial order.Default "linkedin_rank"; Allowed linkedin_rank, newest, most_reactions, most_comments, most_engagement
    dateRangeDate RangestringOnly return posts published inside this window. LinkedIn Top Content is a curated archive, so 24h/7d/30d windows are often empty.Default ""; Allowed , 24h, 7d, 30d, 90d, 1y
    postedAfterPosted AfterstringOnly return posts published on or after this date (YYYY-MM-DD).Default ""
    postedBeforePosted BeforestringOnly return posts published on or before this date (YYYY-MM-DD).Default ""
