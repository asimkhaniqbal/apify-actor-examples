    What it costs

    Leboncoin France Classified Ads Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 23 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    startUrlsSearch URLsarrayPaste one or more leboncoin.fr search URLs. Every filter already in the URL is preserved (location, price, category, sort, property or vehicle filters). When you use this, the search filters below are ignored.Example ["https://www.leboncoin.fr/recherche?category=10"]
    categoryCategory IDintegerLeboncoin category ID used when no search URL is pasted. Common IDs: 9 = property sales, 10 = rentals, 2 = cars, 6 = car parts, 17 = phones, 33 = jobs. You can find any other ID in a leboncoin.fr search URL after ?category=.Allowed 1 to 99999
    searchKeywordsstringFree-text keywords, for example a model, a neighbourhood, or a job title. Combine with a category and location for a narrower search.
    locationsLocationsarrayFrench places to search in. Paste the values Leboncoin uses in its own URL, for example Paris, Lyon, 75015, d_75 (department), r_12 (region), or a full city code such as Paris__48.8566_2.3522_75056. Separate multiple places with one entry each.
    priceMinMinimum price (EUR)integerSmallest price to include. Leave empty for no lower bound.Allowed 0 to 100000000
    priceMaxMaximum price (EUR)integerLargest price to include. Leave empty for no upper bound.Allowed 0 to 100000000
    sortSort orderstringHow Leboncoin should order the results.Default "relevance"; Allowed relevance, newest, oldest, price_low, price_high
    ownerTypeSeller typestringKeep every seller, only private individuals, or only professionals.Default "all"; Allowed all, private, pro
    adTypeAd typestringOffers are listings for sale or rent; demands are wanted ads.Default "offer"; Allowed offer, demand, all
    shippableShippable onlybooleanReturn only ads where the seller offers shipping.Default false
    searchInTitleSearch keywords in titles onlybooleanRestrict the keyword match to ad titles instead of titles and descriptions.Default false
    roomsMinMinimum roomsintegerReal-estate filter: smallest number of rooms.Allowed 0 to 30
