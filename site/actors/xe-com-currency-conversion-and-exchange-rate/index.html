    XE.com Currency Conversion & Exchange Rate Scraper is an Apify Actor published by Vexaloom Labs. It accepts 14 input fields, and mode is required. Each result can carry up to 12 declared fields, including recordType, fromCurrency, baseCurrency, toCurrency, targetCurrency and currencyCode. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    XE.com Currency Conversion & Exchange Rate Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    modeModestring requiredWhat to fetch.Default "convert"; Allowed convert, ratesTable, currencyInfo
    amountAmount (mode=convert)numberAmount of fromCurrency to convert.Default 1; Allowed 0 to 1000000000000
    fromCurrencyFrom currencystringSource currency (mode=convert) or base currency for the rates table (mode=ratesTable).Default "USD"; Allowed ADA, AED, AFN, ALL, AMD, ANG, AOA, ARS and 211 more
    toCurrencyTo currency (mode=convert)stringTarget currency to convert into.Default "EUR"; Allowed ADA, AED, AFN, ALL, AMD, ANG, AOA, ARS and 211 more
    toCurrenciesAdditional target currencies (mode=convert, optional)arrayConvert the amount into multiple currencies at once instead of just 'To currency' (mode=convert). Emits one conversion record per currency, computed from the same live rates snapshot. Leave empty to use only the single 'To currency' field.Default []; Allowed ADA, AED, AFN, ALL, AMD, ANG, AOA, ARS and 211 more
    dateHistorical date (optional)stringYYYY-MM-DD. Leave empty for live/today's rates. In mode=convert, converts the amount using XE's historical daily rate table for that date; in mode=ratesTable, fetches that day's full table. XE has daily rate history back to the mid-1990s; today's date and future dates are rejected. Ignored when 'Historical dates (batch)' is set.
    datesHistorical dates (batch, optional)arrayFetch multiple historical dates in one run (e.g. to build a trend series), instead of a single 'Historical date'. Each entry must be YYYY-MM-DD; invalid or duplicate entries are dropped. Overrides 'Historical date' when non-empty. Up to 20 dates per run. mode=convert emits one conversion per date and target; mode=ratesTable emits each date's full table.Default []
    targetCurrenciesTarget currencies (optional filter)arrayRestrict mode=ratesTable / mode=currencyInfo output to these currency codes. Empty = all currencies.Default []; Allowed ADA, AED, AFN, ALL, AMD, ANG, AOA, ARS and 211 more
    sortBySort order (mode=ratesTable)stringHow to order rows in the rates table.Default "currencyCodeAsc"; Allowed currencyCodeAsc, rateAsc, rateDesc
    includeCryptoCurrenciesInclude cryptocurrenciesbooleanInclude crypto assets (BTC, ETH, ...) in mode=ratesTable / mode=currencyInfo output.Default true
    includeObsoleteCurrenciesInclude obsolete currenciesbooleanInclude retired currencies (e.g. pre-Euro DEM, FRF) in mode=ratesTable / mode=currencyInfo output. Useful for historical dates.Default false
    includeExtendedInfoInclude extended currency details (mode=currencyInfo)booleanFetch additional real-world details from xe.com's currency encyclopedia for each currency: country, symbol, central bank name/rate, inflation rate, nicknames, countries that use it, and a description. Adds one extra request per currency, so disable for faster runs if you only need the basic code/name/flags.Default true
    includeRateStatsInclude 7/30/90-day rate statistics (mode=convert, live only)booleanAttach XE's rolling 7-, 30- and 90-day high/low/average/volatility statistics for each converted pair. Adds one small request per target currency, so disable for the fastest multi-currency conversions. Historical conversions (date/dates set) never include these live statistics.Default true
    maxItemsMax itemsintegerHard cap on emitted records. The full rate table for one date is up to ~190 rows, so raise this when batching dates or converting into many currencies.Default 50; Allowed 1 to 10000
