    Google Search Results Scraper: Organic & SERP Boxes is an Apify Actor published by Vexaloom Labs. It accepts 24 input fields, and queries is required. Each result can carry up to 15 declared fields, including searchQuery, resultsTotal, hasNextPage, organicResults, aiOverview and knowledgePanel. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per search result page”, “Input”, “Use cases” and “FAQ”.

    What it costs

    Google Search Results Scraper: Organic & SERP Boxes uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
