    Facebook Post & Group Comment Thread Extractor is an Apify Actor published by Vexaloom Labs. It accepts 6 input fields, and startUrls is required. Each result can carry up to 12 declared fields, including profileName, text, date, likesCount, commentsCount and threadingDepth. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Facebook Post & Group Comment Thread Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 6 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    startUrlsFacebook URLsarray requiredFacebook post, photo, reel, video, Watch, or public group post URLs (one or more). Comment permalinks (URLs containing ?comment_id=) are accepted and resolved to their post; legacy story.php, permalink.php and share links are normalized automatically. Most public reels and videos are supported; a minority restricted by Facebook return no thread and are reported.Example [{"url": "https://www.facebook.com/NASA/posts/pfbid025kwy...
    maxItemsMax comments per URLintegerMaximum number of comment rows (including replies) to collect per URL. The run also stops when Facebook has no more comments or replies to serve.Default 100; Example 5; Allowed 1 to 10000
    onlyCommentsNewerThanOnly comments newer thanstringLimit results to comments posted after this date. Accepts YYYY-MM-DD, a full ISO 8601 timestamp (e.g. 2024-06-15T12:00:00Z), or a relative value like '1 day', '2 weeks', '3 months', '1 year'. When set, comments are fetched newest-first so the filter can stop as soon as an older comment is reached. Leave blank to disable date filtering.
    commentsModeComment orderingstringWhich comment view to scrape: MOST_RELEVANT (Facebook's ranked view), NEWEST (all comments, newest first), or ALL (Facebook's unfiltered ranked view, including comments its ranked view may hide).Default "ALL"; Example "MOST_RELEVANT"; Allowed ALL, NEWEST, MOST_RELEVANT
    includeNestedCommentsInclude repliesbooleanIf true, also scrape reply rows under top-level comments (with parent/reply metadata). If false, only top-level comments are collected (faster).Default true
    maxReplyDepthMax reply nesting depthintegerHow deep into reply threads to collect: 1 = direct replies to top-level comments only, 2 or more = also include deeper nested replies. Facebook serves reply threads with up to two nesting levels to anonymous visitors.Default 1; Allowed 1 to 5
