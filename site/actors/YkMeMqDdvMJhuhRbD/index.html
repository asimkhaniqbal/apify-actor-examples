Yahoo News Trending, Category & Keyword Feed by Region

Yahoo News aggregates headlines from thousands of publishers — AP, Reuters, BBC, CNN, Bloomberg, The Guardian, and more — across six regional editions. This actor pulls its trending top stories, individual news categories, or a keyword-filtered view across categories, for US, UK, Canada, Australia, Singapore, or Japan.

What this actor does

  • Fetches the current trending top stories for any supported region
  • Browses one or more news category feeds (World, Politics, Finance, Sports, and more, depending on region)
  • Filters every category of a region by one or more keywords, including non-Latin scripts such as Japanese
  • Narrows results further with an optional title/description keyword filter and a source-name filter
  • Omits any field an article doesn't carry — no empty strings or missing-value placeholders

Output per article

  • title — article headline
  • description — summary/excerpt (not present for the jp region — see FAQ)
  • sourceName — publisher name, e.g. Reuters, AP, BBC (not present for the jp region)
  • sourceUrl — publisher's homepage URL (not present for the jp region)
  • link — full article URL
  • publishedAt — publication date/time
  • imageUrl — thumbnail image URL, when the article has one
  • imageWidth, imageHeight — thumbnail dimensions in pixels, when published
  • category — the category slug the article was fetched from (e.g. politics, world) for getTrending/browseCategory; always search for search-mode matches, since that mode checks every category feed rather than one
  • region — regional edition this record came from (us, uk, ca, au, sg, jp)
  • guid — unique article identifier
  • scrapedAt — when the record was collected

Input

Field Type Default Description
mode string getTrending search, browseCategory, or getTrending
region string us Regional edition: us, uk, ca, au, sg, or jp
searchQueries array – Keywords to search for (mode=search)
categories array – Categories to browse (mode=browseCategory); availability varies by region, see below
maxItems integer 50 Maximum total articles to return (1-1000)
keyword string – Only return articles whose title or description contains this keyword
sourceFilter string – Only return articles from a source whose name contains this substring (e.g. Reuters)

Regions and their available categories

Region Categories
United States (us) Top Stories, US, World, Politics, Finance, Health, Science, Entertainment, Sports, Lifestyle, Oddly Enough
United Kingdom (uk) Top Stories, World, Finance, Sports
Canada (ca) Top Stories, World, Finance, Sports
Australia (au) Top Stories, World
Singapore (sg) Top Stories, World, Sports
Japan (jp) Top Stories, Domestic, World, Business, Entertainment, Sports, IT, Science, Local

A category not available for the chosen region is skipped; the run proceeds with whichever requested categories are valid for that region.

Example: trending stories for the UK

{
  "mode": "getTrending",
  "region": "uk",
  "maxItems": 20
}

Example: browse Finance and Sports in Canada

{
  "mode": "browseCategory",
  "region": "ca",
  "categories": ["finance", "sports"],
  "maxItems": 50
}

Example: search for a keyword, restricted to one source

{
  "mode": "search",
  "region": "us",
  "searchQueries": ["AI regulation"],
  "sourceFilter": "Reuters",
  "maxItems": 30
}

Use cases

  • News monitoring — track coverage of a brand, person, or topic across Yahoo's network
  • Media and competitive research — see which publishers cover a given story or category
  • Content aggregation — build a region-specific news feed for a site or app
  • NLP datasets — collect headlines and summaries for sentiment or classification models
  • Data journalism — compare how a story is covered across regional editions

FAQ

Is this affiliated with Yahoo? No — this is an independent, third-party actor that reads Yahoo News's publicly accessible feeds. It is not affiliated with or endorsed by Yahoo.

Why does the jp region have fewer fields per article? Yahoo Japan's feed only publishes title, link, and publish date for each article — no description, source name/URL, or image. This reflects what Yahoo's Japanese edition actually publishes, not a limitation of the actor.

Why are only six regions supported? US, UK, Canada, Australia, Singapore, and Japan are the editions confirmed to publish reliably; other Yahoo News editions aren't exposed because their availability wasn't verified.

How does search differ from browseCategory with a keyword filter? search checks every category feed available in the chosen region against your searchQueries. browseCategory with keyword instead restricts you to the specific categories you list, filtered further by that one keyword.

Why might a publisher's sourceUrl fail to load outside a browser? sourceUrl points to the publisher's own homepage (e.g. reuters.com), not a Yahoo URL — some publishers block non-browser requests to their own site. This doesn't affect link, which always points to the Yahoo-hosted article.

How current is the data? Yahoo's feeds refresh frequently through the day, so results reflect whatever is currently live when the actor runs.

How do I match a source more precisely? sourceFilter is a literal substring match against the full publisher name, so "AP" won't match "Associated Press" — use the full name or a substring of it instead.

Can I filter by date? Not directly as an input, but every article includes publishedAt, so you can filter by date downstream of the run.
