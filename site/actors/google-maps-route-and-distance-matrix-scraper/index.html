    Google Maps Route & Distance Matrix Scraper is an Apify Actor published by Vexaloom Labs. It accepts 19 input fields, none of them required at the top level. Each result can carry up to 35 declared fields, including recordType, origin, destination, originResolved, destinationResolved and routeName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Input”, “Output: route records”, “Output: matrix records”, “Examples” and “Use cases”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (driving route with a waypoint). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPairs (default 100, maximum 1000), maxAlternatives (default 5, maximum 8) and maxItems (default 50, maximum 1000) cap how many results a run collects, and so what it costs.

    What it costs

    Google Maps Route & Distance Matrix Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 19 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to scrape: one route (with optional waypoints), a distance matrix, or a list of Google Maps directions URLs.Default "route"; Allowed route, matrix, urls
    stopsStopsarrayOrdered stops for route mode: 2–10 locations. The first is the origin, the last is the destination, and everything in between becomes a waypoint.Example ["Times Square, New York, NY", "Central Park, New York, NY"]
    originsOriginsarrayStarting locations for matrix mode. Each origin is paired with every destination below.Example ["Times Square, New York, NY", "Grand Central Terminal, N...
    destinationsDestinationsarrayEnding locations for matrix mode. Each destination is paired with every origin above.Example ["Central Park, New York, NY", "Brooklyn Bridge, New York...
    directionsUrlsDirections URLsarrayGoogle Maps directions links for URLs mode. Canonical /maps/dir/ links and short share links are both accepted; waypoints and travel mode are read from the link when present.
    maxPairsMax PairsintegerMaximum number of origin × destination pairs to request in matrix mode. Pairs beyond this cap are left out.Default 100; Allowed 1 to 1000
    travelModeTravel ModestringHow to travel between the stops.Default "driving"; Allowed driving, walking, bicycling, transit
    avoidTollsAvoid TollsbooleanDriving only — ask Google Maps to avoid toll roads. If no toll-free route exists, Google may still return a toll route.Default false
    avoidHighwaysAvoid HighwaysbooleanDriving only — ask Google Maps to avoid highways and motorways. If no practical alternative exists, Google may still return a highway route.Default false
    avoidFerriesAvoid FerriesbooleanDriving only — prefer routes without ferry crossings. If every route uses a ferry, the result is still returned and marked with avoidanceUnmet.Default false
    departureTimeDeparture TimestringOptional ISO 8601 departure time as local time at the origin, for example 2026-06-16T10:30:00. Used for driving traffic estimates and transit schedules. A timezone offset is accepted but ignored; walking and bicycling ignore the field.
    maxAlternativesMax AlternativesintegerMaximum number of route alternatives to return per trip, including Google's recommended route. Applies to route and URLs modes. Google usually supplies up to 3 alternatives.Default 5; Example 1; Allowed 1 to 8
