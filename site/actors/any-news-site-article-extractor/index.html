    Any News Site Article Extractor is an Apify Actor published by Vexaloom Labs. It accepts 10 input fields, none of them required at the top level. Each result can carry up to 17 declared fields, including articleUrl, articleTitle, articleAuthors, articlePublishDate, articleModifiedDate and articleSection. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxArticles (default 20, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    Any News Site Article Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    articleUrlsArticle URLsarrayPaste one or more article URLs to extract directly. Any news site works, and no discovery is needed. When both this and News website URL are set, these URLs are processed first.
    websiteUrlNews website URLstringHomepage, section page, or newsroom URL to discover articles from. The actor reads the site's sitemaps first (including robots.txt entries and gzipped sitemaps) and falls back to article-shaped links on the page itself. Leave blank when using Article URLs.Example "https://techcrunch.com"
    maxArticlesMaximum articlesintegerHard cap on the number of articles returned across all input URLs.Default 20; Example 1; Allowed 1 to 500
    keywordFilterKeyword filterstringBoolean expression applied to each article's title and body. Supports AND, OR, NOT and parentheses, case-insensitive. Examples: AI AND NOT crypto, (startup OR funding) AND SaaS. Leave blank to keep every article.
    minWordCountMinimum article word countintegerDrop articles whose extracted body text is shorter than this.Default 100; Allowed 0 to 10000
    concurrencyConcurrencyintegerNumber of articles fetched in parallel. Higher is faster but more likely to trigger rate limits on small sites.Default 5; Allowed 1 to 20
    extractKeywordsExtract keywordsbooleanCompute the top 10 most frequent content words per article (stopwords removed).Default true
    extractSummaryExtract summarybooleanEmit the first three sentences of each article as a summary, with a meta-description fallback.Default true
    languageArticle languagestringLanguage hint for the articles. Use auto to detect from site metadata. An explicit language also filters out articles that declare a different one.Default "auto"; Allowed auto, en, de, fr, es, it, pt, nl and 32 more
    autoProxyFallbackAuto-retry via proxy when the direct fetch failsbooleanWhen a direct datacenter-IP fetch is blocked (0 candidates or 0 extracted articles), retry the same requests once through Apify residential proxy. Sites that work directly never trigger it. Turn off to guarantee zero proxy spend.Default true
