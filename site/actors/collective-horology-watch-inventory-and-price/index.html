    Collective Horology Watch Inventory & Price Tracker is an Apify Actor published by Vexaloom Labs. It accepts 12 input fields, and mode is required. Each result can carry up to 11 declared fields, including title, brand, productType, price, priceMin and priceMax. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Collective Horology Watch Inventory & Price Tracker uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredChoose what to fetch from Collective Horology.Default "browseAll"; Allowed browseAll, browseCollection, byProductIds
    collectionHandleCollectionstringBrand or collection slug, or paste its URL. Examples: horologer-ming, czapek, armin-strom, https://collectivehorology.com/collections/fears. Used in browseCollection mode. Approximate names such as ming are resolved automatically.
    productHandlesProduct handles or URLsarrayShopify product handles or full product URLs, one per line. Used in byProductIds mode.Default []
    searchQuerySearch wordsstringKeep only products whose title, brand, type, tags, description or SKU contain all of these words (case-insensitive).
    brandFilterBrandstringCase-insensitive substring match on the brand name, e.g. ming, czapek, arcanaut.
    productTypeFilterProduct typestringKeep only one product type. Use all to include watches, straps, books and merchandise.Default "all"; Allowed all, Watches, Wrist Watch, Straps, Watch Bracelet, Books, Shirt, Hoodie and 1 more
    conditionConditionstringFilter by the condition tags Collective Horology publishes.Default "any"; Allowed any, new, preowned
    minPriceMinimum price (USD)integerSkip products priced below this amount.Allowed 0 to 500000
    maxPriceMaximum price (USD)integerSkip products priced above this amount.Allowed 1 to 500000
    availableOnlyIn stock onlybooleanOnly emit products that currently have at least one variant in stock.Default false
    sortBySort orderstringOrder applied by Collective Horology before records are emitted.Default "manual"; Allowed manual, best-selling, title-ascending, title-descending, price-ascending, price-descending, created-ascending, created-descending
