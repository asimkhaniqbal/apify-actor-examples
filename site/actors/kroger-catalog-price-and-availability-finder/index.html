    What it costs

    Kroger Catalog Price & Availability Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 9 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect: a keyword search, UPC lookups, product URLs or whole category pages.Default "search"; Allowed search, byUpc, byProductUrl, byCategory
    searchQueriesSearch queriesarrayKeywords for mode=search, e.g. milk, coffee, protein bars. Results from all queries are combined and deduplicated.Default ["milk"]
    upcsUPCs (mode=byUpc)arrayKroger UPC/GTIN codes to look up, 12-14 digits. Each code is searched and returned once.Default []
    productUrlsProduct URLs (mode=byProductUrl)arrayKroger product page URLs such as https://www.kroger.com/p/<slug>/<upc>. The UPC is read from the URL.Default []
    categoryUrlsCategory URLs or IDs (mode=byCategory)arrayKroger category page URLs such as https://www.kroger.com/pl/fresh-fruit/06111, or a numeric taxonomy ID like 06111.Default []
    availabilityAvailabilitystringKeep all products, only products in stock, or only products currently out of stock.Default "any"; Allowed any, inStock, outOfStock
    minPriceMin price (USD)numberOnly emit products whose regular price is at or above this amount.Allowed 0 to 100000
    maxPriceMax price (USD)numberOnly emit products whose regular price is at or below this amount.Allowed 0 to 100000
    maxItemsMax itemsintegerHard cap on emitted records.Default 50; Example 3; Allowed 1 to 5000
