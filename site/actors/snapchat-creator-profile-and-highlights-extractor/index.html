    Snapchat Creator Profile & Highlights Extractor is an Apify Actor published by Vexaloom Labs. It accepts 12 input fields, and usernames is required. Each result can carry up to 46 declared fields, including username, displayName, accountType, isVerified, subscriberCount and bio. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (quick profile lookup). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxRelatedAccounts, maxHighlightsPerUser and maxSnapsPerHighlight (default 0, maximum 500) cap how many results a run collects, and so what it costs.

    What it costs

    Snapchat Creator Profile & Highlights Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
