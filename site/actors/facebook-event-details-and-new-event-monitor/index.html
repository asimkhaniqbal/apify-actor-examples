    Facebook Event Details & New-Event Monitor Scraper is an Apify Actor published by Vexaloom Labs. It accepts 11 input fields, none of them required at the top level. Each result can carry up to 7 declared fields, including event_id, name, formatted_date, location_name, ticket_price_text and users_responded. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Facebook Event Details & New-Event Monitor Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    eventUrlsEvent, organizer or search URLsarrayFacebook event URLs or IDs, organizer event pages (e.g. https://www.facebook.com/TED/events, /upcoming_hosted_events, /past_hosted_events), or an events search URL. Group event URLs are skipped because they require login.Example ["https://www.facebook.com/events/1855253805343101"]
    searchQueriesSearch queriesarrayKeywords for Facebook's public events search (e.g. "music festival", "tech conference"). Each query is paginated up to Max results.
    searchLocationSearch location textstringCity or place text added to each search query (e.g. "Chicago"). This is a keyword hint, not a strict geographic filter; use Location ID for a strict filter.
    locationIdLocation ID (strict)stringOptional Facebook place ID or /places/<id>/ URL for a location filter on search. Facebook's place scope can include nearby cities. Text-to-ID lookup requires login, which this actor does not use.
    startDateStart datestringOptional search filter lower bound in YYYY-MM-DD format (e.g. 2026-12-01). Applies to search queries only.
    endDateEnd datestringOptional search filter upper bound in YYYY-MM-DD format. Equal to Start date selects one day.
    categoryCategorystringOptional server-side category filter for search queries. Categories are host-set, so some events have none.Default "Any"; Allowed Any, Art, Causes, Comedy, Crafts, Dance, Drinks, Film and 16 more
    includePastEventsInclude past events (organizer pages)booleanFor organizer pages, fetch the Past collection instead of Upcoming. Ignored for event URLs and search.Default false
    includeOccurrencesExpand recurring event datesbooleanFor recurring events, add every occurrence date and URL to the event record. Uses one extra request only when the event is recurring.Default false
    maxItemsMax results per targetintegerMaximum events per organizer listing or search query. A direct event URL always returns its one event.Default 50; Allowed 1 to 1000
    monitorModeMonitor mode (only new events)booleanFor organizer pages and searches, output only events not seen by an earlier run for the same target. The first run is a baseline. State is a named Apify store, is actor-wide (not per user), and is shared by all runs of this actor for the same target; clearing it or changing the target re-emits all events.Default false
