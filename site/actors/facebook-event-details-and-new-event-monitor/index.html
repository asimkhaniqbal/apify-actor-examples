Each result can carry up to 7 declared fields, including event_id, name, formatted_date, location_name, ticket_price_text and users_responded. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Read public Facebook event pages, organizer event lists, and keyword search results without logging in. Get dates and time zones, venue and GPS when Facebook exposes them, hosts, ticket links and prices, recurring-series dates, and an optional only-new mode for scheduled runs.

    What this actor does

    • Event details by URL or ID: name, description, start/end time, time zone, venue, coordinates, cover, hosts, creator, categories, tickets and online links.
    • Organizer Upcoming and Past: read /PageName/events, /PageName/upcoming_hosted_events, or /PageName/past_hosted_events; page through the whole list up to your limit instead of stopping at the first batch.
    • Keyword search: search Facebook's public events index and page through results. Optional date range, category, and location-ID filters (Facebook's place scope can include nearby cities).
    • Recurring series: optionally add every occurrence date and URL for recurring events.
    • Monitor mode: on a schedule, return only events not seen by an earlier run for the same organizer/search target. State is scoped to the Apify user who runs the actor, so separate users do not share history.
    • Durable images: cover and host photos are copied into Apify storage; the original signed URL is kept beside the stored one.

    Empty fields are omitted. The actor never fills a missing value with null, 0, or a placeholder.

    Use cases

    • Build a local what's-on calendar from venues and organizers.
    • Watch an organizer's page on a schedule and report only newly posted events.
    • Collect dates, venues, ticket links and host details for event directories.
    • Research recurring series across a city or category.
    • Map events that expose coordinates.

    Questions

    Do I need a Facebook login or cookies?

    No. The actor reads only public pages. Group events, private events, and city-name typeahead require login and are not supported.

    Why is a venue address or GPS missing?

    Many Facebook events use free-text locations without coordinates. The actor returns what the event exposes and omits the rest; it never geocodes or invents a location.

    Why did a search return fewer results than I asked for?

    Facebook's public search index is relevance-ranked and changes between requests; categories are host-set and often empty. The actor retries a throttled first page and logs a warning when pagination stops short of your limit. Facebook can also end a deep result set early without an error; that can look like exhaustion, so a shortfall is not always flagged. It never fabricates rows to fill the gap.

    How does monitor mode decide what is new?

    It stores the event IDs already reported for each organizer/search target in an Apify key-value store. State is scoped to the Apify user who runs the actor, so separate users do not share history for the same target. Runs without a user identity use a stable anonymous scope. The first run is a baseline; later runs omit seen IDs. Clearing the store, changing the target, or losing state causes a new baseline. There is no webhook; schedule the actor and read the dataset. Concurrent runs can race.

    Can I get every date of a recurring event?

    Yes when the event exposes child occurrences. Turn on includeOccurrences; the record gets an occurrences[] list. A one-off event has no list.

    Can I filter by city?

    Use locationId with a numeric Facebook place ID or /places/<id>/ URL. Facebook's place scope can include nearby cities, so treat it as best-effort, not an exact city boundary. Facebook's city text lookup needs login, so searchLocation is a keyword hint only.

    Can I get attendee lists or separate going/interested counts?

    No. Facebook restricts attendee identities, and it no longer exposes separate going/interested figures to logged-out visitors. users_responded is the combined public count; there is no separate interested field.

    Do group events work?

    No. Facebook Groups require a logged-in session, so group event URLs are skipped with a warning.

    Are images permanent?

    Cover and host images are copied into Apify storage and the original signed URL is kept in *_original. Facebook CDN originals expire after a few days.

    Is this affiliated with Facebook or Meta?

    No. This is an independent tool and is not affiliated with, endorsed by, or sponsored by Meta Platforms, Inc.

    Limits and notes

    Limits

    • No group events, private events, guest lists, or split going/interested counts.
    • No true radius/nearby search; a location filter needs a Facebook place ID, and its scope can include nearby cities.
    • GPS and street addresses are conditional on what the venue exposes.
    • Ticket price is text only; structured price tiers are not public.
    • Search results are dynamic; a retry can still return fewer rows than requested.
