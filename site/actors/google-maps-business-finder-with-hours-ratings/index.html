    Google Maps Business Finder with Hours, Ratings & Location is an Apify Actor published by Vexaloom Labs. It accepts 20 input fields, none of them required at the top level. Each result can carry up to 55 declared fields, including recordType, searchTerm, rankInSearch, name, categoryName and categories. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Find businesses on Google Maps from a search phrase, a Maps place URL, or a canonical Place ID. The actor returns one clean row per business with its category, address, phone, website, rating, review count, weekly hours, price information where Google publishes it, attributes, photos and coordinates. It runs without a login, an API key, or proxy setup.

    What this actor does

    • Search, URL and Place ID modes: search by keyword, paste a list of Maps place URLs, or look up ChIJ Place IDs. The two direct modes accept a mixed batch.
    • Batch coverage: run several search terms across several locations in one run, with a separate result allowance for each term × location pair.
    • Complete business rows: name, category, full address, phone, website, rating, review count, weekly hours, open/closed status, coordinates, Place ID and Maps URL.
    • Optional place details: add Plus Code, price range, hotel stars and nightly price, fuel prices, accessibility and amenity attributes, photo count, photos and the rating histogram.
    • Useful filters: rating range, review-count range, open now, must have a website or phone, name contains, exclude categories, and optionally skip permanently closed places.
    • 74 languages: names, categories, addresses and hours follow the language you select.
    • No browser, no login, no API key. Empty fields are omitted instead of returned as placeholders.

    Use cases

    • Build local prospect lists with phone, website, rating and hours for a city or neighborhood.
    • Compare ratings, review counts, price ranges and amenities across competitors.
    • Refresh opening hours, ratings and contact details for a fixed list of branch URLs or Place IDs.
    • Find hotels with star class, nightly price and check-in/check-out times.
    • Compare fuel prices at stations in an area.
    • Add coordinates, Place IDs and Plus Codes to an existing location database.

    Questions

    What is the data source?

    Public Google Maps pages and their public place data. No Google account, API key or login is used.

    Do I need to set up a proxy?

    No. The actor tries a direct connection first and escalates to Apify's proxy pool only if Google repeatedly blocks requests. There is no proxy field to configure; just fill in the input and run it.

    How many results can one search return?

    Google returns a ranked window of roughly 160–230 places for a typical city query; broad categories such as hotels can return more. That is the source's window, not an unlimited directory. Split a broad search by neighborhood or category for wider coverage.

    Why did I get fewer rows than maxResults?

    The source window ended, filters removed rows, duplicate places were merged, or a place page could not be read. The run status says which of these happened.

    Why are some fields missing?

    Google publishes different details for different businesses, categories and countries. A place without a published website, phone, price or hours omits that field; the actor never invents a value.

    Are prices always available?

    No. Restaurant price ranges, hotel nightly prices and fuel prices appear only when Google publishes them for that place and date.

    Does this actor scrape reviews?

    No. It returns the rating and review count, plus the rating histogram. Review text and reviewer profiles are outside this actor's scope.

    Can I search several cities or categories in one run?

    Yes. Use searchTerms and locations; every term is searched in every location with its own maxResults allowance.

    What happens to duplicates?

    Places are matched by Place ID, feature ID or Maps URL (or name plus address when none is available) across the whole run. A place found twice is saved once.

    Is this affiliated with Google?

    No. It is an independent tool that reads public Google Maps pages. Use the data responsibly and follow applicable terms and laws.
