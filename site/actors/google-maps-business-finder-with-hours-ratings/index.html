    Google Maps Business Finder with Hours, Ratings & Location is an Apify Actor published by Vexaloom Labs. It accepts 20 input fields, none of them required at the top level. Each result can carry up to 55 declared fields, including recordType, searchTerm, rankInSearch, name, categoryName and categories. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Google Maps Business Finder with Hours, Ratings & Location uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 20 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringSearch mode uses a text query; placeUrls mode reads specific Maps URLs; placeIds mode resolves canonical ChIJ Place IDs.Default "search"; Allowed search, placeUrls, placeIds
    searchQuerySearch QuerystringWhat to search for on Google Maps. Include a location for best results, for example 'coffee shops in New York'. Used when mode is search.Example "coffee shops in New York"
    locationLocation (optional)stringOptional location appended to each search term, for example 'Austin, TX'. Leave blank when the location is already in the query.
    placeUrlsPlace URLsarrayGoogle Maps place URLs to read directly. Used in placeUrls and placeIds modes; the two direct modes accept a mixed batch.
    placeIdsGoogle Place IDsarrayCanonical Google Place IDs beginning with ChIJ. Used in placeUrls and placeIds modes; the two direct modes accept a mixed batch.
    maxResultsMax ResultsintegerPlaces to collect per search in search mode, or in total in the direct modes. Google returns a ranked window of roughly 160-230 places for a typical query; split broad searches by neighborhood or category for wider coverage.Default 20; Example 3; Allowed 1 to 100000
    languageLanguagestringLanguage for Google Maps names, categories, addresses and hours.Default "en"; Allowed en, af, az, id, ms, bs, ca, cs and 66 more
    includeDetailsInclude place detailsbooleanRead the place panel for Plus Code, price range, hotel and fuel details, attributes, photo count and rating histogram. Adds one request per place; the basic listing fields and weekly hours are always included.Default true; Example false
    searchTermsSearch terms (batch)arraySeveral search terms in one run, for example ["coffee shops", "dentists"]. Each term is searched in every location.Default []
    locationsLocations (batch)arraySeveral locations in one run, for example ["New York, NY", "Austin, TX"]. Each term is searched in each location.Default []
    minRatingMinimum ratingnumberOnly keep businesses rated at or above this value. Businesses with no published rating are skipped.Allowed 1 to 5
    maxRatingMaximum ratingnumberOnly keep businesses rated at or below this value.Allowed 1 to 5
