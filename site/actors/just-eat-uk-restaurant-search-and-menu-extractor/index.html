    Just Eat UK Restaurant Search & Menu Extractor is an Apify Actor published by Vexaloom Labs. It accepts 10 input fields, and mode is required. Each result can carry up to 9 declared fields, including restaurantId, name, cuisines, rating, deliveryEtaMinutes and restaurantUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Just Eat UK Restaurant Search & Menu Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredSearch restaurants near a location, or fetch full menus for specific restaurants.Default "search"; Allowed search, menu
    locationPostcode or city (search mode)stringA UK postcode/outcode (e.g. EC4M, SW1A 1AA) or a major UK city name (e.g. London, Manchester). In menu mode, an optional location used to resolve numeric restaurant IDs.Example "London"
    cuisineCuisine filterstringOnly emit restaurants whose cuisines include this. Restaurants with no cuisine data always pass through.Default "Any"; Allowed Any, Pizza, Indian, Chinese, Italian, Chicken, Burgers, Kebab and 38 more
    sortBySort orderstringHow to order emitted restaurants.Default "relevance"; Allowed relevance, rating, deliveryTime, distance
    openNowOnlyOpen now for delivery onlybooleanOnly emit restaurants currently open for delivery.Default false
    minRatingMinimum star ratingintegerDrop restaurants below this star rating (1-5). Restaurants with no rating data always pass through.Allowed 1 to 5
    restaurantIdsRestaurants (menu mode)arrayRestaurant menu URLs (https://www.just-eat.co.uk/restaurants-<slug>/menu), slugs, or numeric IDs. Numeric IDs also need location so they can be resolved to a slug.Default []
    offsetStart offsetintegerSkip this many matching restaurants before emitting records. Combine with maxItems to page through the whole search result set.Default 0; Allowed 0 to 100000
    maxItemsMax itemsintegerMaximum number of records to emit.Default 20; Example 3; Allowed 1 to 500
    proxyConfigurationProxy configuration (optional)objectJust Eat's search API uses Cloudflare bot management. The actor automatically falls back to the included Apify AUTO proxy, so you don't need to configure anything. Supply a proxy only if you want to override that automatic choice.
