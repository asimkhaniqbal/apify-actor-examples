    eBay Item, Store & Store Category Detail Extractor is an Apify Actor published by Vexaloom Labs. It accepts 19 input fields, none of them required at the top level. Each result can carry up to 73 declared fields, including recordType, title, price, condition, seller and storeName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    eBay Item, Store & Store Category Detail Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to scrapestringItem details opens the item pages you list. Store inventory walks a seller's whole store. Store category walks one category inside a store. Keyword search finds matching listings.Default "search"; Allowed item, store, storeCategory, search
    itemIdsItem IDs or URLsarrayeBay item IDs (for example 257633093777) or full /itm/ links. Used in Item details mode.Default []
    storeNamesStore names or URLsarraySeller store names (for example discountcomputerdepot) or /str/ store links. Used in Store inventory mode.Default []
    storeCategoryUrlsStore category URLsarrayStore-category links copied from a store page, for example https://www.ebay.com/str/mystore/Laptops/_i.html?store_cat=1234567890. Used in Store category mode.Default []
    searchQueriesSearch keywordsarrayKeywords to search on the selected marketplace. One search per entry. Used in Keyword search mode.Default []; Example ["laptop"]
    startUrlsPaste any eBay URLs (optional shortcut)arrayPaste item, store, store-category, category-browse or search links and each is routed to the right mode automatically. Ignored when the arrays above already cover that source.Default []
    marketplaceMarketplacestringCountry site used for names and keywords, and for any input that is not already a full URL.
