Reed.co.uk UK Job Listings & Pay Extractor

Search live Reed.co.uk vacancies by keyword and location and get structured job records with parsed pay ranges, job type, remote status and job descriptions.

Read the full published documentation

Reed.co.uk UK Job Listings & Pay Extractor

Pull live UK vacancies from Reed.co.uk into a clean dataset with full job descriptions, parsed pay ranges, employer details, location metadata and direct job links. Search by keyword, location, salary band, contract type, work arrangement and posting date, or scrape Reed search and job URLs you already have.

What this actor does

  • Searches Reed.co.uk by keyword and location, with filters for salary, job type, full/part-time, remote/hybrid/on-site, date posted, agency vs employer, graduate roles, Easy Apply, visa sponsorship and 37 sectors
  • Runs one search or several keyword searches in a single run, and accepts Reed search URLs or individual job URLs/IDs
  • Opens each job page to capture the full description, the displayed salary, annualised pay for hourly/daily/weekly/monthly roles, postcode, region, sector, skills and recruiter reference
  • Returns up to 10,000 jobs per search, deduplicated by Reed's job ID, with canonical job and employer URLs
  • Omits fields Reed does not publish for a job, so every record contains only real data

Output per job

Identity and links:

  • jobId — Reed's numeric job identifier
  • sourceUrl — canonical Reed job page
  • title, companyName, companyUrl, companyLogoUrl
  • recordType — always job
  • scrapedAt — collection timestamp

Location:

  • location, town, county, region, country, countryCode, postCode
  • remoteWorking — Remote, Hybrid or On-site
  • isRemote

Pay:

  • salaryDescription — the salary text Reed displays
  • salaryFrom, salaryTo — hourly, daily, weekly, monthly or annual bounds
  • salaryFromPerAnnum, salaryToPerAnnum — annualised bounds for easy comparison
  • salaryCurrency, salaryType
  • salaryIsNegotiable, salaryIsCompetitive, salaryIsOte, salaryIsProRata

Job and employer:

  • jobType — Permanent, Contract or Temporary
  • postedBy — Agency, Employer or Reed
  • recruiterReference
  • isFullTime, isPartTime, isEasyApply
  • category, subcategory, sector, sectorParent
  • skills

Description and dates:

  • description — full plain-text description
  • descriptionHtml — full HTML description
  • datePosted, dateUpdated, displayDate, expiryDate

Flags and provenance:

  • isGraduate, isPromoted, isFeatured, isEarlyBird, isTrainingJob, isSurveyJob
  • eligibleUkOnly, requiresUkEligibility, eligibilityRequirement
  • isLive, isRedirect
  • searchQuery, searchLocation
  • externalUrl — kept for compatibility; Reed's public pages do not expose an external apply URL, so it is normally omitted

FAQ

Do I need a Reed account or API key? No. The actor reads Reed.co.uk's public job pages. There is no login, key or cookie to supply.

Do I need to configure a proxy? No. The actor fetches Reed directly and can fall back to Apify's datacenter proxy automatically if Reed blocks the runner IP. There is no proxy setting to supply.

Why do some jobs have no salary fields? Reed lets employers hide pay. When a listing has no pay data, the salary fields are left out of that record rather than filled with a guess.

What does salaryFromPerAnnum add? It converts hourly, daily, weekly and monthly pay to an annual figure using Reed's own annualised values, so a £450/day contract can be compared with an £85,000 permanent role.

How many jobs can one search return? Reed exposes at most 10,000 results per search. The actor stops at that window and tells you in the run message; split a broad search by keyword, location or sector to collect more.

Why is externalUrl usually missing? Reed's public job pages do not include the employer's external application URL. The actor keeps the field for older integrations but does not invent a link.

Why are skills or postCode missing on some jobs? Reed only publishes them when the employer supplies them. The description, pay, location and dates are still returned.

Does fetchDetails: false still return descriptions? No. Turning details off makes runs faster and returns the listing fields only; the full description and detailed salary breakdown require opening the job page.

What happens if a job page is unavailable? The listing record is still returned with its title, company, location and search-page pay data; only the detail-only fields such as the full description are omitted.

Are duplicate jobs possible? The actor deduplicates by Reed's job ID across pages and searches. Reed's result order can shift slightly between requests, so this is necessary even on a single search.

Is this affiliated with Reed.co.uk? No. It is an independent tool that reads publicly available job listings and is not endorsed by or affiliated with Reed.co.uk.
