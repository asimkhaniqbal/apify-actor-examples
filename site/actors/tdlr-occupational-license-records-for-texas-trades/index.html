    Input reference

    All 11 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredHow to look up licenses. The three name modes return the same record shape; they only change which name column the search matches.Default "byName"; Allowed byName, byOwnerName, byBusinessName, byLicenseNumber
    nameQueryName to search (name modes)stringCase-insensitive partial match against the license holder name in byOwnerName, the business/DBA name in byBusinessName, or either in byName (e.g. Smith or Star Electrical). Optional if licenseType, countyFilter, cityFilter or zipFilter is set — leaving it blank then browses all licenses matching those filters.Default "Smith"
    licenseNumberLicense number (mode=byLicenseNumber)stringThe TDLR license number, e.g. 11484. Note: TDLR numbers licenses per trade category, so the same number can be shared across different license types — use licenseType to disambiguate.Example "11484"
    licenseTypeFilter by license type / trade categorystringOnly emit licenses of this TDLR trade category. The list mirrors the 86 categories currently present in TDLR's published dataset; the two legacy Behavior Analyst labels at the end are accepted for saved tasks and mapped to their current names.Default ""; Allowed , A/C CE Provider, A/C Contractor, A/C Technician, Appliance Installation Contractor, Appliance Installer, Apprentice Electrician, Apprentice Sign Electrician and 81 more
    countyFilterFilter by Texas countystringOnly emit licenses whose business or mailing county is this county. Values are TDLR's own uppercase county names; OUT OF STATE covers out-of-state licensees. Saved tasks using mixed-case text still work.Default ""; Allowed , ANDERSON, ANDREWS, ANGELINA, ARANSAS, ARCHER, ARMSTRONG, ATASCOSA and 248 more
    cityFilterFilter by citystringOnly emit licenses whose business or mailing city matches, e.g. Austin, San Antonio or Green Bay. Case-insensitive exact city match; a trailing state or ZIP is accepted and ignored.
    zipFilterFilter by ZIP codestringOnly emit licenses whose business or mailing ZIP starts with this 5-digit code, e.g. 78701. ZIP+4 input is accepted and truncated to the 5-digit prefix.
    statusFilterFilter by license statusstringOnly emit licenses that are currently active or expired, based on the license expiration date. Leave unset for both.Default ""; Allowed , active, expired
    sortBySort orderstringOrder results are fetched/emitted in. Defaults to license number.Default "licenseNumber"; Allowed licenseNumber, ownerName, businessName, expirationDate
    sortDirectionSort directionstringAscending or descending for the selected sort field. Expiration sorting is chronological, not month-first text order.Default "asc"; Allowed asc, desc
    maxItemsMax itemsintegerHard cap on emitted license records.Default 20; Allowed 1 to 5000
