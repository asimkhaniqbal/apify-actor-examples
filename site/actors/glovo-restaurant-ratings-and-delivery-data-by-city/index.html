    Glovo Restaurant Ratings & Delivery Data by City is an Apify Actor published by Vexaloom Labs. It accepts 12 input fields, and mode and city are required. Each result can carry up to 11 declared fields, including name, cuisine, city, rank, rating and reviewCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (browse american-style restaurants in madrid). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    Glovo Restaurant Ratings & Delivery Data by City uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredBrowse restaurants lists every restaurant Glovo shows for the selected city (optionally filtered by cuisine). Search additionally filters restaurants by a keyword matched against the restaurant name and cuisine tag.Default "restaurants"; Allowed restaurants, search
    cityCitystring requiredCity to scrape Glovo restaurants for.Default "madrid"; Allowed madrid, barcelona, valencia, sevilla, bilbao, malaga, milano, roma and 11 more
    querySearch keywordstringRequired when mode=search. Matched (case-insensitive) against restaurant name and cuisine tag, e.g. pizza, sushi, mcdonald.Example "pizza"
    cuisineCuisine filterstringOptional. Matched case-insensitively against Glovo's cuisine tags, e.g. Pizza, Sushi, Italiana, Burgers. Tags are shown in the local language of the selected city; pizza and burgers work in every market.
    minRatingMinimum ratingintegerDrop restaurants with a customer satisfaction score (0-100) below this value.Allowed 0 to 100
    onlyOpenOnly currently openbooleanOnly return restaurants that are currently open for delivery.Default false
    onlyTopRatedOnly top-ratedbooleanOnly return restaurants Glovo has flagged as top-rated.Default false
    onlyWithPromotionsOnly with active promotionsbooleanOnly return restaurants that currently have at least one active discount/deal (e.g. percentage off, 2x1).Default false
    sortBySort orderstringOrder in which Glovo lists the restaurants: its own recommendation order, customer rating, delivery fee, or distance from the city centre.Default "recommended"; Allowed recommended, rating, deliveryFee, distance
    maxItemsMax itemsintegerHard cap on emitted records. Glovo embeds 50 restaurants per category page; larger values scan additional cuisine-filtered pages until the cap or maxPages is reached.Default 20; Allowed 1 to 500
    maxPagesMax listing pagesintegerMaximum number of Glovo listing pages to request (the first page plus cuisine-filtered pages). Each page carries up to 50 restaurants and requests are deduplicated.Default 10; Allowed 1 to 45
    proxyConfigurationProxy configurationobjectOptional. Glovo does not require a proxy from most locations, but you can enable Apify's free datacenter proxy (AUTO group) for extra reliability.Default {"useApifyProxy": false}
