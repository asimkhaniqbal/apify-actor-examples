Each result can carry up to 20 declared fields, including recordType, storyId, persistentId, headline, category and topics. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (brand monitoring by keyword). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxStories (default 20, maximum 500) and maxArticlesPerStory (default 100, maximum 1000) cap how many results a run collects, and so what it costs.

    What it costs

    Yandex News Story Clusters Across Russia & the CIS uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 18 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape. searchNews searches keywords, browseCategory reads a rubric feed, topStories reads the homepage sections, and byStoryUrls resolves specific story clusters.Default "searchNews"; Allowed searchNews, browseCategory, topStories, byStoryUrls
    searchQueriesSearch queriesarrayOne or more keywords or phrases (mode=searchNews). Russian and English queries are supported. The daily-test prefill uses one query.Example ["Яндекс"]
    categoryCategorystringRubric to browse (mode=browseCategory). all reads all 16 rubrics in one run.Default "politics"; Allowed all, politics, society, svo, business, world, sport, incident and 9 more
    storyUrlsStory URLs or cluster IDsarrayDzen News story or instory URLs, or bare cluster UUIDs (mode=byStoryUrls). A bare numeric persistent ID is not a valid cluster URL.Example []
    maxStoriesMaximum story clustersintegerMaximum number of story clusters to return across the whole run. Yandex search depth varies by query.Default 20; Example 3; Allowed 1 to 500
    sortOrderSort orderstringOrder of the returned search clusters (mode=searchNews). Yandex search itself is relevance-ranked; these options sort the returned set.Default "newest"; Allowed relevance, newest, oldest, mostCovered
    timeRangePublication timestringKeep clusters published in this window (mode=searchNews). Applied to the results Yandex returns. A custom date range overrides this field.Default "any"; Allowed any, day, week, month
    publishedAfterPublished afterstringInclusive start date in YYYY-MM-DD format (mode=searchNews). Leave blank for no lower bound.
    publishedBeforePublished beforestringInclusive end date in YYYY-MM-DD format (mode=searchNews). Leave blank for no upper bound.
    includeDomainsInclude source domainsarrayKeep a cluster when at least one linked article is from one of these domains (for example rbc.ru).Default []
    excludeDomainsExclude source domainsarrayDrop a cluster when any linked article is from one of these domains.Default []
    includePublishersInclude publishersarrayKeep a cluster when any linked source name contains one of these values (case-insensitive).Default []
