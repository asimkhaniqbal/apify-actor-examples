Craigslist Classifieds Scraper with Category Attributes

Scrape Craigslist search results and individual posts across any city subdomain, with category-specific attributes for jobs, housing, autos, and for-sale posts. No login or proxy required.

Open on ApifyGitHub source

Input fields, types, required flags, descriptions, defaults, and prefills come from the published definition. Prefill examples are distinct from defaults.

FieldTypeRequiredDescription
modestringrequiredWhat to collect: keyword search, a category browse, specific Craigslist URLs, or the region/subarea reference list.
regionstringoptionalCraigslist city/region to search (mode=search/category). Pick a common region, or use Custom region for any of the 707 Craigslist sites.
customRegionstringoptionalAny Craigslist hostname or abbreviation (e.g. humboldt, tokyo, sfbay). Overrides Region. (mode=search/category)
subareastringoptionalOptional Craigslist subarea abbreviation inside the region (e.g. sfc, eby, brk). Leave blank for the whole region. (mode=search/category)
categorystringoptionalCraigslist category to search or browse. The default is all for-sale listings.
searchQueriesarrayoptionalOne or more keywords. Each query is searched separately; results are de-duplicated. Leave empty for a category browse. (mode=search)
startUrlsarrayoptionalCraigslist search pages, new-style /view/d/... post URLs, or old /region/category/post-id.html URLs. (mode=byUrl)
minPriceintegeroptionalOnly listings at or above this price. Posts without a price are excluded when a price filter is set.
maxPriceintegeroptionalOnly listings at or below this price. Posts without a price are excluded when a price filter is set.
postedTodaybooleanoptionalOnly listings posted in the last 24 hours (Craigslist's posted-today filter).
hasImagebooleanoptionalOnly listings with at least one photo.
titlesOnlybooleanoptionalMatch the keywords against titles only instead of titles and descriptions.
sellerTypestringoptionalFilter by owner, dealer, or either.
sortBystringoptionalOrder of results within each query.
conditionstringoptionalFor for-sale and auto categories: only items in this condition.
minBedroomsintegeroptionalHousing only.
maxBedroomsintegeroptionalHousing only.
minBathroomsintegeroptionalHousing only.
maxBathroomsintegeroptionalHousing only.
minSqftintegeroptionalHousing only.
maxSqftintegeroptionalHousing only.
autoMakeModelstringoptionalAuto categories only, e.g. honda civic.
minAutoYearintegeroptionalAuto categories only.
maxAutoYearintegeroptionalAuto categories only.
maxAutoMilesintegeroptionalAuto categories only.
postalCodestringoptionalOptional ZIP/postal code to anchor the search geographically. Use with Search radius.
searchRadiusMilesintegeroptionalDistance around the postal code. Requires Postal code.
hideDuplicatesbooleanoptionalAsk Craigslist to group duplicate/reposted listings together.
deliveryAvailablebooleanoptionalFor-sale and auto categories: only listings offering delivery.
cryptoOkbooleanoptionalFor-sale and auto categories: only listings that accept crypto.
countryCodestringoptionalTwo-letter country code to filter the areas list (mode=areas), e.g. US, CA, GB. Leave blank for all 707 sites.
maxItemsintegeroptionalHard cap across all queries and URLs. Craigslist returns at most 10,000 results per search.
includeDetailsbooleanoptionalFetch each listing's full description, attributes, images, coordinates, and repost status. Turn off for faster search-card-only results.

Craigslist Classifieds Scraper with Category Attributes

Scrape Craigslist across 700+ local sites without a login, cookie, or proxy setup. Search by keyword or browse a category, follow individual post links, and get the full listing: price, description, every photo, map coordinates, posted and repost data, plus the category-specific attributes Craigslist shows for jobs, housing, autos, and for-sale items.

What this actor does

  • Four modes: keyword search, category browse, specific URLs, and a region/subarea reference list
  • 700+ regions: every Craigslist hostname, with 62 common regions ready in a dropdown and a custom-region field for the rest
  • Filters that run on Craigslist: price, posted today, photos, titles-only, owner/dealer, sort, condition, bedrooms/baths/square feet, vehicle make/year/mileage, postal radius, and duplicate grouping
  • Full detail records: body text, gallery images, attributes, coordinates, display address, repost link, notices, and typed category fields
  • Empty fields are omitted from every record; no null values or placeholder rows

Output per listing

  • type — always craigslist_listing
  • id, postingUuid, url, title
  • price, priceValue, priceCurrency, priceQualifier
  • postedAt, updatedAt, recordCreatedAt, scrapedAt
  • region, location, neighborhood, subArea, area, areaAbbr, locationType, mapAddress
  • latitude, longitude
  • category, subcategory, section, categoryAbbr, subcategoryAbbr, postingType
  • description, images[], imageCount, attributes, notices[]
  • phoneNumbers[], emails[], vin, replyUrl
  • repostOf, hasContactInfo, seeMyOther
  • Jobs: compensation, employmentType, jobTitle, companyName, experienceLevel, salary
  • Housing: bedroomCount, bathroomCount, sqft, availableDate, housingType, laundry, parking, rentPeriod, listedBy, applicationFee, brokerFee, openHouseDates, catsOk, dogsOk, furnished, smoking, privateRoom, privateBath, wheelchairAccessible, airConditioning, evCharging
  • Autos: yearManufactured, makeManufacturer, modelName, odometer, transmission, fuelType, titleStatus, cylinders, paintColor, drive, vehicleType
  • For sale: condition, size, make, model

With includeDetails off, rows contain only the search-card fields: identity, price, category, posted time, location, coordinates, and image URLs.

Output per area (mode = areas)

  • type — craigslist_area
  • areaId, abbreviation, hostname, description, shortDescription
  • region, country, latitude, longitude, timezone
  • subareas[] — each with abbreviation, description, and subAreaId

FAQ

Do I need a Craigslist account, cookie, or proxy? No. The actor reads public Craigslist listings and connects automatically. There is no login or proxy field to fill in.

How many results can one run return? Craigslist caps a single search at 10,000 results. To collect more, split by category, subarea, price range, or posted-today and combine the runs. The actor tells you in the run status when the cap is reached.

Why are some fields missing from a row? Craigslist posts differ by category and by what the seller filled in. A job may have no price; a generic for-sale post may have no structured attributes; a seller may not publish a phone number. Empty fields are omitted rather than filled with null or an empty value.

Can I get the poster's email address? Only when the seller typed an email into the post body. Craigslist's reply relay hides the real address behind its own form and sometimes a captcha; this actor does not bypass that.

Does the actor support RSS or JSON feeds? No. Craigslist discontinued its RSS output, and its old output=json parameter no longer returns JSON. This actor uses Craigslist's current listing data and returns the same fields in its dataset.

Can I paste an old Craigslist post link? Current /view/d/... links work directly. Older region/category/post-id.html links also work. Very old links that contain a /d/ slug but a broad category are resolved by searching for the post; if Craigslist has removed it, the URL is skipped with a message.

Does an old search URL's s= offset still work? No. Craigslist no longer offers an offset cursor for search results, so the actor ignores s= and starts from the first result. Use maxItems, a narrower price range, or a subarea to control how deep a run goes.

Why did a run return no listings? The query may have no matches, the category may not exist in that region, the post may have been removed, or a filter may be too narrow. A zero-result run completes with a status message and no placeholder record.

Is this affiliated with Craigslist? No. This is an independent actor that reads publicly available Craigslist pages and is not operated or endorsed by Craigslist.
