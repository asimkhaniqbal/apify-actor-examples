    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (one playlist, metadata only). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPlaylistsPerProfile (default 20, maximum 100) and maxItems (default 0, maximum 100000) cap how many results a run collects, and so what it costs.

    What it costs

    TikTok Playlist Discovery & Video Order Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
