Each result can carry up to 8 declared fields, including recordType, title, company, topic, createdAt and viewCount.     Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword search). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    TeamBlind Topic, Company & Post Thread Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape.Default "searchPosts"; Allowed searchPosts, byPost, byTopic, byCompany, byUrl
    querySearch query (mode=searchPosts)stringFree-text search query. TeamBlind's search returns matched posts ranked by relevance.Default "layoffs"
    topicTopic (mode=byTopic)stringTeamBlind topic / channel. The most popular feeds are listed here; if you need a less-common one use mode=byUrl.Default "Career"; Allowed Career, Compensation, Interview, Tech, Layoffs, Startups, Investing, Real-Estate and 7 more
    companiesCompanies (mode=byCompany)arrayCompany slugs as they appear in TeamBlind URLs (e.g. Google, Amazon, Meta, Microsoft, Apple, Netflix, Salesforce, Uber, Airbnb, Stripe).Default ["Google"]
    postUrlsPost URLs (mode=byPost / byUrl)arrayFull TeamBlind post URLs (e.g. https://www.teamblind.com/post/...). For mode=byUrl you can also paste topic / company / search URLs.Default []
    sortBySort order (mode=byTopic / byCompany)stringSort feed by recency (default) or popularity.Default "newest"; Allowed newest, popular
