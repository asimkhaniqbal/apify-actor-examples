Each result can carry up to 16 declared fields, including record_type, pin_id, pinterest_url, media_url, media_type and media_format. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (download specific pins). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxComments (default 10, maximum 20000) caps how many results a run collects, and so what it costs.

    What it costs

    Pinterest Media Downloader uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 17 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to downloadstring requiredAuto handles both Pin links and search phrases. Choose a specific mode to restrict the run to links or search.Default "auto"; Example "pinDetail"; Allowed auto, pinDetail, searchPins, searchVideos
    pinUrlsPinterest Pin URLs or IDsarrayPublic Pin links (https://www.pinterest.com/pin/123...) or numeric Pin IDs. Used by auto and pinDetail.Default []; Example ["112027111109155913"]
    searchTermsSearch phrasesarrayPinterest search phrases. Used by auto, searchPins and searchVideos.Default []
    mediaTypeMedia typestringDownload all media, only images (GIFs count as images), only videos, or only animated GIFs.Default "all"; Allowed all, images, videos, gifs
    imageSizeImage sizestringPreferred image size. The actor falls back to the original or the nearest available size. Animated GIFs are always saved at their original size.Default "original"; Example "736x"; Allowed original, 736x, 564x, 474x, 236x
    videoQualityVideo qualitystringPreferred MP4 quality. The actor falls back to the nearest available quality and prefers H.264 MP4 files.Default "best"; Allowed best, 720p, 540p, 360p, 240p
    maxItemsMaximum media itemsintegerMaximum files to download per Pin URL or search phrase. Set to 0 to follow the available results.Default 50; Example 1; Allowed 0 to 20000
    maxPagesMaximum search pagesintegerMaximum result pages per search phrase. Set to 0 to follow Pinterest's pagination until it ends.Default 0; Allowed 0 to 2000
    minSavesMinimum savesintegerKeep media only when Pinterest reports at least this many saves.Allowed 0 to 10000000
    minCreatorFollowersMinimum creator followersintegerKeep media only when Pinterest reports at least this many creator followers.Allowed 0 to 1000000000
    verifiedOnlyVerified creators onlybooleanKeep only media whose creator Pinterest marks as verified.Default false
    requireOutboundLinkRequire destination linkbooleanKeep only Pins that publish a destination URL.Default false
