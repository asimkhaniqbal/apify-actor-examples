    Facebook Page & Profile Finder by Keyword or URL is an Apify Actor published by Vexaloom Labs. It accepts 16 input fields, and mode is required. Each result can carry up to 10 declared fields, including pageName, facebookUrl, entityType, verified, category and likes. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search pages and profiles). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResults (default 50, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    Facebook Page & Profile Finder by Keyword or URL uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 16 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredChoose whether to discover Pages/profiles by keyword or read the Facebook URLs you already have.Default "search"; Allowed search, urls
    searchQueriesSearch KeywordsarrayKeywords to search on Facebook (mode=search), e.g. 'coffee shop', 'dentist Berlin'. A pasted facebook.com/search/pages/?q=... URL is accepted too. Either this or startUrls is required.Example ["McDonald's"]
    searchTypeResult TypestringSearch for Pages, public profiles, or both. Applies to mode=search.Default "pages"; Allowed pages, people, all
    locationLocation Hint (optional)stringA city or country added to every keyword, e.g. 'Berlin' or 'Kansas City, Missouri'. Facebook search is relevance-ranked, so this narrows results toward that place; it is not a strict geographic filter.
    locationUidsLocation UIDs (partitioned pages search)arrayOptional numeric Facebook Place IDs, one page search per UID, e.g. 108591349161413 from facebook.com/places/<id>/. maxResults is distributed across the UIDs and duplicate pages are removed. Results can include nearby businesses; this is not a strict city boundary.
    categoryFilterCategory ContainsstringOptional case-insensitive text filter on a page's category, e.g. 'dentist' or 'restaurant'. Applied after page details are read; leave empty for all categories.
    startUrlsFacebook URLsarrayDirect Facebook Page or profile URLs to read (mode=urls), e.g. https://www.facebook.com/McDonalds, https://www.facebook.com/profile.php?id=..., /people/... or /p/.... Either startUrls, startIds or searchQueries is required.
    startIdsFacebook IDs or HandlesarrayNumeric Facebook IDs or @handles to read (mode=urls), e.g. 100064458773195 or @McDonalds. Combine with startUrls if you have both. Either startUrls, startIds or searchQueries is required.
    maxResultsMaximum ResultsintegerUpper bound on rows per search query (mode=search) or in total (mode=urls). Facebook may return fewer when the index is exhausted. Deep searches use extra networking automatically.Default 50; Example 1; Allowed 1 to 5000
    fetchPageDetailsFetch Page DetailsbooleanOpen each result to add category, contact details, follower counts, ratings and reviews links. Turn off for a fast identity-only list of names, URLs, IDs and verification badges.Default true; Example false
    includeReviewsInclude ReviewsbooleanFetch up to 10 real reviews per page when Facebook publishes them. Adds one request per result.Default true; Example false
    addDetailInclude Page TransparencybooleanAdd creation date, whether the Page is currently running ads, and its public Page Transparency ID. Adds one request per result.Default false
