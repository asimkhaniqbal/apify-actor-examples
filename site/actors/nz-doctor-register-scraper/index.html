    NZ Doctor Register Scraper is an Apify Actor published by Vexaloom Labs. It accepts 7 input fields, none of them required at the top level. Each result can carry up to 7 declared fields, including fullName, profession, location, specialty, registrationStatus and certificateExpiryDate. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    NZ Doctor Register Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to do. 'Search by name' matches current and previous names; 'Browse by filters' ignores any keyword and pages through the register using the dropdowns.Default "search"; Allowed search, browse
    keywordName or registration keywordstringFree-text search across current and previous names. MCNZ also does phonetic matching (e.g. 'smith' can surface 'smyth'). Ignored in browse mode.Example "smith"
    professionProfessionstringRestrict to doctors or physician associates. The register lists both professions; choose 'All professions' to include every practitioner.Default ""; Example "doctor"; Allowed , doctor, physician-associate
    locationLocation (town / city)stringRestrict results to a practitioner's recorded practice town or city. Leave on 'All of New Zealand' to search nationwide.Default ""; Allowed , akaroa, alexandra, amberley, arrowtown, ashburton, auckland, aukland and 163 more
    specialtyType of medicine (specialty)stringRestrict results to a vocational scope / type of medicine. Practitioners with more than one scope match if any of their scopes matches.Default ""; Allowed , anaesthesia, cardiothoracic-surgery, clinical-genetics, dermatology, diagnostic-and-interventional-radiology, emergency-medicine, family-planning-and-reproductive-health and 29 more
    statusRegistration statusstringRestrict results to a current registration status.Default ""; Allowed , inactive, not-practising, practising, suspended
    maxItemsMax itemsintegerHard cap on the number of practitioner records emitted in this run.
