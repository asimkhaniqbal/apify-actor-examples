    Spotify Podcast Show & Episode Metadata Extractor is an Apify Actor published by Vexaloom Labs. It accepts 10 input fields, and mode is required. Each result can carry up to 10 declared fields, including recordType, name, showName, publisher, totalEpisodes and releaseDate. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Spotify Podcast Show & Episode Metadata Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect from Spotify.Default "searchShows"; Allowed searchShows, searchEpisodes, getShow, getEpisode
    searchQuerySearch querystringKeyword to search for in the selected search mode, for example 'true crime', 'daily news' or a host name.Default "true crime"
    showIdsShow IDs or linksarraySpotify show IDs, spotify:show: URIs or open.spotify.com/show/ links. Used by mode=getShow.Default []
    episodeIdsEpisode IDs or linksarraySpotify episode IDs, spotify:episode: URIs or open.spotify.com/episode/ links. Used by mode=getEpisode.Default []
    startUrlsStart URLsarrayMixed show and episode links. Show links are read when mode=getShow, episode links when mode=getEpisode. Regional /intl-xx/ links and embed links are accepted.Default []
    includeDetailsFetch full detailsbooleanFetch complete show or episode metadata for every search result, including descriptions, ratings, topics, release times, paywall flags and preview audio. Turn off for a faster, lighter search.Default true
    includeEpisodesInclude episodes when fetching a showbooleanWhen mode=getShow, also export the show's episode archive. Turn off to export only the show record.Default true
    releasedAfterReleased afterstringOptional YYYY-MM-DD date. Episodes older than this are skipped. In getShow mode, paging stops once the archive passes this date.Default ""
    releasedBeforeReleased beforestringOptional YYYY-MM-DD date. Episodes newer than this are skipped.Default ""
    maxItemsMax recordsintegerMaximum number of show and episode records to save. Search modes have a source ceiling of about 1,000 matching results.Default 50; Example 3; Allowed 1 to 5000
