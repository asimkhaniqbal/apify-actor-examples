TikTok Video Subtitle & Transcript Extractor

Pull the captions TikTok already has for a public video — automatic speech recognition, the creator's own caption track, and TikTok's machine translations — as timestamped segments and a clean plain-text transcript. Paste a batch of video URLs or IDs and get one row per language, with source flags, available languages, video metadata and optional VTT/SRT output. No account, login, cookies, or proxy setup.

What this actor does

  • Accepts full TikTok video URLs, @user/photo URLs, short share links, and bare numeric video IDs; duplicates are processed once
  • Returns one row per language, not one row per raw caption file
  • Reads both WebVTT captions and TikTok's creator-caption JSON format, so manually authored captions are not lost
  • Classifies every track from TikTok's raw labels as automatic, machine-translated, or creator-provided, with isAutoGenerated, isOriginalCaption, and isTranslation
  • Lists availableLanguages on every row and keeps the original language first
  • Includes the video's author, caption, publish date, duration, post type, and engagement counts
  • Can request TikTok's machine translations for listed languages (languages) or all 20 supported targets (includeAllTranslations); coverage varies by video and is best-effort
  • Can include ready-to-use vtt and srt fields
  • Can transcribe videos that have no captions with an optional local Whisper fallback; language detection is best-effort
  • Empty fields are omitted; the dataset never contains nulls, empty strings, or placeholder rows

Output per transcript row

  • postId — TikTok video ID
  • postUrl — canonical video URL
  • username — author's TikTok username
  • displayName — author's display name
  • caption — video description or caption
  • createdAt — publish timestamp (ISO 8601 UTC)
  • duration — video duration in seconds
  • postType — video or slideshow
  • authorId — TikTok author ID
  • authorVerified — whether the author is verified
  • playCount, likeCount, commentCount, shareCount, collectCount — engagement counts
  • languageCode — TikTok subtitle language code (e.g. eng-US, spa-ES, urd-PK)
  • languageId — TikTok's internal language ID
  • originalLanguageCode — the video's original spoken-language code (e.g. en, ur, my)
  • availableLanguages — every subtitle language obtained for the video
  • subtitleFormat — webvtt, creator_caption, or whisper_asr
  • source — raw source code: ASR, MT, LC, MU, or Whisper
  • sourceType — automatic, machine_translation, creator, or unknown
  • isAutoGenerated, isOriginalCaption, isTranslation — TikTok's flags, copied per track
  • version, variant — TikTok's subtitle version and variant labels
  • subtitleUrl — direct signed subtitle file URL (expires)
  • subtitleUrlExpiresAt — expiry of that URL (ISO 8601 UTC)
  • segments — [{ "start": 0.0, "end": 2.5, "text": "..." }, ...] with seconds
  • segmentCount — number of cues
  • transcript — full joined plain-text transcript
  • transcriptDuration — end time of the last cue in seconds
  • wordCount — approximate whitespace-delimited word count
  • vtt, srt — optional subtitle files when those toggles are on
  • scrapedAt — collection time (ISO 8601 UTC)

Input

Field Type Default Description
postUrls array of strings — TikTok video URLs, photo URLs, short share links, or bare IDs. Duplicates are processed once.
postIds array of strings — Numeric video IDs as an alternative to postUrls.

Use cases

  • Content repurposing — turn a batch of TikToks into blog posts, newsletters, or scripts using the transcript field
  • Multi-language research — compare the original wording with TikTok's translations across markets
  • Accessibility and compliance — archive captions and timed segments for audits or caption-quality reviews
  • Social listening — search what creators actually say, beyond the text caption
  • Translation and dubbing pipelines — feed timestamped segments into translation or voice tools
  • Creator research — collect every video's available languages and caption provenance at scale

FAQ

Do I need a TikTok account or cookies? No. The actor reads public pages and public subtitle files without authentication.

Why does one video produce more rows than another? One row is emitted per language obtained. A video with only its original caption produces one row; a video with an original track plus a translation produces two. Slideshows usually have no caption track, and videos without captions produce no rows unless Whisper is enabled. Caption coverage is not universal: in an independent October 2026 sample of 391 public videos across niches, 47.6% had at least one native caption track (51.8% excluding slideshows).

What is the difference between ASR, MT, LC, and MU? ASR is TikTok's automatic speech recognition. MT is normally a machine translation. LC is TikTok's label on the creator-caption tracks seen in this actor; MU is another label TikTok uses on the converted WebVTT twin of those tracks. Because those raw labels are not perfectly documented, use sourceType, isAutoGenerated, isOriginalCaption, and isTranslation for filtering. A small number of original-language tracks are labelled MT by TikTok (version whisper_lid); the actor preserves that raw label, so isOriginalCaption can be true on the same row as isTranslation. Use originalLanguageCode/languageCode to identify the original.

Why do some translations not appear? TikTok does not precompute every target language for every video. The actor requests English and Spanish through TikTok's translation endpoint and a fixed set of 18 more targets by refetching the video with the requested locale. Targets outside that set (for example German or Japanese) are not requested, even if TikTok's player lists them. The actor reports only the languages it actually obtained and never fabricates a track.

Why is subtitleUrl missing or expired? Native subtitle files are signed links that usually expire in about 48 hours. Links returned by TikTok's translation endpoint expire in about 6 hours. subtitleUrlExpiresAt gives the exact expiry for each row. The parsed segments and transcript are stored in the dataset permanently; use includeVtt or includeSrt if you need a portable file.

What happens when a video has no captions? No dataset row is added by default. The run status and the ERRORS key-value record report no_transcript. If a languages filter removes every available track, the video is also reported as no_transcript. Enable useWhisperFallback to transcribe the audio instead. Other ERRORS reasons are invalid, private, unavailable, blocked, fetch_failed, parse_failed, and translation_unavailable.

Does Whisper detect the language reliably? Not always. It is best on clear, longer speech; short or mixed-language clips can be mislabeled. The detected code is reported on the row and should be treated as a hint.

Can I scrape private, deleted, or region-restricted videos? No. Those videos do not expose a public video record, so they are reported as unavailable and no row is added.

How fresh is the data? Captions, metadata, and translation availability are read when the run executes. A video may gain captions or translations later; run it again to pick them up.

Is this affiliated with TikTok? No. This is a third-party actor using publicly available TikTok pages and subtitle files.
