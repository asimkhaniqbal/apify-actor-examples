TikTok Video Subtitle & Transcript Extractor

Pull the full subtitle stack off any public TikTok video — not just the first caption track, but every language TikTok attached to it, from the auto speech recognition (ASR) track to machine-translated (MT) versions and any other track TikTok lists. Point it at a video and get back one row per language with timed caption segments and a ready-to-use plain-text transcript. No account, login, or cookies needed.

What this actor does

  • Accepts full TikTok video URLs (/@user/video/ID, /video/ID, /embed/v2/ID) or bare numeric post IDs; duplicates are processed once
  • Returns one output row per video per language (e.g. a video with 6 languages produces 6 rows)
  • Provides both a full plain-text transcript field and a segments array with precise start/end/text cues
  • Identifies the subtitle source: ASR (auto speech recognition), MT (machine translation), or whatever other source code TikTok reports
  • Includes video metadata — username, display name, caption, publish date, duration — on every row
  • Supports an optional language filter so you only receive the language(s) you need
  • Skips a video with no usable captions rather than adding a placeholder row — the dataset only contains videos a transcript was actually found for (unless the optional Whisper fallback transcribes the audio)
  • Empty fields are omitted

Output per transcript row

  • postId — unique TikTok video ID
  • postUrl — canonical video URL
  • username — author's TikTok username
  • displayName — author's display name
  • caption — video description/caption text
  • createdAt — publish timestamp (ISO 8601)
  • duration — video duration in seconds
  • languageCode — TikTok's language code for the track (e.g. eng-US, fre-FR, spa), or the short code Whisper detected (e.g. en) on fallback rows
  • languageId — TikTok's internal language identifier (only on native-subtitle rows)
  • subtitleFormat — webvtt for TikTok's own subtitle tracks, or whisper_asr for a Whisper-generated fallback row
  • source — subtitle origin: ASR (auto speech recognition), MT (machine translation), Whisper for the ASR fallback, or other TikTok-reported source
  • version — subtitle version string from TikTok (base for Whisper-fallback rows)
  • variant — subtitle variant identifier from TikTok (asr_fallback for Whisper-fallback rows)
  • subtitleUrl — direct URL to the WebVTT subtitle file (omitted for Whisper-generated rows)
  • subtitleUrlExpiresAt — expiry timestamp of the subtitle URL, when TikTok provides one (native-subtitle rows only)
  • segments — array of timestamped cues: [{ "start": 0.0, "end": 2.5, "text": "..." }, ...]
  • segmentCount — number of caption segments
  • transcript — full joined plain-text transcript for this language
  • transcriptDuration — end time of the last caption segment, in seconds

A row is only produced when the subtitle file downloads and parses into at least one segment; tracks with no language code are skipped.

Input

Field Type Default Description
postUrls array of strings — TikTok video URLs to extract transcripts from. Full video URLs and bare numeric IDs work; vm.tiktok.com / vt.tiktok.com short links are not resolved and are skipped.
postIds array of strings — Numeric TikTok post IDs (alternative to postUrls).
languages array of strings – Optional language filter (case-insensitive prefix match on languageCode, e.g. ["eng-US", "fre-FR"]). Leave empty for all languages.
useWhisperFallback boolean false When enabled, videos with no native subtitles are transcribed from their audio with Whisper speech-to-text, producing one extra row per video. Adds significant processing time.

Use cases

  • Content repurposing — convert TikTok videos into blog posts, newsletters, or social copy using the plain-text transcript field
  • Multi-language SEO — harvest all MT subtitle tracks to identify keyword opportunities across markets
  • Accessibility tooling — build caption archives or compliance audits for brands and media companies
  • Journalism and research — extract verbatim quotes from news, political, or educational creators without manual transcription
  • Translation pipelines — feed segments arrays into translation APIs with exact timing for dubbed audio or subtitle files

FAQ

Q: Do I need a TikTok account or cookies?
A: No. The actor works entirely with public TikTok videos and requires no authentication.

Q: How many rows will I get per video?
A: One row per subtitle track TikTok exposes for that video. A video with only its auto-generated track yields one row; videos TikTok has machine-translated yield one row per translation as well.

Q: What is the difference between ASR and MT sources?
A: ASR (auto speech recognition) is the transcript TikTok generated from the video's own audio. MT (machine translation) is a TikTok-produced translation into another language. Any other source code TikTok reports is passed through as-is, and Whisper marks rows created by the optional fallback.

Q: What happens when a video has no subtitles?
A: That video is skipped — no row is added to the dataset for it, unless useWhisperFallback is enabled and Whisper can produce a transcript from the audio.

Q: Which URL formats are supported?
A: Standard video URLs (https://www.tiktok.com/@username/video/ID), tiktok.com/video/ID, tiktok.com/v/ID, embed URLs and bare numeric IDs. Short share links (vm.tiktok.com, vt.tiktok.com) are not expanded, so open them in a browser first and paste the full URL.

Q: Can I scrape private or deleted videos?
A: No. Private, deleted, or regionally restricted videos produce no usable video data, so no row is added for them.

Q: What is the languages filter format?
A: Case-insensitive prefix matching against TikTok's codes. For example, "eng" matches eng-US and eng-GB, while "eng-US" matches eng-US (and a bare eng track, since the match works in both directions). You can mix short and long codes in the same array. Whisper fallback rows use short codes such as en.

Q: Are slideshow (photo) posts supported?
A: Photo slideshows usually carry no subtitle tracks, so they normally produce no row.

Q: How fresh are the subtitle URLs?
A: subtitleUrl is a signed link that stops working after a while; subtitleUrlExpiresAt gives the cutoff when TikTok supplies it. The parsed segments and transcript are already in your dataset, so you only need the link if you want the original VTT file.

Q: Can I run this on hundreds of videos?
A: Yes. The actor processes URLs sequentially. For large batches, consider splitting across multiple runs.
