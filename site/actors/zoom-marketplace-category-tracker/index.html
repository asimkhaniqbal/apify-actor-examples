    Zoom Marketplace Category Tracker is an Apify Actor published by Vexaloom Labs. It accepts 7 input fields, none of them required at the top level. Each result can carry up to 7 declared fields, including rank, name, companyName, categories, usage and fedRampAuthorized. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Ways to track”, “Output per app”, “Input”, “Use cases”, “FAQ” and “Limitations”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 7 fields in 1 dataset view, and the README documents 13 more. Fields without a value can be left out of a record.

    What it costs

    Zoom Marketplace Category Tracker uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
