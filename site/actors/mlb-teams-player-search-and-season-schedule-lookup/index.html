    MLB Teams, Player Search & Season Schedule Lookup is an Apify Actor published by Vexaloom Labs. It accepts 4 input fields, and mode is required. Each result can carry up to 6 declared fields, including teamName, playerName, eventName, homeTeam, awayTeam and matchDate. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Pull Major League Baseball reference data in three shapes: the full list of current MLB teams with their stadium and founding details, a name search across MLB players with bio and position info, or a season's full schedule of games with final or in-progress scores.

    What this actor does

    • Lists every current MLB team with city, stadium, founding year, and official website
    • Searches MLB players by name and returns position, physical stats, nationality, and a short bio
    • Pulls a full season's game schedule with home/away teams, scores, venue, and status
    • Tags every record with a recordType so mixed exports stay easy to filter
    • Only includes a field when the data source actually supplied it — no blank or placeholder values

    Use cases

    • Fantasy baseball tools pulling player bios and team reference data to enrich a roster app
    • Sports content sites keeping a simple, always-current list of MLB teams and stadiums
    • Analytics projects building a season-by-season game log without hand-collecting scores
    • Trivia and reference apps looking up a player's position, nationality, or physical stats by name
    • Data pipelines that need a lightweight MLB reference layer without a paid sports-data subscription

    Questions

    Do I need an API key or MLB account?

    No — all three modes read from a free, public sports-data source and require no authentication.

    Why does players mode only return results for one name at a time?

    Each run searches the single name given in searchQuery; run it again with a different name to look up another player.

    Why are homeScore/awayScore sometimes missing from a game record?

    Those fields are only included once a score has actually been published for that game; scheduled-but-not-yet-played games omit them rather than showing a zero.

    Which seasons can I pull with games mode?

    2022, 2023, or 2024 — pick the one you need in the season input.

    Why is description cut off at 300 characters?

    Player biographies are truncated to keep records a consistent, manageable size; the full bio is not currently returned.

    Is this affiliated with Major League Baseball?

    No. This is an independent actor that reads publicly available MLB reference data; it is not endorsed by or affiliated with MLB or any team.
