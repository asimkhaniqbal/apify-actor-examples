    Haraj Classifieds Search & Seller Listings Scraper is an Apify Actor published by Vexaloom Labs. It accepts 36 input fields, and mode is required. Each result can carry up to 12 declared fields, including title, priceSAR, priceFormatted, category, subcategory and city. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Haraj Classifieds Search & Seller Listings Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    subTagBrand / model / sub-category tagstringNarrower than category — a specific brand or model tag from Haraj's own hierarchical tag tree, e.g. تويوتا (Toyota), كامري (Camry), ايفون (iPhone) (mode=search, browse).     carBodyTypeCar body typestringRestrict results to a specific car body style (mode=search, browse). Haraj's own frontend uses this exact 12-value vocabulary as a hidden filter axis, distinct from subTag's brand/model tags — confirmed via live probing that each value reliably narrows to the correct body style server-side. Since only one tag value can be sent upstream at a time, this takes priority over subTag/category for that slot when set (both still apply as extra client-side checks afterwards). Leave as "(any body type)" for no filter.Default ""; Allowed , سيدان صغيرة, سيدان, سيدان فاخرة, هاتشباك, كوبيه, اس يو في, جيوب and 5 more

    neighborhoodNeighborhood / town (fine-grained location)stringRestrict results to an exact match of Haraj's finer town/neighbourhood-level location tag (the geoCity output field) — e.g. الدرعية (Diriyah) or الخبر (Al Khobar). More granular than city/cities (which match the broader region) and combines with them as an AND. Free-text because Haraj's town list runs into the hundreds and isn't a stable curated set — enter the exact value from a listing's own geoCity output field (mode=search, browse, byAuthor).Example ""
    excludeCategoryExclude categorystringDrop results from this category, even if they match other filters (mode=search, browse).Default ""; Allowed , حراج السيارات, حراج الأجهزة, حراج العقار, اثاث, خدمات, مستلزمات شخصية, مواشي وحيوانات وطيور and 14 more

    authorUsernameSeller / store username or URL (mode=byAuthor, seller)stringHaraj seller display name, @handler, or a full https://haraj.com.sa/users/... URL. Required for mode=byAuthor (all listings) and mode=seller (profile).
