Each result can carry up to 15 declared fields, including recordType, deviceName, brand, brandName, released and availability. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    GSMArena Device Database & Spec Sheet Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 11 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect: a keyword search, one or more full spec sheets, every device from a brand, the current rankings, or the list of brands.Default "search"; Example "deviceDetails"; Allowed search, deviceDetails, byBrand, topDevices, brands
    searchQuerySearch querystringKeyword matched against device names, aliases and URLs (mode=search). Leave empty to browse the catalog from the newest/popular end. Example: Samsung Galaxy S25.Default ""
    osFilterOperating systemstringKeep only devices with this OS (mode=search). Filtering by OS reads spec sheets, so it is slower than a plain search.Default "any"; Allowed any, android, ios, featurePhone, kaios, windowsPhone, symbian, blackberry and 2 more
    availabilityAvailabilitystringKeep only devices with this availability status (mode=search).Default "any"; Allowed any, available, comingSoon, discontinued, rumored, cancelled
    sortBySort orderstringResult order. Price, weight, camera and battery sorting reads spec sheets and is slower; missing values go last.Default "popularity"; Allowed popularity, newest, price, weight, camera, battery
    topChartRanking chartstringWhich GSMArena homepage ranking to use (mode=topDevices).Default "daily"; Allowed daily, fans
    deviceUrlDevice URL, slug or IDstringOne device for mode=deviceDetails. Accepts a full GSMArena URL, a slug, or a numeric device ID. Example: samsung_galaxy_s25_ultra-13322.Default ""; Example "samsung_galaxy_s25_ultra-13322"
    deviceUrlsDevice URLs, slugs or IDsarrayAdditional devices for mode=deviceDetails. The single field above and this list are combined and deduplicated.Default []
    brandSlugBrandstringBrand to list (mode=byBrand). Choose a brand or type a slug shown on GSMArena.Default "samsung"; Allowed acer, alcatel, allview, amazon, amoi, apple, archos, asus and 120 more
    maxItemsMax itemsintegerMaximum records to return. Brand searches can span thousands of devices; spec-sheet enrichment is capped to keep runs reliable.Default 20; Example 1; Allowed 1 to 2000
    includeDetailsInclude full spec sheetsbooleanFor search, brand and ranking modes, open each device page and return the complete spec sheet instead of the listing summary. Slower and capped; deviceDetails mode always returns full specs.Default false
