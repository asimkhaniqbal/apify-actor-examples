    What it costs

    Google Maps Address & Coordinate Geocoding Lookup uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 9 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringForward turns an address, place name or postal code into coordinates. Reverse turns a coordinate pair into the nearest address. Place ID resolves a Google Place ID or Maps URL. Mixed processes every list in one run.Example "forward"; Allowed forward, reverse, placeId, mixed
    addressAddress or place name (single)stringOne address, landmark, business name or postal code for forward geocoding. Example: 1600 Amphitheatre Parkway, Mountain View, CA.
    addressesAddresses or place names (batch)arrayOne address, place name or postal code per line. Add a country bias for ambiguous postal codes. A lat,lng line is treated as reverse geocoding.Example ["1600 Amphitheatre Parkway, Mountain View, CA"]
    locationCoordinates (single)objectOne reverse-geocoding point as {"lat": 40.7484, "lng": -73.9857}. Decimal degrees, WGS84.
    locationsCoordinates (batch)arrayA list of reverse-geocoding points. Each item is {"lat": 40.7484, "lng": -73.9857} or a "lat,lng" string.
    placeIdPlace ID or Google Maps URL (single)stringOne Google Place ID (starts with ChIJ) or a full Google Maps place URL. Returns the place's address, coordinates and structured components.
    placeIdsPlace IDs or Google Maps URLs (batch)arrayOne Google Place ID or Google Maps place URL per line.
    languageLanguagestringLanguage of the returned names, formatted address and country names. Google Maps translates the result; it does not translate the input.Default "en"; Allowed en, en-GB, de, fr, es, es-419, it, pt-BR and 27 more
    countryRegion bias (optional)stringOptional ISO 3166-1 alpha-2 country code. The country name is appended to forward queries so an ambiguous address is resolved in that country first. Leave empty for no bias.Default ""; Allowed , AD, AE, AF, AG, AI, AL, AM and 242 more
