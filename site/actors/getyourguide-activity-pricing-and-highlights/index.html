    GetYourGuide Activity Pricing & Highlights Extractor is an Apify Actor published by Vexaloom Labs. It accepts 21 input fields, none of them required at the top level. Each result can carry up to 60 declared fields, including title, city, country, price, currency and rating. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What it does”, “Output per activity”, “Input”, “Modes and pagination”, “Legacy inputs” and “Limits and honest notes”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search with filters). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    GetYourGuide Activity Pricing & Highlights Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    searchQueriesSearch queriesarrayCities, landmarks, or activity keywords to search on GetYourGuide. One search per item, e.g. 'rome', 'eiffel tower', 'food tour paris'. Used for the keyword-search mode.Example ["rome"]
    startUrlsStart URLs (optional)arrayGetYourGuide URLs or activity IDs. Accepts search pages (/s/?q=...), destination/attraction pages (…-l<id>/), category pages (…-tc<id>/), activity pages (…-t<id>/), and bare IDs such as 631866 or t631866. URL query filters are preserved.
    activityIdsActivity IDs (optional)arrayDirect GetYourGuide activity IDs. Each ID opens its activity page and returns full detail fields.
    maxItemsMax itemsintegerMaximum activities to return across all queries, URLs, and IDs.Default 30; Example 1; Allowed 1 to 2000
    includeDetailsFetch activity detail pagesbooleanOpen each activity page to add full descriptions, highlights, inclusions, exclusions, meeting point, cancellation policy, supplier, and review fields. Turn off for the fastest search-card-only runs.Default true; Example false
    maxReviewsReviews per activityintegerHow many recent reviews to attach to each activity (0 disables reviews). Only used when detail pages are fetched.Default 0; Allowed 0 to 50
    currencyCurrencystringCurrency for all prices.Default "USD"; Allowed USD, EUR, GBP, AUD, CAD, CHF, JPY, INR and 32 more
    languageContent languagestringLanguage for titles, descriptions, highlights, and policies.Default "en"; Allowed en, de, fr, es, it, pt, nl, pl and 23 more
    sortBySort resultsstringOrder of search and listing results.Default "popularity"; Allowed popularity, rating, price_asc, price_desc
    minRatingMinimum ratingstringOnly return activities with at least this star rating.Default "any"; Allowed any, 3.0, 3.5, 4.0, 4.5
    priceMinMinimum priceintegerMinimum starting price in the selected currency. 0 means no minimum.Default 0; Allowed 0 to 100000
    priceMaxMaximum priceintegerMaximum starting price in the selected currency. 0 means no maximum.Default 0; Allowed 0 to 100000
