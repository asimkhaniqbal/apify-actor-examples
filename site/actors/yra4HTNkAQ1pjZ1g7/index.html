Fiverr Gig & Seller Sitemap Directory Scraper

Scrape Fiverr gigs, sellers and directories without an account, cookies or API keys. Search live gig results by keyword or category, open full gig pages for packages and reviews, read seller profiles, and list Fiverr's public sitemap catalog of 280,000+ gigs and 280,000+ sellers. Results are real, structured and exported as JSON, CSV or Excel.

What this actor does

  • Four modes: search, gigDetails, sellerProfiles, sitemapDirectory
  • Live search with Fiverr's own filters for seller level, country, language, delivery time, budget, Pro, online, agency and hourly gigs, plus five sort options
  • Full gig detail with every package tier, features, paid extras, FAQ, ratings breakdown, latest reviews, gallery, seller card and orders in queue
  • Seller profiles with level, response time, rating, skills, certifications, education, languages, portfolio count, notable clients, all gigs and latest reviews
  • Full sitemap directory for gigs, sellers, categories, search tags and Logo Maker ideas, including exact sitemap counts and category IDs
  • Backward compatible: the original discovery mode names still work, and every existing output field is kept
  • Empty fields are omitted — records never contain nulls or placeholder strings

FAQ

Is this affiliated with Fiverr? No. This is an independent third-party actor that reads Fiverr's public pages and sitemaps. It is not affiliated with or endorsed by Fiverr.

Do I need a Fiverr account, cookies or an API key? No. There are no login, cookie or API-key inputs. Fill in a mode and run it.

Do I need to configure a proxy? No. The actor chooses a working connection to Fiverr automatically.

Why does a search return fewer gigs than Fiverr says exist? Fiverr's search window is shallower than the headline total and varies by query. On 2026-10-26 a logo design search returned 11 pages (516 cards) and about 328 unique gigs before Fiverr stopped; promoted gigs repeat across pages. The actor reads until Fiverr reports no further results, and maxPagesPerQuery is only an upper bound. Fiverr also echoes some requested sort or filter values without applying them. The actor validates the response and applies price sorts locally; unsupported filter values are named in the run log. Use narrower filters or the sitemapDirectory mode for the full public catalog.

What is the difference between search and sitemapDirectory? search reads live Fiverr search/category results with filters and sorting. sitemapDirectory reads Fiverr's public sitemaps, which cover 280,000+ gigs and 280,000+ sellers but only carry URL-level metadata.

Can I get a seller's email or phone number? No. Fiverr does not publish seller emails or phone numbers on public profiles.

How many reviews can I get? Gig and seller pages expose the latest reviews on the page, so the actor returns those reviews plus the full star breakdown and total count. It does not return every historical review.

Why are some fields missing on a record? Fields are omitted when Fiverr does not expose them for that gig or seller. The actor never fills missing values with guesses, nulls or placeholders.

How fresh is the data? Search, gig and seller records are read live at run time. Directory records follow Fiverr's latest sitemap refresh.

Can I still use the old mode names? Yes. discoverGigs, discoverSellers, discoverCategories, discoverTags, discoverLogoMakerIdeas and discoverAndFetchDetails map to the new directory and detail paths, and existing output fields are unchanged.
