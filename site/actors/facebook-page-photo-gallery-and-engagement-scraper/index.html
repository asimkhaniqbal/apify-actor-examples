    What it costs

    Facebook Page Photo Gallery & Engagement Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 512 MB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 8 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    startUrlsFacebook URLsarray requiredFacebook page, profile, photos tab, tagged tab, albums tab, album, or single-photo URL. Bare handles such as nasa are accepted too.Example [{"url": "https://www.facebook.com/humansofnewyork/photos"}]
    resultsLimitMaximum number of photosintegerGlobal cap across all Start URLs. The actor keeps paginating until this many photos are collected or the source runs out.Default 100; Example 1; Allowed at least 1
    newerThanOnly photos newer thanstringOnly include photos posted on or after this date (YYYY-MM-DD). Applied by Facebook for page and tagged tabs. For albums the actor reads each photo timestamp (even with includeDetails off) and applies the bound; rows stay grid-only.Example ""
    olderThanOnly photos older thanstringOnly include photos posted on or before this date (YYYY-MM-DD). Applied by Facebook for page and tagged tabs. For albums the actor reads each photo timestamp (even with includeDetails off) and applies the bound; rows stay grid-only.Example ""
    photoTabPhoto tabstringFor page and profile URLs: photos uploaded by the page, or photos where the page is tagged by others. Ignored for album and photo URLs.Default "uploaded"; Allowed uploaded, tagged
    includeAlbumsAlso collect albumsbooleanFor page and profile URLs, also walk every album listed on the page's Albums tab and collect its photos. A photos_albums URL implies this automatically.Default false
    includeDetailsInclude photo detailsbooleanOpen each photo to add its caption, timestamp, reactions, comments, shares, tagged people, owner, album, and post link. Turn off for a fast grid-only export; album date bounds still read only the timestamp needed for filtering.Default true
    storeImagesStore images permanentlybooleanCopy each full-size image and thumbnail to Apify storage and return non-expiring URLs. The signed Facebook originals and their expiry are kept in the record.Default true
