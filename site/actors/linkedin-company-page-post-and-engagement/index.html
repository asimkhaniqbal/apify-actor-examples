    LinkedIn Company Page Post & Engagement Extractor is an Apify Actor published by Vexaloom Labs. It accepts 20 input fields, none of them required at the top level. Each result can carry up to 7 declared fields, including companyName, postedAt, mediaType, reactionsCount, commentsCount and postUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per post”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 7 fields in 1 dataset view, and the README documents 24 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (daily prefill (smallest run)). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPostsPerCompany (default 10, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    LinkedIn Company Page Post & Engagement Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 20 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to scrape. "Auto" uses the targets you provide; the actor picks the right pipeline automatically.Default "auto"; Allowed auto, companyPosts, postUrls
    companyUrlsCompany URLs or SlugsarrayLinkedIn company pages to scrape. Accepts full URLs (https://www.linkedin.com/company/hubspot/), a posts URL, or just the slug (hubspot).Example ["https://www.linkedin.com/company/hubspot/"]
    postUrlsPost URLsarraySpecific LinkedIn post links to extract (any format: /posts/...-activity-..., share, ugcPost, or /feed/update/urn:li:...). Used in the "Specific post URLs" mode.
    maxPostsPerCompanyMax Posts Per CompanyintegerMaximum posts to return per company. LinkedIn itself stops a company's post history at 500 posts and one year; deeper older posts are reachable only through the public search index.Default 10; Example 2; Allowed 1 to 500
    postTypesPost TypesarrayWhich post media types to keep. Leave empty to keep every type.Default []; Allowed text, image, video, article, document, repost
    includeEmployeePostsInclude Employee PostsbooleanThe public company page mixes a few featured employee posts into its recent feed. Turn this on to include them; off returns the company's own posts (including its showcase/sub-brand pages) only.Default false
    includeIndexedPostsInclude Indexed Posts (deeper history)booleanAlso search the public web index for older company-authored posts. This finds more posts than the company page shows, but coverage depends on the search index.Default true; Example false
    datePostedPosted WithinstringKeep only posts published within this window. Applied to each post's real publish date.Default ""; Allowed , r86400, r604800, r2592000
    postedAfterPosted On or AfterstringOnly posts published on or after this date. Accepts YYYY-MM-DD or an ISO date-time.
    postedBeforePosted On or BeforestringOnly posts published on or before this date. Accepts YYYY-MM-DD or an ISO date-time.
    minReactionsMinimum ReactionsintegerSkip posts with fewer than this many reactions.Default 0; Allowed 0 to 10000000
    minCommentsMinimum CommentsintegerSkip posts with fewer than this many comments.Default 0; Allowed 0 to 10000000
