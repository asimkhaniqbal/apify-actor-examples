    Uline Catalog & Price Scraper is an Apify Actor published by Vexaloom Labs. It accepts 11 input fields, and mode is required. Each result can carry up to 7 declared fields, including itemNumber, description, price, className, groupName and subgroupName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Uline Catalog & Price Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    modeModestring requiredWhat to fetch from Uline.Default "browseByCategory"; Allowed browseByCategory, browseByUrl, search, productDetail
    productClassCatalog department (mode=browseByCategory)stringOne of Uline's 45 top-level catalog departments. The actor crawls every group and subgroup under it to collect real, in-stock products with prices.Default "Cls_04"; Allowed Cls_01, Cls_02, Cls_03, Cls_04, Cls_05, Cls_06, Cls_07, Cls_08 and 37 more

Crawls every product from that exact node down, without being limited to the 45 top-level departments in productClass.Default "https://www.uline.com/Grp_9/Corrugated-Boxes"
    keywordsSearch keywords (mode=search)stringFree-text keyword search, e.g. corrugated boxes 12x12x12, packing tape 2 inch, nitrile gloves. More specific phrases (including a size) return the most precise matches.Default "corrugated boxes 12x12x12"
    itemNumbersItem numbers (mode=productDetail)arrayUline item numbers, e.g. S-4992, or full product URLs.Default []
    minPriceMin pricenumberDrop products cheaper than this (in the currency of the selected country market — Uline prices are rarely whole numbers, e.g. 1.18).Allowed 0 to 1000000
    maxPriceMax pricenumberDrop products pricier than this (in the currency of the selected country market).Allowed 0 to 1000000
    sortBySort results bystringClient-side sort applied after fetching.Default "relevance"; Allowed relevance, priceLowToHigh, priceHighToLow, itemNumber, nameAToZ
    maxItemsMax itemsintegerHard cap on emitted records.Default 30; Allowed 1 to 500
    fetchFullDetailsFetch full product detailsboolean(mode=browseByCategory, browseByUrl, search) Fetch each result's own product page to add pack price, pack quantity, availability, color, dimensions, and price-valid-until date. Adds one extra request per result, so runs take longer. productDetail mode always includes these fields at no extra cost.Default false
    countryMarket / countrystringWhich localized Uline storefront to scrape. Changes the base domain, currency, and (for Mexico) language — the catalog structure and item numbers are identical across markets.Default "US"; Allowed US, CA, CA_FR, MX
