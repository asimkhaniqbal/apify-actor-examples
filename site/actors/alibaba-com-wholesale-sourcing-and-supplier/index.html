    Alibaba.com Wholesale Sourcing & Supplier Vetting Finder is an Apify Actor published by Vexaloom Labs. It accepts 13 input fields, and mode is required. Each result can carry up to 12 declared fields, including title, price, minOrder, supplier, supplierLocation and tradeAssurance. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Modes”, “Input”, “Output per product”, “Output per supplier” and “Data source and reliability”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (compare verified indian led suppliers). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Alibaba.com Wholesale Sourcing & Supplier Vetting Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 13 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredSearch products, search suppliers, or fetch specific product/supplier pages.Default "searchProducts"; Allowed searchProducts, searchSuppliers, productDetails, supplierDetails
    keywordSearch keywordstringProduct or supplier keyword, e.g. 'LED lights' or 'solar panel'. Used by both search modes.Default "LED lights"
    tradeAssuranceOnlyTrade Assurance onlybooleanKeep only products from suppliers that offer Alibaba Trade Assurance order protection.Default false
    verifiedSupplierOnlyVerified suppliers onlybooleanKeep only Gold Suppliers or suppliers assessed by a third-party inspection company.Default false
    supplierCountrySupplier countrystringOptional two-letter ISO country code, e.g. CN, IN, PK, US. Leave empty for all countries.
    minPriceMinimum unit price (USD)numberDrop offers whose lowest listed unit price is below this value.Allowed at least 0
    maxPriceMaximum unit price (USD)numberDrop offers whose lowest listed unit price is above this value.Allowed at least 0
    minSupplierYearsMinimum supplier tenure (years)integerKeep suppliers who have been on Alibaba.com at least this many years.Allowed 0 to 60
    minSupplierRatingMinimum supplier ratingnumberKeep suppliers rated at or above this score out of 5.Allowed 0 to 5
    sortBySort results bystringSort the collected records before the max-items cut-off.Default "relevance"; Allowed relevance, priceLowToHigh, priceHighToLow, supplierRating, yearsOnPlatform, transactionLevel
    startUrlsProduct or supplier URLs / IDsarrayUsed by the two detail modes. Paste Alibaba.com product URLs or numeric product IDs, or supplier minisite URLs or supplier IDs. For supplier profile URLs you can also use https://<supplier>.en.alibaba.com/.
    maxItemsMax recordsintegerMaximum number of product or supplier records to save.Default 20; Example 3; Allowed 1 to 200
    maxPagesMax search pagesintegerSafety limit on result pages (about 40 offers per page). Increase it when filtering heavily or requesting many records.Default 5; Example 1; Allowed 1 to 100
