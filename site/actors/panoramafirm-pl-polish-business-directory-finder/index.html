    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (one trade across several cities). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    PanoramaFirm.pl Polish Business Directory Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
