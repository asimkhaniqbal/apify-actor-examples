    Domain-Scoped Site Crawler for Markdown Datasets is an Apify Actor published by Vexaloom Labs. It accepts 26 input fields, and startUrls is required. Each result can carry up to 5 declared fields, including url, title, depth, wordCount and httpStatusCode. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per page”, “Input”, “Use cases” and “FAQ”.

    What you get

    What it costs

    Domain-Scoped Site Crawler for Markdown Datasets uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 26 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    startUrlsStart URLsarray requiredOne or more URLs to start crawling from. The crawler follows links found on these pages and stays on the domain of the first start URL.Example [{"url": "https://docs.apify.com"}]
    maxCrawlDepthMax Crawl DepthintegerHow many links deep to follow from the start URLs. 0 means only the start URLs are crawled.Default 10; Example 1; Allowed 0 to 100
    maxCrawlPagesMax PagesintegerMaximum number of pages (and files) to store. The crawl stops when this limit is reached.Default 20; Example 3; Allowed 1 to 100000
    useSitemapsUse SitemapsbooleanLook for sitemaps (from robots.txt and /sitemap.xml) and enqueue the URLs they list. Finds pages that are not linked from the start URLs.Default false
    useLlmsTxtUse llms.txtbooleanLook for /llms.txt at the start URL domains and enqueue the files listed there (common on documentation sites).Default false
    respectRobotsTxtFileRespect robots.txtbooleanSkip discovered pages that the site's robots.txt disallows. Start URLs are always crawled.Default true
    crawlOnlyPagesChangedSinceCrawl Only Pages Changed SincestringOptional date (YYYY-MM-DD or full ISO date-time). Crawls only pages that may have changed since then and outputs a delta. Leave empty to crawl everything.Default ""
    includeUrlGlobsInclude URL Patterns (globs)arrayOnly crawl discovered URLs matching these glob patterns (e.g. https://example.com/docs/*). Leave empty to allow everything on the domain.Default []
    excludeUrlGlobsExclude URL Patterns (globs)arraySkip discovered URLs matching any of these glob patterns (e.g. login, *.pdf).Default []
    includeUrlRegexpsInclude URL Patterns (regex)arrayOnly crawl discovered URLs matching at least one of these regular expressions. Combined with glob patterns (both must pass when both are set).Default []
    excludeUrlRegexpsExclude URL Patterns (regex)arraySkip discovered URLs matching any of these regular expressions.Default []
    keepUrlFragmentsKeep URL FragmentsbooleanTreat URLs that differ only in #fragment as different pages. Enable for single-page sites that use fragments as routes.Default false

    FieldTypeDescription
    ignoreCanonicalUrlIgnore canonical URLbooleanWhen disabled, pages whose canonical URL points to a page that was already crawled are skipped as duplicates.Default false

    chunkMaxCharsChunk Size (characters)integerTarget size of each chunk when chunkMarkdown is on. Code blocks and tables stay whole even when larger than this.Default 2000; Allowed 200 to 10000
    chunkOverlapCharsChunk Overlap (characters)integerApproximate overlap between consecutive chunks when chunkMarkdown is on, so context is not lost at chunk boundaries.Default 200; Allowed 0 to 1000
