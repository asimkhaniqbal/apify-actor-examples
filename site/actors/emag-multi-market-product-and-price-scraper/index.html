    eMAG Multi-Market Product & Price Scraper is an Apify Actor published by Vexaloom Labs. It accepts 12 input fields, and mode is required. Each result can carry up to 14 declared fields, including productId, partNumberKey, name, price, currency and originalPrice. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    eMAG Multi-Market Product & Price Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape: a keyword search, a category page, one product, or the seller offers for one product.Default "searchProducts"; Allowed searchProducts, browseCategory, getProductDetails, getProductOffers
    querySearch querystringKeyword or phrase to search for (mode=searchProducts). Use the market's language for the best results.Default "laptop"
    categoryUrlCategory URLstringeMAG category URL or path, e.g. /laptopuri/c or https://www.emag.ro/laptopuri/c (mode=browseCategory). Use a path from the selected market.Default "/laptopuri/c"
    productUrlProduct URL or codestringFull eMAG product URL, a path containing /pd/, or a product code such as DR3HHTYBM (mode=getProductDetails or getProductOffers).
    marketMarketstringWhich eMAG storefront to use. A full product or category URL overrides this value.Default "ro"; Allowed ro, bg, hu
    sortBySort bystringResult order for searchProducts and browseCategory. Reviews and discount are eMAG's own server-side sorts.Default "relevance"; Allowed relevance, price_asc, price_desc, reviews, discount
    minPriceMinimum pricenumberKeep products at or above this price in the market's currency (RON, EUR or HUF).Allowed 0 to 10000000
    maxPriceMaximum pricenumberKeep products at or below this price in the market's currency.Allowed 0 to 10000000
    minRatingMinimum ratingstringKeep products rated at least this many stars. Products with no rating are excluded when a minimum is set.Default "0"; Allowed 0, 1, 2, 3, 4, 5
    inStockOnlyIn stock onlybooleanKeep only products that can be ordered right now.Default false
    includeOffersInclude seller offersbooleanFor mode=getProductDetails, add the buybox and competing seller offers to each product record. Ignored by the other modes.Default true
    maxItemsMax itemsintegerMaximum products to return for searchProducts and browseCategory (1-1000). Detail and offers modes return one product or all of its offers.Default 30; Example 20; Allowed 1 to 1000
