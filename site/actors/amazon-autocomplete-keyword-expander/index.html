    Amazon Autocomplete Keyword Expander is an Apify Actor published by Vexaloom Labs. It accepts 29 input fields, and keywords is required. Each result can carry up to 6 declared fields, including seedKeyword, suggestion, rank, volumeProxy, department and marketplace.countryCode. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (one seed, one market). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxSuggestions (default 500, maximum 10000), maxSuggestionsPerKeyword (default 0, maximum 5000) and maxQueries (default 400, maximum 20000) cap how many results a run collects, and so what it costs.

    What it costs

    Amazon Autocomplete Keyword Expander uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    keywordsSeed keywordsarray requiredOne or more seed keywords or phrases to expand into Amazon autocomplete suggestions.Default []; Example ["wireless earbuds"]
    marketplaceMarketplacestringSingle Amazon marketplace to query. Used when marketplaces is empty.Default "US"; Allowed US, CA, MX, BR, IE, ES, GB, FR and 15 more
    marketplacesMultiple marketplacesarrayOptional multi-market sweep, e.g. ["US", "GB", "DE"]. Leave empty to use the single marketplace value. Codes are the same as the marketplace dropdown.Default []
    departmentsDepartmentsarrayAmazon department aliases to scope suggestions, e.g. ["aps", "kitchen"]. Leave empty for the all-departments default (aps). Common aliases: aps, electronics, computers, fashion, kitchen, stripbooks, beauty, hpc, pet-supplies, toys-and-games, home-improvement, automotive, grocery, office-products, watches, shoes, luggage, digital-text, audible, amazon-devices, instant-video, todays-deals.Default []; Example ["aps"]
    expandAlphabetExpand with suffix A-ZbooleanAppend each letter a-z to every query (e.g. yoga mat a) to surface more than the per-query cap.Default false
    expandPrefixAlphabetExpand with prefix A-ZbooleanPrepend each letter a-z to every query (e.g. a yoga mat). Returns a different suggestion set from suffix expansion.Default false
    expandNumbersExpand with digits 0-9booleanAppend each digit 0-9 to every query, useful for sizes, models and quantities.Default false
    expandQuestionsExpand with questionsbooleanQuery locale-aware question stems such as how to, what is and where to buy in front of each seed.Default false
    expandComparisonsExpand with comparisonsbooleanQuery comparison tokens such as vs, or, versus and and after each seed.Default false
    expandPrepositionsExpand with prepositionsbooleanQuery preposition tokens such as for, with, without, under and over after each seed.Default false
    expandBuyerModifiersExpand with buyer modifiersbooleanQuery locale-aware buyer-intent modifiers such as best, cheap, for men, for women and waterproof.Default false
    customSuffixesCustom suffixesarrayAdditional suffixes to append to every query, e.g. ["for men", "waterproof", "iphone 15"].Default []
