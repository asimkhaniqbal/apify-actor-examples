Ecwid App Market Pricing & Category Scraper

Catalog the apps listed on the Ecwid (Lightspeed E-Series) App Market — the add-on marketplace for stores built on Ecwid. Browse the full market, narrow it down to one category, or search by keyword to get each app's name, developer, description, categories, pricing type and icon.

What this actor does

  • Browses the entire Ecwid App Market in one run
  • Filters apps down to a single marketplace category (Marketing, Shipping, Analytics & Reporting, and others)
  • Searches apps by a keyword matched against name and description
  • Optionally restricts results to apps marked completely free
  • Empty fields are omitted from records

Output per app

  • appId — the app's unique namespace/slug
  • name — app name
  • tagline — short one-line description shown on listing cards
  • description — full app description (may contain HTML markup)
  • developer — developer or company name
  • categories — marketplace categories the app is listed under
  • pricingType — free, freemium, or paid
  • pricing — the human-readable pricing text shown on the app page, when there is one beyond the pricing type
  • url — the app's marketplace page URL
  • iconUrl — a constructed icon-image URL for the app; not every app's icon resolves at this address
  • headerImageUrl — app header/banner image URL, when the listing has one
  • recordType — always app
  • scrapedAt — ISO 8601 timestamp of when the record was captured

Input

Field Type Default Description
mode string browse browse (all apps) / byCategory / search
category string – Category slug or display name (mode=byCategory)
searchQuery string – Keyword matched against app name/description (mode=search)
includeFreeOnly boolean false Keep only apps marked totally free
maxItems integer 50 Maximum number of apps to return (1–500)

Accepted category values: featured, marketing, shipping, tools, store management, store-design, analytics, accounting, dropshipping, selling-on-marketplaces, customer-support.

Example: browse the whole market

{
  "mode": "browse",
  "maxItems": 100
}

Example: one category, free apps only

{
  "mode": "byCategory",
  "category": "shipping",
  "includeFreeOnly": true,
  "maxItems": 50
}

Example: keyword search

{
  "mode": "search",
  "searchQuery": "inventory",
  "maxItems": 30
}

Use cases

  • Competitive research — see which shipping, accounting, or marketing apps Ecwid merchants have available
  • App directory sites — mirror the Ecwid marketplace listing into your own comparison site
  • Pricing analysis — compare how many apps in a category are free, freemium, or paid
  • Partner/developer scouting — find developers active in a given app category
  • Market monitoring — re-run periodically to catch newly listed apps

FAQ

Does this need an Ecwid account? No — the App Market pages this actor reads are publicly accessible without logging in.

How many apps are on the Ecwid App Market? It varies as developers add and remove listings; mode: "browse" with a high maxItems returns everything currently listed.

What does pricingType: "freemium" mean versus "free"? free means the app is marked as totally free. freemium means the listing advertises a free trial or a tiered plan that starts free but has paid tiers. Everything else is paid.

What does a pricing value like "Billed Externally" mean? The app has its own pricing/billing page hosted by the developer rather than being billed through the Ecwid marketplace itself.

Can I combine category and searchQuery? No — mode picks one approach per run: browse everything, filter to one category, or search by keyword.

Why do some apps have no headerImageUrl or pricing? Those fields are only included when the app's own marketplace page actually provides that image or text.

Is this affiliated with Ecwid or Lightspeed? No. This actor reads Ecwid's publicly listed marketplace pages and is not affiliated with or endorsed by Ecwid or Lightspeed Commerce.

Why does the actor description mention both Ecwid and Lightspeed E-Series? Ecwid was acquired by Lightspeed Commerce and its platform is now also branded Lightspeed E-Series, but the app marketplace still lives at ecwid.com/apps.
