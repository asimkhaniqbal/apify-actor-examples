    Ticketmaster US Event & On-Sale Date Finder is an Apify Actor published by Vexaloom Labs. It accepts 15 input fields, none of them required at the top level. Each result can carry up to 10 declared fields, including recordType, title, startDate, venueName, venueCity and venueState. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Ticketmaster US Event & On-Sale Date Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to collectstringPick the lookup path. Search uses a keyword; Category browses one or more top-level categories; Artist and Venue read their public calendars; Event returns full detail for exact IDs/URLs; Suggestions returns matching artists and venues.Default "search"; Allowed search, category, artist, venue, event, suggestions
    searchQuerySearch querystringArtist, team, show, genre or a combined phrase such as taylor swift, lakers or comedy austin. Used by Search and Suggestions modes. Legacy tasks that send keyword still work.Default ""; Example "concerts"
    categoriesCategoriesarrayTop-level Ticketmaster categories. In Category mode each selected value is browsed; in Search, Artist and Venue modes the results are filtered to these categories.Default []; Allowed concerts, sports, arts-theater, family, film, miscellaneous
    artistIdsArtist IDs or URLsarrayArtist/attraction IDs or Ticketmaster artist URLs, e.g. 735585 or https://www.ticketmaster.com/barry-manilow-tickets/artist/735585 (mode=artist).Default []
    venueIdsVenue IDs or URLsarrayVenue IDs or Ticketmaster venue URLs, e.g. 107143 or https://www.ticketmaster.com/hertz-arena-tickets-estero/venue/107143 (mode=venue).Default []
    eventIdsEvent IDs or URLsarrayEvent IDs, discovery IDs or Ticketmaster event URLs, e.g. 0D00632F271D385A or https://www.ticketmaster.com/event/0D00632F271D385A (mode=event).Default []
    startUrlsStart URLs (optional)arrayTicketmaster search, artist, venue, event or category URLs to process instead of the mode targets. Each URL is routed automatically, and several can be mixed in one run.Default []
    dateFromEvents fromstringOnly keep events on or after this date (YYYY-MM-DD). Leave empty for no lower bound. In Category and Event modes the filter is applied to the returned rows.
    dateToEvents untilstringOnly keep events on or before this date (YYYY-MM-DD). Leave empty for no upper bound.
    sortSort orderstringRelevance keeps Ticketmaster's search ranking; Date orders by the soonest event first. Legacy sorts such as date,asc are mapped to Date.Default "relevance"; Allowed relevance, date, date,asc, date,desc, name,asc, name,desc, venueName,asc, random
    maxResultsMaximum recordsintegerHard cap on records emitted across every target in the run. Ticketmaster serves 20 events per page and stops at 980 rows per query; use a narrower date range or more categories to go wider.Default 20; Example 3; Allowed 1 to 1000
    skipSoldOutSkip sold-out eventsbooleanDrop events Ticketmaster flags as sold out.Default false
    skipCancelledSkip cancelled / postponedbooleanDrop cancelled, postponed and rescheduled events.Default true
    usOnlyUnited States onlybooleanKeep only events at US venues. Turn this off to include international results that Ticketmaster returns alongside US listings.Default true
    includeDetailsInclude full event detailsbooleanFetch each event's detail record and primary price levels: description, genre/classification, doors time, images, seat map, venue address and min/max price. Adds up to two requests per event. Leave off for the fastest, cheapest run.Default true; Example false
