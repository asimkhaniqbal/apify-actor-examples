    WebMD Health Condition & Drug Information Scraper is an Apify Actor published by Vexaloom Labs. It accepts 6 input fields, and mode is required. Each result can carry up to 7 declared fields, including name, genericName, drugClass, description, bodySystem and conditionUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search a condition). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    WebMD Health Condition & Drug Information Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 6 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to collectstring requiredWhether to collect medical-condition topics or drug monographs.Default "conditions"; Allowed conditions, drugs
    searchQuerySearch by name or keywordstringCondition or drug name, brand name, or keyword. Leave blank to browse the A-Z index. Multiple words must all appear in the name.Example "diabetes"
    letterBrowse a letterstringLimit results to one A-Z letter. Use All letters to let the search decide where to look.Default "all"; Allowed all, a, b, c, d, e, f, g and 19 more

    includeDetailsFetch detail pagesbooleanOpen each matched page to add description, symptoms, drug class, brand names, review date and other details. Turn off for a faster index-only run.Default true
    maxItemsMaximum recordsintegerStop after this many records.Default 20; Example 1; Allowed 1 to 500
