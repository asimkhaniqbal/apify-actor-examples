    What it costs

    Odysee Video Search by Keyword, Channel & Tag uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 9 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredChoose what to collect: a keyword search, a channel's uploads, a tag feed, or details for specific videos.Default "search"; Allowed search, byChannel, byTag, details
    keywordSearch keywordstringKeyword used by mode=search. Supports ordinary words and non-English text. Odysee returns at most about 550 results per keyword.Default "open source"
    channelChannelstringUsed by mode=byChannel. Accepts an @handle (@veritasium), an Odysee channel URL, an lbry:// channel URL, or a channel claim ID.Default "@veritasium"
    tagTagstringUsed by mode=byTag. Tag text without the leading #, for example science, technology or gaming.Default "science"
    videoUrlsVideo URLs or claim IDsarrayUsed by mode=details. One item per line: a full Odysee video URL, an lbry:// URL, or a 40-character claim ID.
    orderBySort orderstringSort order for channel and tag modes. Keyword search always uses Odysee's relevance ranking.Default "release_time"; Allowed release_time, effective_amount, support_amount, trending_group, trending_mixed
    mediaTypeMedia typestringFilter channel, tag and keyword results by Odysee stream type. Details mode returns the referenced item as-is.Default "video"; Allowed video, audio, document, image, all
    maxItemsMax itemsintegerMaximum number of records to collect across the whole run.Default 20; Example 3; Allowed 1 to 10000
    includeStatsInclude engagement statsbooleanAdd view count, likes, dislikes and channel follower count. These numbers come from Odysee's public counters and add a few small requests per record.Default true
