    Delaware Corporation Entity Search Scraper is an Apify Actor published by Vexaloom Labs. It accepts 14 input fields, and mode is required. Each result can carry up to 9 declared fields, including entityName, fileNumber, entityKind, entityType, residency and formationDate. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 9 fields in 1 dataset view, and the README documents 11 more. Fields without a value can be left out of a record.

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (several names in one run). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Delaware Corporation Entity Search Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to look up. Use names, file numbers, or both in one run.Default "searchByName"; Allowed searchByName, byFileNumber, both
    entityNamesEntity namesarrayOne or more company names to search (case-insensitive "starts with" by default). Every name is searched in the same run and duplicates are removed. Used by mode=searchByName and mode=both.Default ["AMAZON"]; Example ["AMAZON WEB SERVICES, INC."]
    exactMatchExact name matchbooleanOff: mirrors the source's default "starts with" match, so GOOGLE also finds GOOGLE FIBER INC.. On: only the complete legal name is returned, using the Delaware form's own documented quotation-mark exact-match syntax.Default false; Example true
    fileNumbersFile numbersarrayExact Delaware file numbers to look up, e.g. 4152954. Used by mode=byFileNumber and mode=both.Default []
    expandBroadSearchesReach past the 50-result windowbooleanDelaware returns at most 50 matches per name search and refuses to page further. When on, a broader search is automatically split into alphabetical prefixes (e.g. AMAZON into AMAZON A, AMAZON B, ...) so later matches can still be collected. Costs a few extra requests only when the source reports the 50-result cap; ignored for exact matches.Default true
    entityKindsEntity kindsarrayKeep only these Delaware entity kinds. Leave empty for all kinds.Default []; Allowed Corporation, Credit Services Organization, Limited Partnership, Limited Liability Company, Statutory Trust, Partnership, Registered Series, Unincorporated Non-Profit Association
    entityTypesEntity typesarrayKeep only these Delaware entity types. Leave empty for all types.Default []; Allowed General, Bank, Benefit Corporation, Closed Corp, Professional Association, Dual Entity, Regulated Investment Corp., Non-Title 8 and 3 more
    residencyResidencystringDomestic = formed in Delaware. Foreign = formed elsewhere and registered to do business in Delaware.Default "any"; Allowed any, Domestic, Foreign
    stateOfFormationState of formationstringKeep only entities whose stateOfFormation equals this value, e.g. DELAWARE or CALIFORNIA (case-insensitive). Leave empty for all.Default ""
    formationDateFromFormation date fromstringKeep only entities formed on or after this date (YYYY-MM-DD). Leave empty for no lower bound.
    formationDateToFormation date tostringKeep only entities formed on or before this date (YYYY-MM-DD). Leave empty for no upper bound.
    registeredAgentContainsRegistered agent containsstringKeep only entities whose registered-agent name contains this text, e.g. CORPORATION SERVICE (case-insensitive).Default ""
    proxyConfigurationProxy configurationobjectOptional. The actor defaults to Apify's free datacenter (AUTO) proxy group and uses a fresh IP automatically if Delaware rate-limits a request. Residential proxy is never used by default.Default {"useApifyProxy": true}
    maxItemsMax entitiesintegerHard cap on emitted records across all names and file numbers. Kept low by default because each record needs one extra detail request against a source that actively rate-limits automated traffic.Default 5; Example 1; Allowed 1 to 100
