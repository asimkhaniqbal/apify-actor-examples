    TikTok Comment & Reply Thread Extractor is an Apify Actor published by Vexaloom Labs. It accepts 14 input fields, none of them required at the top level. Each result can carry up to 14 declared fields, including rowType, commentId, postId, text, createdAt and likeCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (comments and replies for one video). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxVideosPerProfile (default 10, maximum 500), maxCommentsPerPost (maximum 10000), maxRepliesPerComment (default 0, maximum 5000), maxItems (default 0, maximum 1000000) and maxCommenterLookups (default 100, maximum 10000) cap how many results a run collects, and so what it costs.

    What it costs

    TikTok Comment & Reply Thread Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    profilesProfiles (comments on their newest videos)arrayTikTok usernames or profile URLs. The actor scrapes comments from their newest videos, up to 'Max videos per profile'.

    maxCommentsPerPostMax comment rows per videointegerMaximum number of rows per video, counting replies when 'Include replies' is on. The actor walks the comment section as deep as TikTok serves it.Example 5; Allowed 1 to 10000
    includeRepliesInclude repliesbooleanFetch the reply thread under each root comment and emit each reply as its own row right after its parent.Default true
    maxRepliesPerCommentMax replies per commentintegerCap the replies fetched for any single root comment. Set to 0 for all replies (still bounded by 'Max comment rows per video').Default 0; Example 5; Allowed 0 to 5000
    maxItemsMax total rowsintegerGlobal cap on the number of rows in the run (comments + replies). Set to 0 for no global cap.Default 0; Allowed 0 to 1000000
    minLikesMinimum likesintegerOnly keep comments and replies with at least this many likes. Comments below the threshold are skipped before their replies are fetched.Default 0; Allowed 0 to 1000000
    includeVideoMetadataInclude video metadatabooleanAdd a 'video' object (caption, author, view/like/comment counts) to every row.Default false
    includeCommenterDetailsInclude commenter details (region, bio)booleanAdd the commenter's region code and bio to user.region / user.bio, matched by comment ID from TikTok's app-style view of the page.Default false
    includeCommenterStatsInclude commenter follower countsbooleanAdd exact follower, following, heart and video counts to user.* for every commenter. Each commenter's public profile is looked up once; private or banned accounts are omitted.Default false
    maxCommenterLookupsMax commenter lookupsintegerCap on how many commenters are enriched when 'Include commenter follower counts' is on. Set to 0 for no cap.Default 100; Allowed 0 to 10000
    deepWalkDeep walk (higher comment coverage)booleanRead TikTok's app-style view of the comment list, which reaches far more comments on many videos, and restore image/sticker data from the standard view per comment. Off keeps the standard walk.Default false
