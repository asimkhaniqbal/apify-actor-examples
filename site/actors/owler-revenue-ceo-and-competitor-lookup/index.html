    Owler Revenue, CEO & Competitor Lookup is an Apify Actor published by Vexaloom Labs. It accepts 5 input fields, and mode is required. Each result can carry up to 7 declared fields, including name, industry, headquarters, revenueRange, employeeRange and ceoName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Owler Revenue, CEO & Competitor Lookup uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
