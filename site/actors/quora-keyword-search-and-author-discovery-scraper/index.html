    Quora Keyword Search & Author Discovery Scraper is an Apify Actor published by Vexaloom Labs. It accepts 23 input fields, none of them required at the top level. Each result can carry up to 15 declared fields, including content_type, title, url, question_id, answer_id and author_name. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (a question with many answers). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxAnswersPerQuestion (default 20, maximum 500), maxItems (default 200, maximum 50000) and maxItemsPerSource (default 0, maximum 5000) cap how many results a run collects, and so what it costs.

    What it costs

    Quora Keyword Search & Author Discovery Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    modeModestringWhat to scrape. urls follows pasted Quora links. search discovers indexed question links for your keywords and expands related questions. authors builds author profiles from pasted profile or question URLs.Default "urls"; Allowed urls, search, authors
    directUrlsQuora URLsarrayPaste question, answer, profile, or topic URLs. Language subdomains such as es.quora.com are accepted. Invalid links are reported as status rows.Example ["https://www.quora.com/What-is-Python-primarily-used-for"]
    searchQueriesKeywords or Question TitlesarrayBest-effort keyword discovery. Quora's own search page is gated for anonymous visitors, so results depend on the public web index; a run with no indexed matches returns a clear status row instead of invented results.Default []
    usernamesProfile UsernamesarrayQuora profile slugs, with or without a leading @ or trailing slash. Converted to profile URLs and merged with Quora URLs.Default []
    resultTypesResult TypesarrayWhich entity rows to emit. Status and run-manifest rows are always written when relevant.Default ["question", "answer"]; Allowed question, answer, profile, author, topic
    includeAnswersInclude AnswersbooleanEmit answer rows and fetch answers beyond the first visible cards on question pages.Default true
    maxAnswersPerQuestionMaximum Answers per QuestionintegerAnswer cap for each question URL. Zero emits no answers from question pages.Default 20; Example 2; Allowed 0 to 500
    includeRelatedQuestionsDiscover Related QuestionsbooleanFollow the related-question links on each question page and scrape those questions too. This is the reliable discovery path when keyword search is gated.Default false
    maxRelatedQuestionsMaximum Related QuestionsintegerRelated questions retained per question page and used as discovery seeds. Zero keeps all observed related questions.Default 15; Example 0; Allowed 0 to 100

    maxAuthorsMaximum AuthorsintegerMaximum unique author rows emitted from answer evidence.Default 100; Example 20; Allowed 1 to 5000
    minAnswerUpvotesMinimum Answer UpvotesintegerDrop answers below this upvote count. Answers with no explicit upvote count are excluded when this is above zero.Default 0; Allowed 0 to 2000000000
