    Corporations Canada Registry Scraper is an Apify Actor published by Vexaloom Labs. It accepts 11 input fields, and mode is required. Each result can carry up to 10 declared fields, including corpName, corpNumber, businessNumber, status, statusCategory and isActive. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What you get

    What it costs

    Corporations Canada Registry Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    corpNumbersCorporation numbers (mode=byCorporationNumber)arrayExact corporation numbers to look up, e.g. 426160-7.Default []
    businessNumbersBusiness numbers / BN (mode=byBusinessNumber)arrayExact CRA business numbers to look up, e.g. 847871746 (with or without the RC0001 program-account suffix).Default []
    corporationIdsCorporation IDs (mode=byCorporationId)arrayInternal Corporations Canada corpId values to fetch directly, e.g. 4261607. Get these from a prior search result's corpId field or from a bookmarked fdrlCrpDtls.html?corpId=... URL.Default []
