    UFC Weight-Class Rankings & Fight Card Results is an Apify Actor published by Vexaloom Labs. It accepts 20 input fields, none of them required at the top level. Each result can carry up to 10 declared fields, including recordType, rankingName, rank, name, eventName and fighter1Name. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (current lightweight rankings). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    UFC Weight-Class Rankings & Fight Card Results uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    dataTypeData typestringWhat to collect: current rankings, a fighter directory, fighter profiles, event fight cards, or individual fight statistics.Default "rankings"; Allowed rankings, fighters, fighterDetails, events, fights
    weightClassWeight class (mode=rankings)stringDivision to rank, or every division plus both pound-for-pound lists.Default "Lightweight"; Allowed Lightweight, Heavyweight, Light Heavyweight, Middleweight, Welterweight, Featherweight, Bantamweight, Flyweight and 6 more
    modeLegacy modestringLegacy mode values are still accepted and mapped automatically.

    stanceStance filter (mode=fighters)stringOnly include fighters with this stance.Default "Any stance"; Allowed Any stance, Orthodox, Southpaw, Switch, Open Stance, Sideways
    minWinsMinimum wins (mode=fighters)integerDrop fighters with fewer recorded wins.Allowed 0 to 1000
    sortFightersSort fighters by (mode=fighters)stringOrder the directory output. Wins, losses, and bouts sort highest first; name sorts A–Z.Default "name"; Allowed name, wins, losses, bouts

    eventSearchEvent name filter (mode=events)stringCase-insensitive text match on the event name, e.g. UFC 300 or Fight Night.
    eventSortEvent order (mode=events)stringNewest first or oldest first.Default "newest"; Allowed newest, oldest
