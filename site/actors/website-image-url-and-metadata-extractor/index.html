    Website Image URL & Metadata Extractor is an Apify Actor published by Vexaloom Labs. It accepts 7 input fields, and startUrl is required. Each result can carry up to 6 declared fields, including url, sourcePage, alt, discoveredVia, crawlDepth and mimeTypeHint. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per image”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 6 fields in 1 dataset view, and the README documents 7 more. Fields without a value can be left out of a record.

    Output fields
    FieldLabelWhat it holds
    urlImage URLabsolute URL of the image (data: URIs and javascript: pseudo-URLs are filtered out)
    sourcePageSource pagethe page where the image was discovered
    altAlt textthe image's alt attribute, when present
    discoveredViaDiscovered viahow the image was found: img-tag, srcset, picture-source, link-icon, or css-background
    crawlDepthDepthhow many link-hops from the start URL the hosting page was found at (0 = the start URL itself)
    mimeTypeHintTypeMIME type inferred from the file extension (e.g. image/png, image/svg+xml)
    pageTitlethe <title> of the page where the image was found
    hasAltTexttrue when alt is present and non-empty, so you can filter for missing alt text without checking field presence
    titlethe image's title attribute, when present
    widthexplicit pixel dimensions from the tag, when numeric values are given
    heightexplicit pixel dimensions from the tag, when numeric values are given
    extensionlowercase file extension parsed from the URL path (e.g. jpg, svg, webp)
    scrapedAtISO 8601 timestamp of the run

    What it costs

    Website Image URL & Metadata Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 7 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    startUrlStart URLstring requiredThe page to start crawling from (e.g. 'https://example.com'). The actor extracts images from this page and, if maxCrawlDepth >= 1, follows internal links to additional pages on the same host.Example "https://apify.com"
    maxCrawlDepthMaximum crawl depthinteger0 = only the start URL. 1 = also follow links found on the start URL (same host only). Higher values widen the crawl but cost more time.Default 1; Allowed 0 to 5
    maxImagesPerPageMaximum images per pageintegerCap on how many images are extracted from a single page. Pathological gallery pages can list hundreds of duplicates; this keeps runs bounded.Default 200; Allowed 1 to 5000
    maxTotalImagesMaximum images per runintegerHard cap on the total number of image records pushed across all crawled pages. The crawl stops once this many images are emitted.Default 1000; Allowed 1 to 50000
    imageExtensionsImage extensions to acceptarrayOnly image URLs whose path ends in one of these extensions are kept. Drop entries to filter to a subset (e.g. only ['svg']) or extend with custom formats.Default ["jpg", "jpeg", "png", "gif", "webp", "svg", "avif", "bmp...
    includeBackgroundImagesInclude CSS background-imagesbooleanAlso extract images referenced via inline style="background-image: url(...)" attributes. Disable to only collect <img>-sourced images.Default true
    userAgentCustom User-Agent (optional)stringOverride the default Chrome User-Agent string. Most sites accept the default; only set this if a target server filters by UA.
