    Facebook Group Feed & Engagement Extractor is an Apify Actor published by Vexaloom Labs. It accepts 12 input fields, and startUrls is required. Each result can carry up to 7 declared fields, including postId, authorName, text, creationTime, reactionsTotal and commentsCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Collect public Facebook group posts as structured data: full text, author, timestamp, media, reaction breakdown, comment and share counts, top comments, reshares, and optional full comment threads. Add group profiles, paste individual post links, or monitor a group on a schedule — without logging in or supplying cookies.

    What this actor does

    • Scrape public group feeds from a group URL, bare slug, or numeric group ID.
    • Scrape individual group posts by pasting one or more post links.
    • Fetch full comment threads with comment text, author, reactions, timestamps, and nested replies.
    • Include group profiles: name where available, description, exact member count, creation date, privacy, rules, plus admins and tags when Facebook exposes them.
    • Work with private groups honestly: their posts are not public, but their public profile data (description, member count, rules, privacy) is returned when group enrichment is enabled.
    • Four feed orders: top posts, chronological, recent activity, and buy/sell listings.
    • Filter while collecting: date range, keyword, and monitor mode for new posts only.
    • Handle mixed languages and formats: English, Arabic, Vietnamese, and other group content is returned as written.
    • Omit empty fields at every level — no nulls or blank placeholders.

    Comment fields

    Comments carry id, text, authorId, authorName, authorUrl, createdAt, reactionsTotal, replyCount, and permalinkUrl when Facebook exposes them; missing fields are omitted. Comments fetched with replies enabled also carry a replies array using the same shape.

    Group profile fields

    id, name when available (post-link mode; some group-feed About payloads omit it), url, description, memberCount, memberCountFormatted, createdAt, admins, rules, privacy, discoverability, and tags.

    Private and empty groups produce a status row with _status, _inputUrl, _groupUrl, _message, scrapedAt, and the public group object when enrichment is enabled.

    Examples

    Scrape the newest 50 posts from a group:

    {
    "startUrls": ["https://www.facebook.com/groups/pythondevelopers/"],
    "sortBy": "chronological",
    "maxItems": 50
}

    Fetch full comment threads for two group posts:

    {
    "startUrls": [
        "https://www.facebook.com/groups/pythondevelopers/posts/29000349089604342/",
        "https://www.facebook.com/groups/OPonemillion/posts/29298552993071994/"
    ],
    "fetchAllComments": true,
    "maxCommentsPerPost": 50,
    "includeCommentReplies": true
}

    Monitor a group and include its profile:

    {
    "startUrls": ["https://www.facebook.com/groups/pythondevelopers/"],
    "sortBy": "recent_activity",
    "maxItems": 100,
    "enrichGroupInfo": true,
    "monitoringMode": true
}

    Questions

    Do I need a Facebook account, cookies, or a proxy?

    No. The actor reads public data without logging in and chooses its connection automatically. You do not need to configure a proxy.

    Can it scrape private groups?

    Private group posts are not available without membership. The actor returns the group's public profile when group enrichment is enabled, and a clear status message explaining that posts are private.

    Why are some engagement fields missing, and why do others show 0?

    Facebook reports 0 for some posts with no reactions, comments, or shares; those exact zeros are kept. Fields Facebook does not return at all are omitted, along with empty strings, arrays, objects, and nulls. Counts are preserved exactly as Facebook reports them, never rounded up or fabricated.

    Are date and keyword filters applied by Facebook?

    No. Facebook's group feed does not expose a server-side date or keyword filter, so the actor applies these filters while collecting posts. A very narrow filter can stop after the configured scan ceiling; the status message explains this.

    Why is videoUrl missing on some video posts?

    Facebook exposes a direct MP4 for some group videos only. When it does not, the actor returns the thumbnail, duration, dimensions, and permalink instead of inventing a URL.

    How many comments can I get?

    Facebook serves comments in pages of ten. Set maxCommentsPerPost to control the budget. Public visibility can be lower than the total shown on the post; commentsVisible reports what was available.

    Why is a group feed shorter than the requested number of posts?

    Facebook returns three posts per request and may stop serving older posts. The actor stops when the feed ends or the requested number is reached.

    Does this actor use cookies or a login for post links?

    No. Public group post links and their comment threads are read without authentication.

    Can I export the results?

    Yes. Any run's dataset can be exported to JSON, CSV, Excel, XML, or pushed to Google Sheets from the run page.
