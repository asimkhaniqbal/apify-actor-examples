    Facebook Group Feed & Engagement Extractor is an Apify Actor published by Vexaloom Labs. It accepts 12 input fields, and startUrls is required. Each result can carry up to 7 declared fields, including postId, authorName, text, creationTime, reactionsTotal and commentsCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 500) and maxCommentsPerPost (default 20, maximum 200) cap how many results a run collects, and so what it costs.

    What it costs

    Facebook Group Feed & Engagement Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    startUrlsGroup or post URLsarray requiredFacebook group URLs, bare group slugs or numeric IDs, or links to individual group posts.Example ["https://www.facebook.com/groups/pythondevelopers/"]
    sortBySort bystringHow to order each group's feed.Default "top"; Allowed top, chronological, recent_activity, listings
    maxItemsMax posts per groupintegerMaximum number of posts to return per group. Post links always return one post.Default 50; Example 3; Allowed 1 to 500
    includeTopCommentsInclude top commentsbooleanInclude each post's inline top comments, with comment text, author, reactions and reply count.Default true
    fetchAllCommentsFetch full comment threadsbooleanFetch the full comment thread for each post, not just the inline top comments. This is slower and can add many rows of comment data.Default false
    maxCommentsPerPostMax comments per postintegerComment budget per post, including replies. Only used when full comment threads are enabled.Default 20; Example 5; Allowed 1 to 200
    includeCommentRepliesInclude comment repliesbooleanAttach replies to each fetched comment. Only used when full comment threads are enabled.Default true
    onlyPostsNewerThanOnly posts newer thanstringKeep posts created after this date. Use YYYY-MM-DD or a relative value such as '7 days' or '24 hours'. Applied while collecting posts.
    onlyPostsOlderThanOnly posts older thanstringKeep posts created before this date. Use YYYY-MM-DD or a relative value such as '30 days'.
    searchKeywordKeyword filterstringKeep only posts whose text contains this keyword (case-insensitive). Applied while collecting posts.
    enrichGroupInfoInclude group profilebooleanAdd the group's name, description, member count, creation date, privacy, rules and admins to posts. Works for public groups; private groups return their public profile only.Default false
    monitoringModeMonitor mode (only new posts)booleanReturn only posts not seen in a previous run for the same group or post link, so scheduled runs return just what is new.Default false
