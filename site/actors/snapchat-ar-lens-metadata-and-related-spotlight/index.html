    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (page through the trending chart). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Snapchat AR Lens Metadata & Related Spotlight Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 8 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to scrapestring requiredBrowse the public lens charts, fetch specific lenses, or search the Explore lens tab.Default "home"; Allowed home, detail, search
    categoryLens chart categorystring(mode=home) Which public Snapchat lens chart to page through. For You, Trending and Face are the deepest charts; World, Music and Live are shorter.Default "for_you"; Allowed for_you, trending, face, world, music, web_live
    lensUrlsOrIdsLens URLs or UUIDsarray(mode=detail) Lens page URLs (snapchat.com/lens/{uuid}), unlock URLs with a uuid= parameter, or bare 32-character UUIDs.Example ["565e7595ec4e4a0da689762b127308ef"]
    keywordsSearch keywordsarray(mode=search) Keywords, brands or creator names to search on the public Snapchat Explore lens tab. Snapchat returns at most 24 lenses per keyword.Example ["food"]
    includeMoreLensesInclude related lensesboolean(mode=detail) Include the related lenses Snapchat shows beside the lens. Up to 12 are returned; the lens itself is excluded when Snapchat includes it.Default true
    includeSpotlightsUsingLensInclude related Spotlightsboolean(mode=detail) Include Spotlight videos that use this lens, with thumbnails, media URLs, creator details, engagement counts and AI-generated descriptions when public.Default true
    maxItemsMaximum recordsintegerGlobal cap on saved records. Home mode pages through the selected chart until this cap or the end of the chart; the other modes stop when their inputs are exhausted.Default 100; Example 24; Allowed 1 to 100000
    proxyConfigurationProxy configurationobjectOptional proxy override. Snapchat's public lens pages work without a proxy; leave this empty unless you hit rate limiting.
