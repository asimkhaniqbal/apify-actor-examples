    LinkedIn Keyword & Hashtag Post Discovery Scraper is an Apify Actor published by Vexaloom Labs. It accepts 28 input fields, none of them required at the top level. Each result can carry up to 9 declared fields, including authorName, authorFollowers, postedAt, content, reactionsCount and commentsCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per post”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword search with engagement filter). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResults (default 25, maximum 200) caps how many results a run collects, and so what it costs.

    What it costs

    LinkedIn Keyword & Hashtag Post Discovery Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 28 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to run. 'auto' searches when searchQuery/searchQueries are set and enriches when postUrls are set (both can run together).Default "auto"; Allowed auto, search, postUrls
    searchQuerySearch QuerystringKeyword, phrase, or hashtag to find in public LinkedIn posts. Examples: 'artificial intelligence', '"product launch"', '#MachineLearning'. (mode=search/auto)Example "artificial intelligence"
    searchQueriesSearch Queries (batch)arrayAdditional queries to run in the same run; each is searched independently, duplicates are delivered once. Combine with Search Query. (mode=search/auto)Default []
    postUrlsPost URLsarrayLinkedIn post or article URLs to enrich directly (activity, share, ugcPost, feed/update, /pulse/ links and country subdomains). (mode=postUrls/auto)Default []
    sortBySort BystringHow to order the posts that were found. 'relevance' keeps the search engine's order; 'recency' sorts the found posts by date (newest first).Default "relevance"; Allowed relevance, recency, date_posted
    datePostedDate PostedstringOnly keep posts from this time window.Default ""; Allowed , r86400, r604800, r2592000
    postedAfterPosted AfterstringOnly keep posts published on or after this date (YYYY-MM-DD). Leave empty to disable.Default ""
    postedBeforePosted BeforestringOnly keep posts published on or before this date (YYYY-MM-DD). Leave empty to disable.Default ""
    authorTypeAuthor TypestringKeep only posts written by a person or by a company page. Applied after each post is opened, so a post whose author type cannot be determined is kept.Default ""; Allowed , PERSON, COMPANY
    contentTypeContent TypesarrayKeep only these post types: articles (LinkedIn articles), posts (text/reposts/polls/events), documents (PDF/PPTX document cards), videos, images.Default ["articles", "posts", "documents", "videos", "images"]
    minReactionsMinimum ReactionsintegerKeep only posts with at least this many reactions. Posts whose reaction count is unknown are skipped when this is above 0.Default 0; Allowed 0 to 1000000
    minCommentsMinimum CommentsintegerKeep only posts with at least this many comments. Posts whose comment count is unknown are skipped when this is above 0.Default 0; Allowed 0 to 1000000
