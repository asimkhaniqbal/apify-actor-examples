    LinkedIn Hashtag Feed Engagement Scraper is an Apify Actor published by Vexaloom Labs. It accepts 14 input fields, and hashtags is required. Each result can carry up to 9 declared fields, including hashtag, authorName, authorFollowers, postedAt, content and mediaType. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (weekly ai pulse). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPostsPerHashtag (default 50, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    LinkedIn Hashtag Feed Engagement Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    hashtagsHashtagsarray requiredHashtags to collect. Accepts #AI, AI, artificial-intelligence, https://www.linkedin.com/feed/hashtag/ai/ or .../feed/hashtag/?keywords=ai. Duplicates are removed.Example ["AI"]
    maxPostsPerHashtagMax Posts Per HashtagintegerMaximum posts to keep for each hashtag after the hashtag check and filters are applied.Default 50; Example 3; Allowed 1 to 500
    datePostedDate PostedstringRestrict posts to a recent window. Applied by the search index and re-checked against each post's published date.Default ""; Allowed , r86400, r604800, r2592000
    postedAfterPosted AfterstringKeep posts published on or after this date (YYYY-MM-DD, UTC day). Leave empty to disable.Default ""
    postedBeforePosted BeforestringKeep posts published on or before this date (YYYY-MM-DD, whole UTC day). Leave empty to disable.Default ""
    sortBySort BystringOrder the posts found in this run. Relevance keeps the search index order; date and engagement sort only the posts that were found, not all of LinkedIn.Default "relevance"; Allowed relevance, date, engagement
    mediaTypeFilterMedia TypestringKeep only one post type. Text, image, video, article and repost are the types public posts expose most often.Default ""; Allowed , text, image, video, article, document, repost, poll
    authorTypeAuthor TypestringKeep only posts written by a person or by a company page. Author type is read from the public author profile link.Default ""; Allowed , PERSON, COMPANY
    minReactionsMinimum ReactionsintegerDrop posts with fewer than this many reactions. A post with no visible reaction count is treated as 0.Default 0; Allowed 0 to 1000000
    minCommentsMinimum CommentsintegerDrop posts with fewer than this many comments. A post with no visible comment count is treated as 0.Default 0; Allowed 0 to 1000000
    includeCommentsInclude CommentsbooleanInclude the first public page of comments (up to 10) with each post. No extra request is made.Default true
    includeVideoTranscriptInclude Video TranscriptbooleanAdd the public transcript and caption URL when a video post publishes them.Default false
    excludeRepostsExclude RepostsbooleanDrop posts that reshare another post.Default false
    dedupeAcrossHashtagsDedupe Across HashtagsbooleanReturn each post once even when it appears under several requested hashtags. By default a post is returned once per hashtag.Default false
