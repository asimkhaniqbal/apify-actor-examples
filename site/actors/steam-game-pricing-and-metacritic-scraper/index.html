    Steam Game Pricing & Metacritic Scraper is an Apify Actor published by Vexaloom Labs. It accepts 16 input fields, and mode is required. Each result can carry up to 9 declared fields, including appName, appType, currentPrice, discountPercent, metacriticScore and reviewScoreDesc. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Steam Game Pricing & Metacritic Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    modeModestring requiredChoose how to find games: keyword search, a Steam chart, specific App IDs, or pasted store URLs.Default "search"; Allowed search, browse, appDetail, urls, featured
    searchQueriesSearch queriesarrayOne or more game names or keywords. Used when mode is Search by keyword.Default ["adventure"]; Example ["Hades"]
