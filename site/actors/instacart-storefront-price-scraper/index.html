    Instacart Storefront Price Scraper is an Apify Actor published by Vexaloom Labs. It accepts 16 input fields, and mode and retailerSlug are required. Each result can carry up to 8 declared fields, including name, brandName, priceString, pricePerUnitString, size and retailerName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search a retailer by keyword). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    Instacart Storefront Price Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 16 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch.Default "search"; Allowed search, browseAisle, listAisles, productDetail, storeOverview
    retailerSlugRetailerstring requiredWhich Instacart-partnered retailer's storefront to scrape. Pick from the list, or use "Custom retailer slug" below to supply any Instacart retailer slug not in this list.Default "costco"; Allowed costco, safeway, publix, cvs, walgreens, aldi, wegmans, kroger and 22 more
    customRetailerSlugCustom retailer slug (overrides Retailer above)stringAny Instacart retailer slug, e.g. whole-foods-market or sprouts-farmers-market. Find a retailer's slug in its Instacart storefront URL: instacart.com/store/<slug>/storefront. Leave empty to use the Retailer dropdown instead.
    postalCodeDelivery ZIP code (optional)stringFive-digit US ZIP code to price this retailer's storefront at, e.g. 10001. Leave empty to use Instacart's default location for the session. The actor resolves the matching shop and zone before scraping; a ZIP this retailer does not serve fails the run instead of silently returning another market's prices.
    searchQuerySearch query (mode=search)stringKeyword to search for within the selected retailer's storefront, e.g. milk, organic eggs, paper towels. Results are filtered so every returned item's name/brand/category contains each significant word of your query (generic words like "organic" are ignored for this check). Note: this is a substring check, not full product understanding, so on rare occasions an item that happens to contain all your query words in an unrelated context (e.g. a "milk chocolate"-flavored candy matching a search for "almond milk") can still slip through.Default "milk"
    orderBySort order (mode=search, browseAisle)stringHow to order results.Default "bestMatch"; Allowed bestMatch, priceAsc, priceDesc
    aisleSlugAisle / department slug (mode=browseAisle)stringWhich department/aisle (a.k.a. "collection") to browse within the selected retailer, e.g. 9797-crackers, produce, or dynamic_collection-sales (retailer-wide deals). Run mode=listAisles first to get the exact slugs available for your chosen Retailer, or copy one from an Instacart collection URL: instacart.com/store/<retailer>/collections/<slug>.Example "9797-crackers"
    itemIdsItem IDs (mode=productDetail)arrayFull Instacart item IDs to look up, e.g. items_74-17444603 (copy from a search, browseAisle, or storeOverview result's itemId field). Must all belong to the same Retailer selected above.Default []; Example ["items_74-17444603"]
    minPriceMin price (USD)integerDrop items priced below this amount (whole dollars).Allowed 0 to 10000
    maxPriceMax price (USD)integerDrop items priced above this amount (whole dollars).Allowed 0 to 10000
    brandContainsBrand name containsstringKeep only items whose brand name contains this text (case-insensitive).
    inStockOnlyIn-stock onlybooleanDrop items that are marked out of stock.Default false
