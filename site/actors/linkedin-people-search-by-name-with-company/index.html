It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Turn a list of names into LinkedIn profiles — with the current employer, location, headline, photo and followers — without a LinkedIn account, cookie or proxy. Give the actor names plus an optional company or location, and it returns the people who match.

    What this actor does

    • Looks up each name in LinkedIn's public people directory and returns the matching profiles, up to 50 candidates per name.
    • Narrows the list with strict current company and location filters: every candidate's public profile page is checked before a row is kept, so a person whose company only appears in a directory summary is verified or dropped.
    • Opens each matched profile to fill the public details: current employer, location, followers, "500+" connection indicator, about text, education and profile photo.
    • Understands full names, single names, middle names, and one-sided searches (first:Madonna, last:Smith).
    • Removes duplicates, so the same profile is never returned twice in one run.
    • Works with zero credentials and zero proxy setup. No LinkedIn login is used at any point.

    Data source & limitations

    The actor reads LinkedIn's public people directory (/pub/dir/) and the public, logged-out profile pages it links to. It selects its own access path automatically; no proxy configuration is needed.

    Honest limits: the directory window is about 50 candidates per name; exact connections, skills, full experience history, education degrees and contact details are not public; and headline visibility depends on what LinkedIn and public search indexes expose to logged-out visitors. The search-engine fallback is best-effort and may pause itself when the engines rate-limit. About texts are often truncated for anonymous visitors (flagged with aboutTruncated).

    Use cases

    • Lead research — turn a list of names into current employer, role and profile links.
    • Recruiting — confirm a candidate's current company and location before outreach.
    • CRM cleanup — refresh LinkedIn URLs and employers for existing contacts.
    • Name disambiguation — use company or location to pick the right person among namesakes.

    Questions

    Do I need a LinkedIn cookie or account?

    No. The actor reads only LinkedIn's public directory and logged-out profile pages. It never asks for a login and does not use your account.

    Why is a person missing from the results?

    LinkedIn's public directory shows at most 50 candidates per name. Very common names ("John Smith") can push the person you want outside that window. Add a company or location filter: the actor then also runs a company-augmented public search-engine query, which recovers many common-name cases, and verifies every candidate against its profile.

    Are the company and location filters exact?

    They are case-insensitive text matches, verified against the profile the actor opens. They keep people whose current employer or location contains your text. They are not LinkedIn's own server-side filters.

    Why is the headline missing for some people?

    LinkedIn hides most logged-out headlines and replaces them with asterisks or the current company. The actor returns a real headline when it is visible on the page or recoverable from an indexed public result (name, vanity and name+company query forms); otherwise the field is left out rather than guessed.

    Why do some rows have companyRedacted: true?

    On some profiles LinkedIn hides the employer and puts the job title where the company should be. The actor detects that pattern, never reports the job title as a company, and marks the record instead.

    Why does the connection count say "500+"?

    LinkedIn caps the public connection indicator at "500+". An exact number is not exposed to logged-out visitors.

    Can I get email addresses, skills or full work history?

    No. Those fields require a logged-in LinkedIn session and are outside this actor's public-data scope.

    What happens when a name has no matches?

    No row is emitted for that name; the run continues with the remaining names.

    Is this actor affiliated with LinkedIn?

    No. It is an independent tool and is not affiliated with, endorsed by or sponsored by LinkedIn Corporation.

    Limits and notes

    Use it as an API (server mode)

    Need one answer right away instead of a batch job? Send the input as an HTTP request and the results come back in the response. There's no run to start and poll.

    curl -H "Authorization: Bearer $APIFY_TOKEN" \
  "https://vexaloom-labs--linkedin-people-search-by-name-with-company.apify.actor/?names=Satya%20Nadella&maxResultsPerName=1"

    Or POST the same input as JSON:

    curl -X POST -H "Authorization: Bearer $APIFY_TOKEN" -H "Content-Type: application/json" \
  -d '{"names": ["Satya Nadella"], "maxResultsPerName": 1}' \
  "https://vexaloom-labs--linkedin-people-search-by-name-with-company.apify.actor/"
    • The fields are the same as in the input above. With GET, repeat a parameter once for each value in a list.
    • You get back a JSON array with the same records a normal run saves. They're saved to the run's dataset too.
    • Each request is capped at 50 results and 4 minutes. For bigger jobs, start a normal run.
    • The request runs in your own Apify account at the Actor's normal price (a start fee plus a price per result). The server shuts down after a minute with no requests.
    • The Server tab on this page lists every parameter and lets you try a request from your browser.
