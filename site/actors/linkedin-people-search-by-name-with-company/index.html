    LinkedIn People Search by Name with Company & School Filters is an Apify Actor published by Vexaloom Labs. It accepts 6 input fields, and names is required. Each result can carry up to 6 declared fields, including name, headline, location, currentCompany, profileUrl and searchName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per profile”, “Input”, “Use cases”, “FAQ” and “Data source & limitations”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 6 fields in 1 dataset view, and the README documents 11 more. Fields without a value can be left out of a record.

    Output fields
    FieldLabelWhat it holds
    nameThe person's name as shown on their profile.
    headlineReal headline when publicly visible or recoverable from an indexed public result (headlineSource: "page" or "search_engine"); omitted when LinkedIn hides it everywhere.
    locationThe location shown on the profile.
    currentCompanyCurrent employer as {name, slug, url}.
    profileUrlCanonical https://www.linkedin.com/in/... profile URL.
    searchNameThe input name that produced this row.
    currentTitleJob title parsed from a real headline, when available.
    companyTextThe employer summary shown in the directory card, kept for traceability.
    companyRedactedtrue when LinkedIn hides the employer and would otherwise show the job title in its place.
    aboutThe public About text (aboutSource: page, dom or og).
    aboutTruncatedtrue when LinkedIn only exposes a truncated About excerpt to logged-out visitors.
    followersCountFollower count.
    connectionsTextPublic connection indicator, usually "500+".
    currentSchoolSchool shown in the profile's top card.
    discoveredViadirectory, directory_profile (the directory page was the profile itself) or search_engine.
    searchEngineyahoo or duckduckgo when the row came from the search-engine fallback.
    scrapedAtISO 8601 UTC timestamp.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (name plus company). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResultsPerName (default 10, maximum 50) caps how many results a run collects, and so what it costs.

    What it costs

    LinkedIn People Search by Name with Company & School Filters uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 6 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    namesNames to searcharray requiredPerson names to look up. Use a full name ("Satya Nadella"), a single name, or "First Middle Last". Prefix a single term with "first:" or "last:" for a one-sided search.Example ["Satya Nadella"]
    maxResultsPerNameMax results per nameintegerMaximum profiles to return for each name. LinkedIn's public directory lists up to 50 candidates per name.Default 10; Example 1; Allowed 1 to 50
    currentCompanyCurrent companystringKeep only people whose current employer contains this text, e.g. "Microsoft" or "Conrad Labs". Checked against the profile the actor opens for each candidate.
    locationLocationstringKeep only people whose location contains this text, e.g. "London" or "Pakistan".
    enrichProfilesOpen each profile for full detailsbooleanOpen each matched profile's public page to fill photo, about, followers, education and a verified current employer. Turn off for a faster, directory-only result.Default true
    includeHeadlinesFromSearchEnginesUse search engines for extra matches and headlinesbooleanWhen the directory has fewer matches than requested, also check public search-engine results for the name. Also recovers indexed headlines. Free and best-effort.Default true; Example false
