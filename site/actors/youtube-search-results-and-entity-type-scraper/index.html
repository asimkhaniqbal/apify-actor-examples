    What it costs

    YouTube Search Results & Entity Type Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 11 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    searchQueriesSearch Queriesarray requiredOne or more YouTube search terms. Each query is scraped separately and its results are combined in the dataset.Example ["apify"]
    maxResultsMax Results Per QueryintegerMaximum number of results per query. YouTube may serve fewer rows for a given query, entity type, session, or IP; the run reports the requested and actual counts and whether the result pool was exhausted.Default 20; Example 3; Allowed 1 to 1000
    scrapeAllResultsScrape All Available ResultsbooleanKeep loading pages until YouTube stops offering results. This ignores Max Results Per Query and can take longer on broad searches.Default false
    sortBySort BystringOrder of the search results. YouTube currently supports relevance and popularity (view count). Legacy values upload_date and rating are accepted for saved tasks and mapped to relevance with a warning.Default "relevance"
    uploadDateUpload DatestringOnly return results uploaded in the selected period. Applies to videos and Shorts.Default ""; Allowed , last_hour, today, this_week, this_month, this_year
    typeResult TypestringRestrict results to one entity type. Legacy plural value shorts is accepted and mapped to Shorts.Default ""; Example "video"
    durationDurationstringFilter videos by length. Applies to video and Shorts searches.Default ""; Allowed , short, medium, long
    featuresVideo FeaturesarrayFilter videos by features. Multiple selections are combined. Legacy aliases cc, location, and purchased are accepted for saved tasks; cc maps to subtitles and the other two are ignored with a warning.Default []
    marketMarketstringCountry used for YouTube's search context (gl). Results and labels follow this market.Default "US"; Allowed US, GB, CA, AU, DE, FR, JP, KR and 23 more
    languageInterface LanguagestringLanguage for YouTube labels and search text (hl). Auto follows the selected market.Default "auto"; Allowed auto, ar, bn, cs, da, de, el, en and 26 more
    includeVideoDetailsInclude Video DetailsbooleanFetch each video's public detail payload to add exact publish date, views, likes, category, tags, and full description. Adds one request per video and makes runs slower.Default false
