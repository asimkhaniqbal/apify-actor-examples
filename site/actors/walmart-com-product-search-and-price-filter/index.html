    Walmart.com Product Search & Price Filter Scraper is an Apify Actor published by Vexaloom Labs. It accepts 22 input fields, none of them required at the top level. Each result can carry up to 15 declared fields, including name, price, rating, reviewCount, brand and sellerName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Walmart.com Product Search & Price Filter Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 22 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to scrape: keyword search, a category shelf, full product pages, or customer reviews.Default "search"; Allowed search, browse, products, reviews
    searchQueriesSearch keywordsarrayOne or more keywords to search on walmart.com (mode = search). Each query is walked page by page.Default ["iphone case"]
    categoryUrlsCategory URLsarrayWalmart category links starting with /browse/ or /cp/ (mode = browse), e.g. https://www.walmart.com/browse/electronics/3944.Default []
    productUrlsProduct URLsarrayWalmart product links (mode = products or reviews), e.g. https://www.walmart.com/ip/20042402979. Short /ip/ links and alphanumeric product IDs also work.Default []
    itemIdsItem IDsarrayWalmart numeric item IDs (the number at the end of a product link), one per line (mode = products or reviews).Default []
    maxItemsMax recordsintegerHard cap on emitted records for the whole run. In review mode this caps review rows.Default 50; Example 3; Allowed 1 to 10000
    maxPagesMax result pages per queryintegerMaximum search or category pages to walk per query/URL (about 40 products per page). Walmart caps its own listing at 25 pages.Default 5; Example 1; Allowed 1 to 25
    sortBySort bystringWalmart listing order for search and browse modes.Default "best_match"; Allowed best_match, price_low, price_high, best_seller, rating_high, new
    minPriceMin price (USD)numberOnly keep products at or above this price. Applied by Walmart's own price filter.Allowed 0 to 1000000
    maxPriceMax price (USD)numberOnly keep products at or below this price. Applied by Walmart's own price filter.Allowed 0 to 1000000
    minRatingMin ratingnumberOnly keep products rated at least this (0-5). Products with no rating yet are kept.Allowed 0 to 5
    minReviewCountMin review countintegerOnly keep products with at least this many reviews. Products with no review count are kept.Allowed 0 to 100000000
