    What it costs

    JobsDB Hong Kong & Thailand Job Listings Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    workArrangementWork arrangementarrayFilter by on-site/hybrid/remote work arrangement. Pick one or more (OR match). Leave empty for any arrangement.Default []; Allowed 1, 2, 3
