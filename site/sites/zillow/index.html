    Zillow scrapers and data tools

    Vexaloom Labs publishes 2 Apify Actors that read Zillow. Each one answers a different question, so pick by the data you need. Each costs $0.99 per 1,000 results on the Free plan.

    Which Zillow Actor do you need?

    • Zillow Daily Mortgage Rate & Lender Quote Scraper: Pull Zillow's national mortgage rates, APR, and daily rate trend by loan type, with optional individual lender quotes per state.
    • Zillow Property Manager Directory by City: Search Zillow's property manager directory by city/state, or read specific profile URLs directly. Returns business name, contact details, ratings, reviews, rental listings, specialties, and service areas.
